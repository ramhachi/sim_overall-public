# 改善されたトレーニングガイド

## 現在の結果分析

### 問題点
```
Fx: RMSE=175.6N (目標: <100N) ✗
Fy: RMSE=81.2N (目標: <100N) ✓
Mx: R²=0.1408 (目標: >0.90) ✗
Mz: R²=0.3057 (目標: >0.90) ✗
```

### 原因
1. **エポック数が少ない** - 50エポックでは収束していない
2. **モデルが浅い** - 標準モデルではモーメント予測に不十分
3. **学習率が低い** - 0.0005では学習が遅い

## 改善策

### オプション1: シンプル改善版（推奨）⭐

**スクリプト:** `run_simple_validation.m` (更新済み)

```matlab
cd matlab/dl_tire_model
run_simple_validation
```

**変更点:**
- エポック数: 50 → 200
- バッチサイズ: 128 → 256
- 学習率: 0.0005 → 0.001
- Patience: 5 → 15

**予想時間:** 15-30分  
**予想改善:** Fx RMSE < 100N, Mx/Mz R² > 0.5

---

### オプション2: 深層モデル版（最高性能）🚀

**スクリプト:** `run_improved_validation.m` (新規作成)

```matlab
cd matlab/dl_tire_model
run_improved_validation
```

**特徴:**
- **深層モデル使用** (`createDeepTireModel`)
- エポック数: 300
- バッチサイズ: 256
- 学習率: 0.001（減衰あり）
- Patience: 20

**予想時間:** 20-40分  
**予想改善:** すべての要件を満たす可能性が高い

## トラブルシューティング

### 学習が遅い場合
- GPUが使用されているか確認
- バッチサイズを増やす（メモリが許せば）

### メモリ不足エラー
- バッチサイズを減らす: 256 → 128
- または標準モデルを使用

### 過学習の兆候
- Validation lossが上昇し始めたら
- Early stoppingが機能しているか確認
- Patienceを調整
