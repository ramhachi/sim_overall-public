**結論**: 標準モデル(3層)の方が深いモデル(5層)よりも優れた性能を示しました。

## 詳細分析

### なぜ深いモデルが劣っているのか？

#### 1. **過学習の兆候**
- 深いモデル(40Kパラメータ)は訓練データ(5,000サンプル)に対して過剰に複雑
- パラメータ数 vs データ数の比率: 
  - 標準: 10K / 5K = 2.0
  - 深い: 40K / 5K = 8.0 ⚠️
- **推奨比率**: 通常1:10以下(データ数 > パラメータ数×10)

#### 2. **訓練データ不足**
- 5,000サンプルは深いモデルには不十分
- 深いモデルは最低でも20,000〜50,000サンプル必要
- 利用可能な全データ: 197,924サンプル(未使用)

#### 3. **最適化の困難性**
- 深いネットワークは勾配消失/爆発のリスクが高い
- 20エポックでは収束が不十分な可能性
- より長い訓練時間が必要

#### 4. **力とモーメントの違い**
興味深い観察:
- **力(Fx, Fy)**: 深いモデルで大幅悪化(-25%〜-33%)
- **モーメント(Mx, Mz)**: わずかに改善(+0.2%〜+0.4%)

これは、力の予測がより単純な関係性を持ち、浅いモデルで十分である一方、モーメントはより複雑な関係性を持つ可能性を示唆しています。

## 推奨事項

### 即座の推奨
✅ **標準3層モデル(128→64→32)を使用**
- 理由:
  - より高い精度(RMSE平均25%良い)
  - より速い訓練(23%速い)
  - よりシンプル(保守が容易)
  - 過学習のリスクが低い

### 深いモデルを試す場合の条件

もし深いモデルを再試行する場合、以下の条件を満たす必要があります:

1. **より多くのデータ**
   ```matlab
   % 全データセットを使用
   subset_size = 50000;  % 5,000 → 50,000
   ```

2. **より長い訓練**
   ```matlab
   config.max_epochs = 50;  % 20 → 50
   ```

3. **正則化の強化**
   ```matlab
   % Dropout率を上げる
   dropoutLayer(0.3, 'Name', 'dropout1')  % 0.2 → 0.3
   ```

4. **学習率の調整**
   ```matlab
   config.learning_rate = 0.0005;  % 0.001 → 0.0005
   ```

5. **バッチ正規化の追加**
   ```matlab

   ```

## 結論

### 主要な発見

1. ✅ **標準3層モデルが最適** - 現在のデータ量とタスクに対して
2. ❌ **深いモデルは過学習** - データ不足により性能が悪化
3. ⚠️ **両モデルとも要件未達** - より多くのデータと訓練が必要
4. 💡 **力とモーメントで異なる挙動** - 将来的に別々のモデルを検討する価値あり

### 最終推奨

**本番環境では標準3層モデル(128→64→32)を使用してください。**

理由:
- より高い精度
- より速い訓練と推論
- よりシンプルで保守しやすい
- 過学習のリスクが低い

深いモデルは、以下の条件が整った場合のみ再検討:
- 50,000+サンプルでの訓練
- 50+エポックの訓練
- 適切な正則化とハイパーパラメータチューニング
