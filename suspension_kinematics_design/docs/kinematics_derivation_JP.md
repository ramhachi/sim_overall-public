# FASE Aアーム・キネマティクス 数学導出ドキュメント

本資料は、上下Aアームの空間座標（3Dハードポイント）から各種サスペンション・ジオメトリ（キャンバー、ロールセンターなど）を幾何学的・解析的に導出するための数学的アプローチを記録したものです。

## 1. 入力パラメータ (Input Hardware Points)
サスペンションの片輪（例えば右前輪 FR）について、以下の6つの座標（[X, Y, Z]）が与えられます。

- `U_F`: アッパーアーム・シャーシ側フロントピボット
- `U_R`: アッパーアーム・シャーシ側リアピボット
- `U_U`: アッパーアーム・アップライト側（アウター）ボールジョイント
- `L_F`: ロアアーム・シャーシ側フロントピボット
- `L_R`: ロアアーム・シャーシ側リアピボット
- `L_U`: ロアアーム・アップライト側（アウター）ボールジョイント

また、以下のホイール/タイヤ情報が必要です。
- `W_center`: ホイールセンター座標
- `R_tire`: タイヤ外径半径（Loaded Radius）

---

## 2. キングピン軸 (Kingpin Axis) と 関連アライメント

キングピン軸は、アッパーアウタージョイント (`U_U`) とロアアウタージョイント (`L_U`) を結ぶ直線です。
方向ベクトル $\vec{K} = \frac{U_U - L_U}{||U_U - L_U||}$

### 2.1 キャスター角 (Caster Angle)
キャスターは、キングピン軸を側面（X-Z平面）から見た時の後傾角です。
$\theta_{caster} = \arctan\left(\frac{\vec{K}_x}{\vec{K}_z}\right)$
※前輪の場合、通常上側が後ろ（+X方向）に傾いているとき正のキャスター角となります。

### 2.2 キングピン傾角 (Kingpin Inclination / KPI)
KPIは、キングピン軸を正面（Y-Z平面）から見た時の内傾角です。
$\theta_{KPI} = \arctan\left(\frac{|\vec{K}_y|}{\vec{K}_z}\right)$

### 2.3 スクラブ半径 (Scrub Radius)
キングピン軸の直線が接地面（Z = -R_tire、タイヤの接地点基準）と交わる点 $P_{pierce}$ と、実際のタイヤ接地点の中央 $P_{contact}$ のY方向の距離です。
1. 接地点 $P_{contact} = [W_{center.x}, W_{center.y}, W_{center.z} - R_{tire}]$
2. 交点 $P_{pierce}$ は、キングピン上の点。 $P_{pierce} = L_U + t \cdot \vec{K}$ 
   $t = \frac{P_{contact.z} - L_U.z}{\vec{K}_z}$
3. Scrub Radius = $P_{contact.y} - P_{pierce.y}$

## 3. ロールセンター (Roll Center) の幾何学的導出 (Front View)

ロールセンターは、車体（シャーシ）がロールする際の瞬間的な回転中心です。
一般的に2D正面投影（Y-Z平面）によるFront View Swing Arm (FVSA) 法で算出されます。

### Step 1: 各アームの正面投影直線の導出
上下のAアームはそれぞれ仮想的な「1本のリンク」として振る舞います。
- **アッパーリンク投影:** 
  シャーシ側の回転軸は `U_F` と `U_R` を結ぶ直線。この軸に直交し、`U_U` を通る平面において、Y-Z平面への投影ベクトルを求めます。
  簡易的には、`U_F` と `U_R` の中点 `U_C` を求め、`U_C` から `U_U` へ向かうベクトルのY-Z成分を「アッパーアームの正面投影線」とします。
  直線 $l_{upper}$: 通過点 $U_U(Y, Z)$、方向ベクトル $\vec{v}_{upper} = (U_U_y - U_C_y, U_U_z - U_C_z)$

- **ロアリンク投影:**
  直線 $l_{lower}$: 通過点 $L_U(Y, Z)$、方向ベクトル $\vec{v}_{lower} = (L_U_y - L_C_y, L_U_z - L_C_z)$

### Step 2: 瞬間中心 (Instant Center / IC) の算出
直線 $l_{upper}$ と $l_{lower}$ の交点を求めます。これが瞬間中心 $IC(Y, Z)$ です。

### Step 3: ロールセンター (Roll Center) の算出
瞬間中心 $IC$ と タイヤ接地点 $P_{contact}(Y, Z)$ を結ぶ直線を引きます。
この直線が、車両の中心線（Y = 0）と交わる点の Z 座標が **ロールセンター高 (Roll Center Height)** になります。

$RC_z = P_{contact.z} + \frac{IC_z - P_{contact.z}}{IC_y - P_{contact.y}} \cdot (0 - P_{contact.y})$

---

## 4. キャンバー角 (Camber Angle) の計算
キャンバー角は、アップライト（タイヤ）が正面（Y-Z平面）に対してどれだけ傾いているかを示します。
静的状態（Heave=0）では、ホイール中心方向のベクトル（スピンドルベクトル）から算出されます。

ヒーブ（上下ストローク）時のキャンバーゲインを解析するには、車体を仮想的にZ方向に変位させ、拘束条件（上・下Aアーム長不変、タイロッド長不変等）を解くか、瞬間中心の距離から簡易導出します。

### 簡易キャンバーゲイン（Roll Centerベース）
キャンバー変化率 (deg/m) は、ICから接地点までの距離アーム（Swing Arm Length）に反比例します。
正確な3D最適化では、微小ヒーブ量 $dz$ に対してアップライトを運動学的に解き、スピンドルベクトルの微小傾きを差分法で算出するのが最も堅牢です。
