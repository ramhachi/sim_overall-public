# FSAE ダブルウィッシュボーン・サスペンションシステム設計書

## 1. はじめに
本資料は、FSAE（学生フォーミュラ）車両におけるダブルウィッシュボーン式サスペンションおよびプッシュロッド／ベルクランク（POU: Pushrod-On-Upright）システムの幾何学的設計（キネマティクス設計）における基本原理と設計指針をまとめたものです。

先のステップで実施したPOU最適化（ジャッキアップ・プッシュロッド変位の最適化）を前提としつつ、システム全体としてどのように構造を定義し、ラップタイムシミュレーションの最適化結果（`optimized_autocross.json`）を実際のジオメトリに落とし込むかの体系的なワークフローを解説します。

---

## 2. ダブルウィッシュボーン（Aアーム）の幾何学的設計
ダブルウィッシュボーンのハードポイント（アッパーアーム・ロアアームのシャーシピボットおよびアップライトピボット）は、車輪の軌跡を完全に拘束し、以下の重要なキネマティクス特性を決定します。**POU（プッシュロッド機構）はこれらを変更できません。**

### 2.1 キャンバー角（Camber Angle）とキャンバー変化（Camber Gain）
*   **設計目的:** コーナリング時の旋回横Gによって車体がロールした際にも、外輪側のタイヤが路面に対して常に最適な接地角（理想的には対路面0°〜わずかにネガティブ）を保ち、最大グリップを発揮させること。
*   **キャンバーゲイン:** ボトム（サスペンション沈み込み）時のネガティブキャンバーの増力率。アッパーアームをロアアームより短く設定（不等長）し、かつアームの取り付け角度（非平行）を調整することでキャンバーゲインを制御します。

### 2.2 ロールセンター（Roll Center）
*   **設計目的:** シャーシの重心点とロールセンターの距離（ロールモーメントアーム）を適切に保ち、車体のロール量と荷重移動を制御すること。
*   **特性:** 左右のアームの瞬間中心（Instant Center）からタイヤ接地点を結んだ線が車両中心面と交わる点がロールセンターとなります。
*   **最適化:** ロールセンターは高すぎるとジャッキアップフォースが発生しやすく挙動がピーキーになり、低すぎるとロール剛性が低下し過大なロールを生じます。ストロークによるロールセンターの水平・垂直方向の急激な移動量（マイグレーション）を最小限に抑える設計が求められます。

### 2.3 キャスター角（Caster Angle）とトレール / キングピン傾角（KPI）
*   **キャスター角:** キングピン軸を側面から見たときの後傾角。直進安定性の向上と、操舵時にネガティブキャンバーを誘発する効果（キャンバースラスト）があり、フロントグリップ向上に寄与します。
*   **KPI:** キングピン軸を正面から見た時の内向きの傾斜角。ステアリングキックバックの低減や保舵力に影響します。スクラブ半径（接地中心とピボット延長線のズレ）は可能な限り小さくゼロ付近に設計します。

## 3. ベルクランク＆プッシュロッド機能の設計（POU）
ダブルウィッシュボーンが「タイヤの軌跡（路面アライメント）」を支配するのに対し、プッシュロッドとベルクランクの機構は「タイヤに掛かる荷重の支持とダンピング特性」を支配します。

### 3.1 レバー比（Motion Ratio: MR）
*   **定義:** 「ホイールの上下ストローク量に対する、ショックアブソーバー（ダンパー）のストローク量の比」。
*   **設計目標:** 一般に MR = 1.0 に近い値が理想とされます。MRの値が低すぎるとバネの変位が少なくなるため、巨大なスプリングレートが必要になり減衰力の微細なコントロールが極めて難しくなります。

### 3.2 ライジングレート（Rising Rate / Progressive Rate）
*   **定義:** ストロークが進むにつれてレバー比（MR）が変化し、実効的なホイールレート（タイヤ位置でのバネの硬さ）が徐々に硬くなる特性。
*   **効果:** 初期ストロークでは柔らかく路面追従性を確保し、ロールが深くなった限界領域ではハードに踏ん張る理想的な特性を作れます。ベルクランクの回転角度の非線形性によって生み出されます。（POU最適化システムの多項式カーブがこれを定義します）

## 4. 全体シミュレーション（`optimized_autocross.json`）との統合設計ワークフロー

ラップタイムシミュレータによって導出された「空力的・力学的に理想的な車両諸元（`optimized_autocross.json`）」を、実際のサスペンションCAD座標（ハードポイント）に翻訳していく手順です。

### フェーズ 1: アライメント＆Aアーム空間座標の設計（シャーシ・アップライト）
`optimized_autocross.json` に記載されている「動的に決定された静的パラメータ」を満たすように、上下Aアームのピボット位置を決定します。

*   **目標トレッド幅 (TrackF / TrackR):** Front `1369 mm`, Rear `1396 mm` になるように左右のアップライト位置を固定します。
*   **目標ホイールベース (Wheelbase):** `1640 mm` になるように前後アクスルの距離を設定します。
*   **目標重心高 (CG Height):** `297 mm`。この重心高に対して、適切なロールモーメントアーム長となるようにAアームの角度を調整し、前後ロールセンター高を（例：F=30mm, R=50mm付近に）設計します。
*   **静的アライメント (Static Camber / Static Toe):**
    *   **Front:** Camber `-3.5 deg`, Toe `+0.79 deg`
    *   **Rear:** Camber `-0.66 deg`, Toe `+0.27 deg`
    これらの定常状態アライメントが基準（0ストローク位置）となるようにジョイント位置を拘束します。

このフェーズを完了した時点で、タイヤの動的な軌跡（キャンバー変化、トー変化、ロールセンター推移）が完全に確定します。これが完了するまでPOU側の設計は行えません。

### フェーズ 2: ばね上・ばね下質量とホイールレートの定義
`optimized_autocross.json`が指定する理想的なばね定数（Spring Rate）と減衰（Damper Rate）を確認します。

*   **Front:** バネ定数 `56.6 N/mm` (56606 N/m)、ダンパー `637 Ns/m`
*   **Rear:** バネ定数 `16.4 N/mm` (16436 N/m)、ダンパー `537 Ns/m`

※注意点: この数値が「ホイールレート（タイヤ位置での実効値）」なのか「スプリング単体の固有レート」なのかを見極める必要があります。もしこれがスプリング単体レートであれば、レバー比（MR）の二乗に比例して実際の硬さが決まります（$k_{wheel} = k_{spring} \times MR^2$）。

### フェーズ 3: POUプッシュロッド/ベルクランクの幾何学最適化（今回改修したMATLABスクリプト）
フェーズ1で確定したAアーム軌跡（無干渉な空間）に従って、フェーズ2のバネ性能を発揮するためのダンパーマウントおよびベルクランクマウントを決定します。

1.  目標とするライジングレート（ストロークに応じたバネのプログレッシブな硬さ変化）を、「ジャッキアップ（プッシュロッドの変位）多項式ターゲット」として定義します。
2.  `main_pou_hardpoint_optimizer.m` にAアームの固定座標系を入力します。
3.  目的関数からキャンバー等の物理的影響がないパラメータを排除し（`w_camber = 0.0`）、純粋に「ジャッキアップ曲線（Jack-up RMS error）」を満たすように、**Mピボット（アップライト側マウント）** および **ベルクランク（シャーシ側マウント）** の3D座標を非線形ソルバーで算出し、最終的な設計座標を定義します。
