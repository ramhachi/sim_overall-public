# データ解析特論 中間レポート計画

## 1. 課題要件の確認

講義資料から、1st report の要件は以下であることを確認した。

- テーマは `Multiple regression analysis`
- 提出形式は `PowerPoint style`、目安は `~10 pages`
- 必須項目は次の6点
- `1. どのようなデータを使うか`
- `2. 目的変数と説明変数`
- `3. 外れ値解析`
- `4. 共線性チェック`
- `5. 結果（回帰係数, p-values）`
- `6. 考察（何が分かったか、結果は妥当か）`

したがって、今回の中間レポートは「タイヤ力データを対象にした重回帰分析」としてまとめるのが最も自然である。

## 2. 推奨するレポート主題

### 推奨テーマ

`TTCタイヤデータを用いて、純コーナリング条件での横力 Fy を重回帰分析で説明する`

### このテーマを推す理由

- 講義課題の主題である「1つの連続値を複数説明変数で推定する」に直接合う
- TTC 生データに `Fy` が実測値として入っており、無理に派生量を定義しなくてよい
- 説明変数として `SA, Fz, IA, TSTC` を自然に採用できる
- タイヤ物理として解釈しやすい
- 後半で `PINN` に拡張する導線を作りやすい

### 代替案

- `Fx` を目的変数にした純制動・純駆動条件の重回帰
- `Mz` を目的変数にした操舵感寄りの分析
- `μy = Fy / Fz` を目的変数にした正規化解析

ただし、最初のレポートとしては `Fy` が最も説明しやすい。

## 3. 実装で確認済みの事実

### 講義資料

- `Chap 0 Introduction.pdf` で 1st report が multiple regression analysis であることを確認
- `Chap 2 Outlier-2 (1).pdf` で、必須項目が
  `データ紹介 / 目的変数と説明変数 / 外れ値 / 共線性 / 回帰係数とp値 / 考察`
  であることを確認

### TTC データの生カラム

TTC の `.dat` には少なくとも以下が入っている。

- `SA`
- `IA`
- `FX`
- `FY`
- `FZ`
- `MX`
- `MZ`
- `TSTC`
- `SR`

つまり、「力をそのまま目的変数として使う」という方針は成立する。

### 既存 PINN 実装

既存の `tire_pinn` は次の 5 入力を使う。

- `SR`
- `SA`
- `Fz`
- `IA`
- `TSTC`

出力は次の 4 つである。

- `Fx`
- `Fy`
- `Mx`
- `Mz`

したがって、中間レポートで使う重回帰の説明変数は、そのまま PINN の入力設計と接続できる。

### 推奨データセット

現時点では、次のデータセットを第一候補にする。

- `Hoosier_18p0X6p0-10_R20_Rim6`

理由は以下。

- `DriveBrake + Cornering` の両方が揃った complete dataset
- 既存 `tire_pinn/config/pinn_config.yaml` に個別プロファイルがある
- データ量が十分大きい

### 実測データ量の確認

`Hoosier_18p0X6p0-10_R20_Rim6` について、ローダ実行で以下を確認した。

- 総サンプル数: `329600`
- `Cornering`: `166953`
- `DriveBrake`: `162647`

範囲の例:

- `SR`: `-1.4998` から `1.4999`
- `SA`: `-12.472 deg` から `12.567 deg`
- `Fz`: `0.25 N` から `1904.48 N`
- `IA`: `-4.973 deg` から `4.029 deg`
- `TSTC`: `26.66 C` から `88.60 C`

### 純コーナリング Fy 重回帰の成立性

以下のような現実的なフィルタをかけた。

- `source_test_type == Cr`
- `|SR| <= 0.02`
- `Fz >= 300 N`
- `35 <= TSTC <= 85 C`

その上で、`Fy ~ SA + Fz + IA + TSTC` の線形重回帰を試すと、

- サンプル数: `17153`
- `R^2 = 0.8959`
- `adjusted R^2 = 0.8959`
- `SA, Fz, IA, TSTC` の p-value はいずれも十分小さく、有意性は確保しやすい

共線性の指標 VIF も、

- `SA: 1.08`
- `Fz: 1.15`
- `IA: 1.20`
- `TSTC: 1.03`

であり、少なくともこの候補では深刻な多重共線性は見えていない。

したがって、`Fy` 主題は中間レポートとして十分成立する可能性が高い。

### 外れ値解析の見込み

同じ `Fy` 候補集合に対して簡易確認すると、

- `Fy` 単変量の `1.96 SD` 外れ値候補: `0`
- `Fy` 単変量の `1.5 IQR` 外れ値候補: `0`
- 説明変数 `SA, Fz, IA, TSTC` に対する Mahalanobis 距離の `95%` 閾値超過: `1214`
- 比率: 約 `7.1%`

このため、今回のレポートでは

- 単変量外れ値は少ない
- 多変量の組み合わせとして外れ値候補が現れる

という構図で書くと、講義内容に沿った自然な議論ができる。

## 4. レポート全体方針

### 基本方針

中間レポートでは、まず講義要件どおりに「古典的な重回帰分析」を正面からやる。

その上で最終盤に、

- 線形回帰では表しきれない非線形性
- タイヤ力学にある奇関数性や摩擦円制約
- それを補う次段階としての `PINN`

を追加すれば、あなたの研究・実装との接続が綺麗になる。

### 重要な判断

このレポートの主役は `PINN` ではなく `重回帰分析` に置く。

`PINN` は最後の

- 発展
- 限界
- 今後の改善

の位置に置くのが安全である。

## 5. PowerPoint 約10枚の推奨構成

### 1枚目: タイトル

- 仮タイトル
- `TTCタイヤデータを用いた横力 Fy の重回帰分析`
- 氏名
- 所属

### 2枚目: 背景と目的

- Formula SAE 車両ではタイヤ特性の把握が性能に直結する
- TTC データは `SA, SR, Fz, IA, 温度` と実測タイヤ力を含む
- 本レポートでは、純コーナリング条件下で `Fy` を複数変数から説明できるかを調べる

### 3枚目: データの説明

- 使用データセット名
- TTC 由来であること
- どこから得たデータか
- なぜこのデータに興味があるか
- 仮説
- `Fy` は主に `SA` と `Fz` に支配され、`IA` と `TSTC` が補助的に効く

### 4枚目: 目的変数と説明変数

- 目的変数: `Fy`
- 説明変数: `SA, Fz, IA, TSTC`
- 解析対象条件: `|SR| <= 0.02` の純コーナリング近傍
- 必要なら単位を併記

### 5枚目: 前処理

- 欠損除去
- 物理的に不適切な点の除外
- `Fz` 下限
- 温度範囲フィルタ
- 純コーナリング条件の抽出

### 6枚目: 外れ値解析

- 単変量: `Fy`, `SA`, `Fz` に対する箱ひげ図または `1.96 SD`
- 多変量: Mahalanobis 距離の適用候補
- 何件外れ値候補が出たか
- その外れ値を除去したか保持したか
- 理由

### 7枚目: 共線性チェック

- 相関行列
- 散布図行列
- VIF
- 現時点の事前確認では VIF は 1 台で深刻ではない

### 8枚目: 回帰結果

- 回帰式
- 回帰係数
- p-value
- `R^2`
- adjusted `R^2`
- 実測 vs 推定 の散布図

### 9枚目: 考察

- `SA` が最も強く効くか
- `Fz` の寄与は物理直感と合うか
- `IA` の寄与はキャンバースラストとして妥当か
- 温度の係数は期待通りか
- 線形モデルの限界
- 飽和、奇対称、複合スリップ、摩擦円は線形では表現しにくい

### 10枚目: 発展としての PINN

- 既存実装では `5D input -> 4D output`
- `PINN` はデータ適合だけでなく
- `zero-slip`
- `symmetry`
- `friction circle`
- `monotonicity`
  などの物理制約を入れられる
- 今回の重回帰はベースラインとして有効
- 今後は `PINN` と比較して非線形モデルの優位性を示せる

## 6. 今すぐ実装でやるべき項目

### 必須

1. 使用するタイヤデータセットを最終決定する
2. レポート用の前処理条件を固定する
3. 外れ値解析を実装する
4. OLS 回帰を実装し、回帰係数と p-value を出す
5. VIF を計算する
6. 実測 vs 推定、残差、箱ひげ図、相関図を出す

### できれば実施

1. `Fy` と `Fx` の両方を試し、主題を最終比較する
2. 外れ値除去前後で `R^2` と係数変化を比較する
3. 温度を含める場合と含めない場合を比較する
4. `PINN` の既存学習済み結果または再学習結果を参考図として追加する
