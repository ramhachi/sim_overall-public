# tests/property/test_properties_evaluator.py

## 役割
`FitEvaluator` の評価指標計算が、ランダムな真値・予測値に対しても数式定義そのものと一致するかを確かめます。

## 守っている振る舞い
- `rmse` が `sqrt(mean((y_true-y_pred)^2))` と一致すること。
- `nrmse` が `rmse / (max(y_true)-min(y_true))` と一致すること。
- `r2` が残差平方和と全変動から導く標準式と一致すること。
- `tic` が Theil 不等式係数の定義式と一致すること。
- ピーク摩擦誤差が、測定ピーク位置での予測摩擦との差分百分率になること。

## 主なフィクスチャ/ヘルパー
- `setup_method()` で `FitEvaluator` を 1 回生成します。
- Hypothesis が力・荷重配列を生成し、`assume()` で分母ゼロや分散ゼロに近い退化ケースを除外します。

## アサーションの意味
許容誤差つき比較は実装が別経路で計算しても、最終値が理論式から逸脱しないことを保証します。評価指標がずれると最適化比較や品質判定全体が誤るため、このファイルは評価器の基礎信頼性を支えます。
