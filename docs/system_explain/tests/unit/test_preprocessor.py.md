# tests/unit/test_preprocessor.py

## 役割
`TireDataPreprocessor` の行フィルタ、荷重帯分割、IQR 外れ値除去を具体例で検証します。

## 守っている振る舞い
- 速度、鉛直荷重、スリップ角、スリップ率、温度の各条件が独立に効くこと。
- 複合条件適用時に全条件を満たす行だけが残ること。
- `group_by_load()` が Low/Medium/High の範囲と境界重複を正しく扱うこと。
- 範囲外荷重がどのグループにも入らないこと。
- `FZ` 欠落や対象列欠落時に `ValueError` になること。
- IQR 除去が外れ値を落とし、境界計算と custom multiplier に従うこと。

## 主なフィクスチャ/ヘルパー
- `setup_method()` で `TireDataPreprocessor` を生成します。
- 小さな `DataFrame` を各テスト内で直接構築し、どの条件が効いたかを読みやすくしています。

## アサーションの意味
行数確認はフィルタが効いたこと、列条件確認は残存データの品質を見ています。境界値の二重所属チェックは、荷重帯分析で端点が欠落・重複カウントされる事故を防ぐために重要です。
