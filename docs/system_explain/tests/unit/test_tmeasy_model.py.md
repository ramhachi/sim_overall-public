# tests/unit/test_tmeasy_model.py

## 役割
`TMeasyModel` の代表式、符号規約、飽和挙動、配列入力処理を具体例で確認する基礎単体テストです。

## 守っている振る舞い
- 公称荷重上下で荷重依存摩擦係数が期待どおり増減すること。
- 飽和関数が `s=0`, `0.5`, `1`, `>1` で既知値を返すこと。
- 縦力・横力がゼロスリップ/ゼロ荷重で 0 になること。
- 正負スリップで力の符号が反転し、絶対値は対称になること。
- 大きなスリップで力増加率が低下し、飽和へ向かうこと。
- キャンバのみでも `C_gamma * camber * Fz` の横力が出ること。
- 配列入力で同じ長さの配列が返り、要素ごとに一貫した結果を出すこと。
- 同じ正規化変形を与えると縦横で同じ飽和関数が使われること。

## 主なフィクスチャ/ヘルパー
- `setup_method()` で `fz_nominal=1000.0` のモデルを生成します。
- 手計算コメントが多く、各期待値の由来を明示しています。

## アサーションの意味
ここでの既知値比較は、モデルの数式レベルの回帰防止です。符号規約と飽和形状は車両運動へ直結するため、小さな式変更でもこのテストが即座に検出します。
