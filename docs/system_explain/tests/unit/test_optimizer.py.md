# tests/unit/test_optimizer.py

## 役割
`TireParameterOptimizer` の境界設定、合成データ適合、データ不足時の拒否、カスタム境界反映を確認します。

## 守っている振る舞い
- 初期化時の縦横パラメータ bounds が設計どおりであること。
- 合成したクリーンな縦・横データから真値近傍の係数を回収でき、`rmse` が小さく `r2` が高いこと。
- 点数不足では `Insufficient data` を出してフィットを拒否すること。
- 呼び出し側が与えた custom bounds を最終解が守ること。

## 主なフィクスチャ/ヘルパー
- `setup_method()` で `TMeasyModel` と `TireParameterOptimizer` を生成します。
- `np.random.seed(42)` を固定し、ノイズなしの合成データで最適化の基準応答を作ります。

## アサーションの意味
真値比の誤差率チェックは、最適化器が大きく外した解に落ちていないことの確認です。例外系と bounds 系は、実運用で不十分データや過度な探索領域を誤って受け入れないための契約になっています。
