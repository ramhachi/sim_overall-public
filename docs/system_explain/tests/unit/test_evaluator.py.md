# tests/unit/test_evaluator.py

## 役割
`FitEvaluator` の代表的な数値例、ゼロ誤差系、負荷重ではなく負力を含むケース、可視化出力を単体テストで押さえます。

## 守っている振る舞い
- 完全一致入力で `rmse=0`、`nrmse=0`、`r2=1`、`tic=0` になること。
- 既知の数列で手計算した `rmse`、`nrmse`、ピーク摩擦誤差と一致すること。
- 全ゼロ力ではピーク摩擦誤差を 0 と扱うこと。
- `plot_force_vs_slip()` と `plot_residuals()` が実ファイルを生成すること。
- 負力や符号混在データでも指標が安定して計算できること。

## 主なフィクスチャ/ヘルパー
- `setup_method()` で `FitEvaluator` を生成します。
- 一時ディレクトリに PNG を保存し、ファイル存在とサイズを確認します。
- 荷重グループ付き描画では `load_groups` マスクを手で構成します。

## アサーションの意味
数値既知例の比較は評価式の基準点、画像ファイル確認は可視化 API の生存確認です。メトリクスが負値や混合符号で破綻しないことは、実測タイヤデータを扱う上で不可欠です。
