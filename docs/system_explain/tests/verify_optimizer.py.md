# tests/verify_optimizer.py

## 役割
`TireParameterOptimizer` が合成データから既知パラメータを回収できるかを、縦力・横力の両方で確認する検証スクリプトです。

## 入力と出力
- 入力: 乱数 seed 42 で作る合成 `sr/sa/fz/camber` と 5N ノイズ付き力データ
- 出力: 真値、推定値、RMSE、R²、収束フラグ、各係数の相対誤差
- 生成物: なし

## 主な処理
- 前半では真値 `mu_x_peak/k_mu_x/Kx` を使って縦力データを生成し、`fit_longitudinal()` の回収結果を比較します。
- 後半では `mu_y_peak/k_mu_y/Ky/C_gamma` で横力データを生成し、`fit_lateral()` の回収結果を比較します。
- どちらも相対誤差を百分率で表示し、最適化の健全性を確認します。

## 存在理由
- 実データ依存を排し、最適化器そのものが既知解へ戻れるかを素早く確かめるための確認用スクリプトです。
