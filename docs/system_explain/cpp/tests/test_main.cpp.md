# `cpp/tests/test_main.cpp`

## 1. ファイルの目的

GoogleTest ベースの C++ テスト群に対して、共通の実行入口を与えるためのファイルです。  
個別テスト本体を持たず、`RUN_ALL_TESTS()` を呼ぶ最小ランナーだけを提供します。

## 2. 実行上の役割

- `cpp/tests/` 配下の各 `TEST` / `TEST_F` をまとめて起動する入口です。
- コマンドライン引数を GoogleTest に引き渡し、フィルタや出力制御を有効にします。
- ビルド済みテスト実行ファイルの終了コードを、そのまま CI / `ctest` 側へ返します。

## 3. 依存関係

- `gtest/gtest.h`
  - テストフレームワーク初期化 (`::testing::InitGoogleTest`)
  - 全テスト実行 (`RUN_ALL_TESTS`)

このファイル自身はリポジトリ内の個別モジュールへ直接依存せず、リンク時に各テストオブジェクトと結合されて役割を果たします。

## 4. 入力 / 出力

- 入力
  - `argc`, `argv`: GoogleTest のオプション (`--gtest_filter` など) を受け取るコマンドライン引数
- 出力
  - 標準出力 / 標準エラー: GoogleTest の実行ログ
  - 戻り値: テスト成功時 `0`、失敗時は非 `0`

## 5. 関数・メソッド・クラスの網羅的な説明

### `int main(int argc, char** argv)`

- このファイルで唯一の関数です。
- `::testing::InitGoogleTest(&argc, argv);` で GoogleTest ランタイムを初期化します。
- `return RUN_ALL_TESTS();` により登録済み全テストを実行し、結果コードを呼び出し元へ返します。
- 補助ロジックや例外処理は持たず、テストランナーとしての責務だけに限定されています。
