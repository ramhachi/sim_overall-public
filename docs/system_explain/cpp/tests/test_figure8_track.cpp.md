# `cpp/tests/test_figure8_track.cpp`

## 1. ファイルの目的

8 の字トラック生成関数 `create_figure_eight_track` の幾何形状を手早く確認するための、コンソール出力型の確認プログラムです。  
GoogleTest ではなく、生成トラックの長さ・始終点一致・途中点を人間が読む用途に寄っています。

## 2. 実行上の役割

- 8 の字トラックが閉路になっているかを数値出力で確認します。
- 代表点の `x`, `y`, `theta`, `kappa` を観察し、トラック生成ロジックのデバッグ補助を行います。
- 自動判定よりも、開発中の形状チェック・目視確認に向いた役割です。

## 3. 依存関係

- `cpp/include/fsae/track/track_model.hpp`
  - `track::create_figure_eight_track`
  - 生成されるトラック型の `length()`, `get_point()`
- 標準出力関連
  - `iostream`, `iomanip`
- 数値計算
  - `std::sqrt`, `M_PI`

## 4. 入力 / 出力

- 入力
  - ソース内固定値 `25.0`（代表スケール）, `3.0`（幅などの設定値）
- 出力
  - トラック長
  - 開始点 / 終端点の座標と姿勢
  - 始終点間距離、姿勢差
  - 等間隔サンプル点の `x`, `y`, `kappa`

## 5. 関数・メソッド・クラスの網羅的な説明

### `int main()`

- `track::create_figure_eight_track(25.0, 3.0)` で 8 の字トラックを生成します。
- `track.length()` を表示し、トラック全長の概略値を確認します。
- `get_point(0.0)` と `get_point(track.length())` を比較して、閉路として始点と終点が一致しているかを観察します。
- 始終点の距離と姿勢差を計算し、閉路誤差を数値化します。
- さらに 10 分割した途中点を列挙し、曲率 `kappa` を含む軌道形状を一覧表示します。
- 正常終了時に `0` を返します。
