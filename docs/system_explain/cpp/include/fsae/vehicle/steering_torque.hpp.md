# steering_torque.hpp

## 1. ファイルの目的
ステアリングトルク平衡式を inline 関数として提供するヘッダです。

## 2. 実行上の役割
14DOF 車両モデルのトルクモード操舵で、ステアリングホイール角加速度と角度変換を計算します。

## 3. 依存関係
- `vehicle_14dof_new.hpp`

## 4. 入力/出力
- 入力: 慣性、ドライバートルク、SAT、ギア比、現在角・角速度、摩擦・減衰・復元係数
- 出力: ステアリングホイール角加速度、または角度変換結果

## 5. 関数・メソッド・クラスの網羅的な説明
### `compute_steering_acceleration(...)`
SAT、クーロン摩擦、粘性減衰、復元ばねを差し引いたトルク収支から角加速度を返します。内部でゼロ速度対応の符号 lambda を使います。

### `steering_wheel_to_tire_angle(...)`
ステアリングホイール角をタイヤ舵角へ変換します。

### `tire_angle_to_steering_wheel(...)`
タイヤ舵角をステアリングホイール角へ戻します。
