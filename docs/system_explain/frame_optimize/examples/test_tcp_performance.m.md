# `frame_optimize/examples/test_tcp_performance.m`

## 役割

- TCP 版 FEM ソルバーと従来版 `beam_fem_solver` の性能・結果一致性を比較するベンチマークです。

## スクリプトの流れ

- 材料とパイプカタログを読み込み、16 ノード 16 要素の簡易フレームを構築します。
- `beam_fem_solver_tcp` を 10 回呼び、初回起動時間と 2 回目以降の平均時間を測ります。
- サーバ停止後、`beam_fem_solver` を 5 回呼んで Docker/従来版の平均時間を測ります。
- 質量とねじり剛性の差分を比較し、結果一致性を確認します。
- 最後に棒グラフと時系列グラフを描きます。

## 入力

- `materials.json`
- `pipe_catalog.json`
- 16 ノードフレーム
- `beam_fem_solver_tcp`
- `beam_fem_solver`

## 出力

- TCP 版・従来版の平均時間と標準偏差
- 質量誤差、剛性誤差
- 比較図

## セクション詳細

### テストデータ準備

- **責務**
  - `demo_simple_frame` 相当の簡易ジオメトリを比較用に再構築します。
- **注意点**
  - 中間ログとして要素行の長さやスカラーサイズを表示しており、デバッグ色が強いです。

### TCP 版性能測定

- **責務**
  - 初回起動込み時間と、接続済み状態の定常性能を切り分けます。

### Docker/従来版性能測定

- **責務**
  - 同一入力で旧バックエンドの平均時間を測り、速度差を求めます。

### 一致性確認

- **責務**
  - 質量と剛性の相対誤差から、計算結果が同じかを判断します。

## 前提・注意点

- 比較対象の `beam_fem_solver` が同環境で使えることが前提です。
- 速度比較はローカル環境負荷やサーバ起動状態に左右されます。
