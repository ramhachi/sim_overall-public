# `frame_optimize/examples/demo_simple_frame.m`

## 役割

- 16ノードの簡易フレームを手で定義し、`beam_fem_solver` で質量・ねじり剛性・変位を確認する最小デモです。
- 材料読込、要素配列の組み立て、境界条件、可視化までを一通り確認する入口になっています。

## スクリプトの流れ

- **1. 材料とパイプカタログの読込**
  - `loadMaterials` と `loadPipeCatalog` を使って AISI4130 の物性を取得します。
- **2. フレーム形状の定義**
  - 前後フープ、中央補助点、対角補剛点を含む 16 ノードを手で定義します。
  - `elements` は `[node_i, node_j, D_outer, t, E, G, rho, shape, joint_factor]` の 9 列形式です。
- **3. 境界条件と荷重**
  - ノード 1・2 を 6DOF 完全拘束、ノード 5 を並進拘束として剛体モードを抑えます。
  - 後部上側 2 点に ±1000 Nm のねじりモーメントを与えます。
- **4. FEM 実行**
  - `beam_fem_solver` を呼び、`result.mass`、`result.K_torsion`、`result.U` を取得します。
- **5. 結果表示**
  - 想定範囲外の質量・剛性は `warning` を出します。
- **6. 可視化**
  - 左に原形状、右に 1000 倍拡大した変形形状を描画します。

## 主な入力

- `materials.json`
- `pipe_catalog.json`
- ハードコードされた寸法
  - `L=2.4 m`, `W=1.2 m`, `H_front=1.0 m`, `H_rear=1.4 m`
- パイプ仕様
  - 外径 25.4 mm、肉厚 1.65 mm、丸管、`joint_factor=0.75`

## 主な出力

- `result.mass`
- `result.K_torsion`
- `result.U`
- MATLAB 図 2 枚分のサブプロット

## 依存関係

- `frame_optimize/matlab/loadMaterials.m`
- `frame_optimize/matlab/loadPipeCatalog.m`
- `beam_fem_solver` MEX または同名インターフェース

## セクション詳細

### 1. データ読込

- **責務**
  - 材料物性と標準パイプ仕様を MATLAB 構造体へ展開します。
- **注意点**
  - `catalog` 自体は本スクリプトでは直接使わず、主に物性取得のための流れ確認用です。

### 2. ノード・要素定義

- **入力**
  - 手書きノード座標、共通パイプ仕様
- **出力**
  - `nodes`, `elements`
- **要点**
  - 前後フープ、上下レール、クロスブレースをすべて明示的に列挙しています。
  - 要素仕様を全行共通にすることで、FEM インターフェース形式を分かりやすく示しています。

### 3. 境界条件・荷重

- **入力**
  - 節点番号、DOF 番号、拘束値または荷重値
- **出力**
  - `bcs`, `loads`
- **注意点**
  - トルクは 2 節点の `Mx` に正負で与えています。
  - ノード 5 の補助拘束がないと特異行列になりやすい設計です。

### 4. FEM 実行

- **責務**
  - 解析器が存在するか確認し、なければ Docker ビルド手順を表示して終了します。
- **注意点**
  - コメントは Docker ベースですが、実際の呼び出しは `beam_fem_solver(...)` です。

### 5. 結果評価

- **責務**
  - 質量、剛性、最大変位を数値として報告します。
- **前提**
  - 剛性 100〜2000 Nm/deg、質量 5〜20 kg を簡易妥当範囲として扱っています。

### 6. 可視化

- **責務**
  - 原形状と変形形状を比較しやすい形で表示します。
- **注意点**
  - 変形は `result.U(:,1:3)` のみ使い、回転成分は表示していません。

## 前提・注意点

- 教材用の簡略モデルであり、FSAE 規則適合性はチェックしません。
- 荷重ケースはねじり 1 ケースのみです。
- パイプ径・板厚の探索や最適化は行いません。
