# `frame_optimize/examples/demo_real_vehicle_frame_opt.m`

## 役割

- 実車ベースのフレーム最適化を、前後懸架ブラケット・可変ノード・可変トポロジー込みで実行する統合デモです。
- `frameObjectiveFunction` と `custom_mixed_ga` を中心に、最終ダッシュボードまで通します。

## スクリプトの流れ

- **1. データ読込**
  - ジオメトリ、材料、パイプカタログ、懸架ファイルを読みます。
- **2. ベースフレーム構築**
  - 43 ノード系を意識した初期節点群を作り、前懸架・FBH・インナーブラケットを含む配置を決めます。
- **3. 除外ゾーン確認**
  - 実車除外ゾーンと追加テンプレートの侵害を確認します。
- **4. 最適化設定**
  - 18 変数の混合整数 GA 問題を定義します。
- **5. FEM サーバ起動**
  - `beam_fem_solver_tcp_java('start')`
- **6. GA 実行**
  - `custom_mixed_ga` に初期推定値・整数制約付きで渡します。
- **7. 最終解再構築**
  - `generate_parametric_nodes` と `generate_adaptive_topology` で最終フレームを再生成します。
- **8. 可視化・保存**
  - `fsae_viewer` を表示し、`fsae_optimized_dashboard.png` を保存します。
- **9. サーバ停止**

## 入力

- 実車ジオメトリ JSON
- 材料・パイプカタログ
- 懸架ハードポイント
- 18 変数設計ベクトル

## 出力

- `best_x`
- `best_fval`
- 世代履歴
- `fsae_optimized_dashboard.png`

## セクション詳細

### 2. ベースフレーム構築

- **責務**
  - FBH を懸架ジオメトリに整合させ、FH を懸架後方へ逃がし、MH と SI を運転席寸法に合わせて配置します。
- **注意点**
  - インナーブラケット節点は懸架マウントから FH 面へ向けて生成されます。
  - トポロジー自体はここで固定せず、目的関数側が毎回再構築します。

### 4. 最適化設定

- **整数変数**
  - パイプインデックス 1〜5
  - ノードトグル 13〜14
- **連続変数**
  - フレーム高さ・幅・位置比
  - 距離閾値
  - 補助ノード位置比
- **責務**
  - 離散設計と連続設計を同時に扱える問題へ変換します。

### 6. GA 実行

- **責務**
  - 各候補に対して FEM 評価・除外ゾーン評価・目的関数計算を繰り返し、最小値を探索します。
- **注意点**
  - 並列評価を想定して FEM サーバを外部プロセスとして明示起動しています。

### 8. 可視化・保存

- **入力**
  - 最終節点、最終トポロジー、履歴、再生成した BC/荷重
- **出力**
  - ダッシュボード図
  - PNG 保存
- **責務**
  - 世代変化と最終形状をまとめて確認できるようにします。

## 前提・注意点

- 研究用色が強く、コード内のコメントにも試行中の設計意図が多く残っています。
- FEM サーバや Java/TCP インターフェースが利用可能であることが前提です。
- 出力ファイル保存後も `uiwait(gcf)` で図が閉じるまで終了しません。
