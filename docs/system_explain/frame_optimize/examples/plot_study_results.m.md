# `frame_optimize/examples/plot_study_results.m`

## 役割

- `study_pipe_sizes.m` の結果をハードコード済み配列から再描画する可視化専用スクリプトです。
- FEM を再実行せず、設計比較資料を素早く作る用途を想定しています。

## スクリプトの流れ

- 結果配列 `data` を読み込み、鋼外径・板厚・質量・剛性へ分解します。
- 2x3 の図を作成し、以下を順に描画します。
  - 質量 vs 剛性散布図 + Pareto front
  - 鋼外径 vs 質量
  - 鋼外径 vs 剛性
  - 剛性重量比
  - 材料別質量内訳
  - 文字ベースの要約表
- 推奨構成をコンソールへ表示します。

## 入力

- ハードコード配列 `data`

## 出力

- 6 枚組の要約図
- 推奨構成のログ

## セクション詳細

### `data`

- **内容**
  - `[D_steel, t_steel, D_alum, mass, K_torsion]`
- **責務**
  - 過去実行結果の固定スナップショットです。

### Pareto 表示

- **責務**
  - 軽量かつ高剛性な非支配解を赤破線で示します。
- **追加表示**
  - 500 Nm/deg の目標線
  - 推奨構成（31.8×2.0）を黄色の五角形で強調

### 材料別質量内訳

- **前提**
  - 鋼 12 要素、アルミ 33 要素という近似比率で質量配分しています。
- **注意点**
  - 厳密な積算ではなく説明用の概算です。

### Summary Table

- **責務**
  - 図中に文章で主要知見を載せ、資料用途で使いやすくします。

## 前提・注意点

- 数値はハードコードで、ソース・データ更新に自動追従しません。
- 再解析ではなく結果整理専用です。
