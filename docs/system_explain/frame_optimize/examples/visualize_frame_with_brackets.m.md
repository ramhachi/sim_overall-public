# `frame_optimize/examples/visualize_frame_with_brackets.m`

## 役割

- 懸架ブラケット付きのフレーム骨格を 3D で可視化し、フロント・リアのブラケット接続レイアウトを目視検証するスクリプトです。

## スクリプトの流れ

- 懸架 JSON とホイールベースを読み込みます。
- 前後懸架マウントとアップライトをフレーム座標系へ変換します。
- FBH、FH、SI、MH、リアセクションの基準寸法を設定します。
- 前後のインナーブラケット節点を、マウント→アップライト方向から 50 mm 車体側へ延長して生成します。
- `frame_nodes` と `frame_edges` を組み立て、ブラケット接続も含めて描画します。

## 入力

- `suspension_base_geometry.json`
- `optimized_autocross.json`

## 出力

- フレーム節点数・ブラケット数のログ
- フレーム・ブラケット・懸架系を重ねた 3D 図

## セクション詳細

### 前後懸架抽出

- **責務**
  - フロントは FL を元に FR をミラー、リアは RL を元に RR をミラーして節点配列へ整理します。

### フレーム基準寸法設定

- **責務**
  - FBH/FH/MH/Rear Section の代表寸法を決め、可視化用の簡易骨格を構築します。
- **注意点**
  - ここでの値は可視化向けであり、本番最適化モデルと完全一致する保証はありません。

### インナーブラケット生成

- **入力**
  - 懸架マウント点、対応アップライト点
- **出力**
  - `front_inner`, `rear_inner`
- **責務**
  - マウントから車体側に 50 mm 入った仮想ブラケット節点を生成します。

### `frame_edges`

- **責務**
  - FH、SI、MH heptagon、RS front/rear ring の接続関係を可視化用に定義します。

## 前提・注意点

- 「視覚検証ツール」であり、FEM 用要素生成や規則チェックは行いません。
- ブラケット接続先は近傍フレーム節点への手作業マッピングです。
