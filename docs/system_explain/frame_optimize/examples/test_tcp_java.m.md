# `frame_optimize/examples/test_tcp_java.m`

## 役割

- Java Socket 版 `beam_fem_solver_tcp_java` の起動時間・定常性能・既存 `beam_fem_solver_tcp` との比較を行うベンチマークです。

## スクリプトの流れ

- 2 ノード・1 要素の最小ケースを用意します。
- 初回呼び出しでサーバ起動時間込みの応答を測定します。
- 100 回連続呼び出して平均・標準偏差・最小・最大・中央値を集計します。
- `beam_fem_solver_tcp` が存在すれば停止後に比較測定し、速度比を表示します。
- ヒストグラムと時系列グラフを描画します。

## 入力

- 最小 FEM ケース
- `beam_fem_solver_tcp_java`
- 任意で `beam_fem_solver_tcp`

## 出力

- 平均応答時間
- 比較時の速度比
- ヒストグラムと安定性プロット

## セクション詳細

### 初回呼び出し

- **責務**
  - Java 側サーバ起動を含む初回レイテンシを測定します。

### 100 回性能測定

- **責務**
  - 定常状態でのレイテンシ分布を確認します。

### `tcpclient` 版比較

- **責務**
  - 旧 `beam_fem_solver_tcp` がある場合だけ比較し、なければスキップします。
- **注意点**
  - 比較前に Java 版を `stop` してポート衝突を避けています。

## 前提・注意点

- 最小ケースなので、FEM 負荷より通信・起動オーバーヘッドの比較に向いています。
