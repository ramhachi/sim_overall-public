# parse_debug.cpp
## ファイル目的
- C++ ビルド系の最小動作確認用デバッグ実行ファイルを提供する。

## 実行フロー
- `main` が標準出力へ固定文字列を 1 行出す。

## 関数詳細
### `int main()`
- シグネチャ: `int main()`
- 入力: なし
- 出力:
  - 標準出力 `"Debug file created"`
- 責務:
  - きわめて単純な実行確認
- 主要ロジック:
  - `std::cout << ... << std::endl`
- 依存関係:
  - `<iostream>`
- 前提条件・注意事項:
  - 戻り値 `return 0;` は明示されていないが C++ では `main` 終了時に 0 扱い
