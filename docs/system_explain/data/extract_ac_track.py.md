# `data/extract_ac_track.py`

## 役割

- Assetto Corsa 系の `.ai` バイナリから走行ライン点列を抜き出し、可読な CSV に変換する抽出スクリプトです。
- `fast_lane.ai` のヘッダに書かれたレコード数を信頼し、余剰バイトを候補線や古いデータとして無視します。

## 運用上の入口

### `extract_track()`
- スクリプト実行時に直接呼ばれます。
- `filepath` と `output_csv` は絶対パスで固定されています。

## 主要処理

### ヘッダ解析
- 先頭 16 バイトを `struct.unpack('iiii', ...)` で読み、`version`, `count`, `u1`, `u2` を取得します。
- 標準出力にヘッダ情報と、ファイルサイズから見た最大レコード数を表示します。

### レコード抽出
- 1 レコード 20 バイトとして、`float x, y, z, dist` と `int id` を読み出します。
- 読み取り件数はヘッダの `count` を上限にし、実ファイル終端が早ければ途中で停止します。

### CSV 出力
- 列名 `x, y, z, dist, id` を付けて、抽出した全点を CSV に保存します。

## 入出力・副作用

- **入力**: `data/fast_lane.ai`
- **出力**: `data/fast_lane.csv`
- **戻り値**: なし
- **副作用**: 出力 CSV を新規作成または上書き

## データフロー

1. `.ai` バイナリ存在確認
2. 16 バイトヘッダ解析
3. 残り領域を 20 バイト単位で分解
4. 点列を Python リストへ蓄積
5. CSV へ永続化

## システム内での位置づけ

- 外部シミュレータやゲームの走行ラインを、このリポジトリで加工しやすい形式へ落とす**データ取り込みユーティリティ**です。
- `convert_track_data.py` とは別系統ですが、どちらも走行ラインを FSAE シミュレーション用データへ近づける前段で使われます。
