# `data/analyze_track_quality.py`

## 役割

- `ASE_autocross_sim.csv` の中心線点列を読み、**点間隔のばらつき**と**最大曲率**を素早く確認する解析スクリプトです。
- 生成済みトラックがシミュレーション向けに粗すぎないか、急曲率がないかを手元で点検する用途に向いています。

## 運用上の入口

### `analyze_track()`
- モジュール末尾の `if __name__ == "__main__":` から直接呼ばれます。
- 引数はなく、ファイルパスはグローバル変数 `filename` に固定されています。

## 主要処理

### CSV 読み込み
- `csv.reader` で 1 行目ヘッダを読み飛ばし、各行の 1・2 列目を `float` 化して `(x, y)` として保持します。
- 数値変換に失敗した行は `ValueError` を握りつぶしてスキップします。

### 点間隔評価
- 隣接 2 点間距離 `d1`, `d2` を逐次計算し、`min_dist` と `max_dist` を更新します。
- これにより、リサンプリング不足や局所的な点密度異常を把握できます。

### 曲率評価
- 3 点 `p0, p1, p2` から三角形面積を求め、Menger curvature `4A/(abc)` で近似曲率を計算します。
- 面積がほぼ 0 の場合は除外し、最大曲率のみを保持します。

## 入出力・副作用

- **入力**: `data/ASE_autocross_sim.csv`（絶対パス固定）
- **出力**: 標準出力へ総点数、最小/最大点間隔、最大曲率、最小回転半径を表示
- **副作用**: なし（ファイル更新なし）

## データフロー

1. CSV から `(x, y)` 点列を収集
2. 連続 3 点ごとに距離と曲率を計算
3. 極値を集計
4. トラック品質の概要を標準出力へ報告

## システム内での位置づけ

- `convert_track_data.py` で整形したトラックを**後段で検査する軽量チェッカー**です。
- 本体シミュレータへ入力する前に、形状品質を数値で確認する補助ツールとして機能します。
