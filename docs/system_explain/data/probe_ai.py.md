# `data/probe_ai.py`

## 役割

- `.ai` バイナリの構造を推測するための**調査用プローブスクリプト**です。
- 正式変換器ではなく、ヘッダ値・残りバイト数・先頭浮動小数列・割り切れるレコード幅候補を観察するために使います。

## 運用上の入口

- 関数定義はなく、ファイルを実行するとトップレベルの処理がそのまま動きます。
- 対象ファイルは `filepath = data/fast_lane.ai` に固定されています。

## 主要処理

### ファイルサイズ確認
- `os.path.getsize()` で総バイト数を取得し、冒頭で表示します。

### ヘッダ候補の読み出し
- 先頭 16 バイトを 4 個の `int` として読み、ヘッダ候補値を出力します。
- `.ai` 形式の仕様が未確定な前提で、意味づけ前の生値を観察する作りです。

### 先頭 float / int の両解釈表示
- オフセット 16 以降の先頭 20 ワードを `float` と `int` の両方で表示し、座標か ID かを人手で判別しやすくしています。

### ストライド探索
- 残りバイト数が `stride * 4` で割り切れる候補を 1〜199 float 幅まで列挙します。
- これにより、1 レコードが何 float 相当かの当たりを付けられます。

## 入出力・副作用

- **入力**: `data/fast_lane.ai`
- **出力**: 標準出力のみ
- **副作用**: なし

## データフロー

1. ファイルサイズ取得
2. 先頭 16 バイトを整数ヘッダとして観察
3. 余剰領域の float/int 値を表示
4. レコード幅候補を列挙

## システム内での位置づけ

- `extract_ac_track.py` を書く前段・直し込み時に使う**フォーマット解析補助**です。
- 本番パイプラインには入らず、未知バイナリの取り込み方針を決める調査用コードとして位置付けられます。
