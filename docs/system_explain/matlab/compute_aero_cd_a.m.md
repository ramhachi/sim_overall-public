# `matlab/compute_aero_cd_a.m`

## 1. ファイルの目的

与えた `CL_A` 相当値から簡易 drag polar で `CD_A` を計算する共通ユーティリティです。  
複数の最適化スクリプトで同じ空力抵抗モデルを再利用するためにあります。

## 2. 主な入出力または依存関係

- 入力:
  - `cl_a`
  - オプション `cd0`, `k_induced`, `power`
- 出力: `cd_a`
- 依存関係: `inputParser`

## 3. 処理の流れ / アルゴリズム

1. `inputParser` で基礎抗力、誘導抗力係数、指数を受け取ります。
2. `cl_a` は負値を許さず `max(cl_a, 0)` で切り上げます。
3. `cd0 + k_induced * cl_a^power` を計算して返します。

## 4. ファイル内の関数

### `compute_aero_cd_a(cl_a, varargin)`

- 本ファイル唯一の関数です。
- 誘導抗力をべき乗則で近似しており、最適化中に毎回使う軽量モデルとして設計されています。
- 入力がベクトルでも要素ごと演算で処理できます。

## 5. 注意点・前提条件

- 負の `cl_a` は 0 として扱われるため、揚力方向反転のような挙動は表現しません。
- 高精度な空力マップではなく、最適化用の近似モデルです。
