# `matlab/create_vehicle_baseline_template.m`

## 1. ファイルの目的

シミュレーションや最適化が C++ 側の暗黙デフォルトに依存しないよう、車両パラメータの完全テンプレートを返す関数です。

## 2. 主な入出力または依存関係

- 入力: なし
- 出力: `base`
- 依存関係: 外部関数なし

## 3. 処理の流れ / アルゴリズム

1. エンジン回転数配列とトルク曲線を先に定義します。
2. `mass`, `suspension`, `tire`, `steering`, `powertrain`, `brake`, `aero`, `drs` を含む大きなネスト構造体を 1 回で構築します。
3. タイヤ relaxation やフレームねじり関連も含め、後段で参照される主要キーをすべて埋めた状態で返します。

## 4. ファイル内の関数

### `create_vehicle_baseline_template()`

- 本ファイル唯一の関数です。
- 質量・慣性・バネ・ダンパ・タイヤ緩和長・ステア系・LSD・ブレーキ・空力基準値を一括で返します。
- artifact 生成、GA 初期値、ランタイム実行時のフォールバックなど、多くの MATLAB スクリプトの基準土台として使われます。

## 5. 注意点・前提条件

- ここで返す値は「完全テンプレート」であり、現実車両の最新仕様そのものとは限りません。
- 多くのスクリプトがこのキー構造の存在を前提としているため、フィールド名変更の影響範囲は大きいです。
