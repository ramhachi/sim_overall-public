# `matlab/pou_hardpoint_design/geometry/axis_angle_rotation.m`

## 1. 目的

軸・角度表現から 3×3 回転行列を作る基礎関数です。POU 系ではキングピンまわりの操舵回転や補助計算に使われます。

## 2. 入出力と依存関係

- 入力:
  - `axis`: 3 要素ベクトル
  - `angle`: 回転角 [rad]
- 出力:
  - `R`: 3×3 回転行列
- 依存関係: MATLAB 基本演算のみ

## 3. 全体処理フロー

1. `axis(:) / norm(axis)` で軸を単位ベクトル化します。
2. 軸から外積行列 `K` を作ります。
3. Rodrigues 公式 `R = I + sinθ K + (1-cosθ) K^2` を計算します。

## 4. 関数詳細

### `axis_angle_rotation(axis, angle)`

- 軸の形は列ベクトルへ揃えられます。
- 右手系の角度符号を使います。
- ゼロベクトル軸への防御は入っていないため、呼び出し側は正規化可能な軸を渡す前提です。

- **ローカル関数**  
  このファイルにローカル関数はありません。
