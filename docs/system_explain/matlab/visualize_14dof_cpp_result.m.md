# `matlab/visualize_14dof_cpp_result.m`

## 1. ファイルの目的

14DOF C++ シミュレーション結果 CSV を読み込み、軌跡・速度・姿勢・荷重を一枚の図に整理して可視化するスクリプトです。

## 2. 主な入出力または依存関係

- 入力: `../output/14dof_result.csv`
- 出力: 図表示
- 依存関係: `readtable`, `subplot`, `sgtitle`

## 3. 処理の流れ / アルゴリズム

1. CSV を読み込み、主要列を個別変数へ展開します。
2. 2x3 の subplot を作り、軌跡、縦速度、ヨー角、横加速度、各輪鉛直荷重、ロール/ピッチ角を描画します。
3. 最後に図全体タイトルを設定します。

## 4. ファイル内の定義

### スクリプト本体

- 軌跡だけは `plot(y, x)` としており、X 前方・Y 横方向の見え方を意識した配置です。
- ヨー角、ロール角、ピッチ角は degree に変換して表示します。
- 各輪荷重は `FL/FR/RL/RR` を同じ軸に重ねます。

## 5. 注意点・前提条件

- CSV パスは `matlab/` から見た相対 `../output/14dof_result.csv` に固定です。
- 保存処理はなく、対話的な確認用可視化です。
