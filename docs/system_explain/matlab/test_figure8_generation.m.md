# `matlab/test_figure8_generation.m`

## 1. ファイルの目的

8 の字トラック生成ロジックの幾何を素早く確認するための検証スクリプトです。

## 2. 主な入出力または依存関係

- 入力: スクリプト内固定の `radius=25`, `n_points=500`
- 出力: 図表示と主要点座標の標準出力
- 依存関係: `figure`, `plot`

## 3. 処理の流れ / アルゴリズム

1. 半周長 `pi*R` を使って全長を `2*pi*R` とし、8 の字 1 周分の弧長パラメータを作ります。
2. 初期姿勢を北向き、開始点を `(R,0)` として曲率積分で軌跡を生成します。
3. 終点を始点へ強制的に合わせて閉ループ化します。
4. 軌跡、開始点、上/下円中心、自己交差点を描画し、主要点座標を表示します。

## 4. ファイル内の定義

### スクリプト本体

- 関数化されていない単発検証コードです。
- `Midpoint`, `Quarter`, `3Quarter` の位置を出力し、期待する形状になっているかを人手確認します。

## 5. 注意点・前提条件

- 下位円/上位円の厳密な切替ロジックを持つ本番トラック生成関数とは別実装です。
- 終点を始点へ代入しているため、純粋な数値積分誤差は隠れます。
