# `matlab/test_skidpad_track.m`

## 1. ファイルの目的

Formula SAE スキッドパッドの幾何が期待通りかを数値と図で検証するスクリプトです。

## 2. 主な入出力または依存関係

- 入力: 固定半径 `R=9.125`
- 出力:
  - 標準出力の検証ログ
  - 図表示
  - `skidpad_verification.png`
- 依存関係: `figure`, `fill`, `plot`, `saveas`

## 3. 処理の流れ / アルゴリズム

1. 右円 1 周 + 左円 1 周で全長 `4*pi*R` の弧長 `s_vals` を作ります。
2. 前半は右円中心 `(R,0)` の時計回り、後半は左円中心 `(-R,0)` の反時計回りとして `x,y,theta,kappa` を計算します。
3. 開始点、交点、終点、方位連続性を標準出力で確認します。
4. 許容誤差判定から PASS/FAIL を出し、レイアウト図・方位図・曲率図を描いて PNG 保存します。

## 4. ファイル内の定義

### スクリプト本体

- 関数化されていない検証コードです。
- 右円と左円の接続点で heading jump が小さいかを特に確認しています。
- 灰色塗りつぶしで内外境界を描き、中心線が想定レーン内にあるか視覚確認できるようにしています。

## 5. 注意点・前提条件

- 合否閾値は `start_err < 0.1`, `cross_err < 0.5`, `close_err < 0.5`, `heading jump < 5deg` に固定です。
- 解析用スクリプトであり、シミュレータ本体のトラック生成コードを直接呼んでいるわけではありません。
