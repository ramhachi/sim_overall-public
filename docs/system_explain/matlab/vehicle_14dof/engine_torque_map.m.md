# engine_torque_map.m

## 目的
`engine_torque_map` は、エンジン回転数 `rpm` からトルク `Nm` を返す単機能関数です。コメントでは CBR600RR のトルクカーブとされ、C++ 実装と同一であることが明記されています。

## 入口とシグネチャ
```matlab
function torque = engine_torque_map(rpm)
```

### 入力
- `rpm`: エンジン回転数 `[rpm]`

### 出力
- `torque`: エンジントルク `[Nm]`

## 外部依存
外部関数への依存は `interp1` のみです。ファイル内ローカル関数はありません。

## 処理内容
1. `rpm_points` に 17 点の回転数テーブルを定義します。
2. `torque_points` に対応する 17 点のトルク値を定義します。
3. 入力 `rpm` が最小点 `3000` 未満なら、最初の値 `40.0` をそのまま返します。
4. 入力 `rpm` が最大点 `15000` を超えるなら、最後の値 `55.0` をそのまま返します。
5. 範囲内なら `interp1(..., 'linear')` による線形補間を行います。

## テーブル値
### 回転数点
`[3000, 4000, 5000, 6000, 7000, 8000, 9000, 10000, 11000, 11500, 12000, 12500, 13000, 13500, 14000, 14500, 15000]`

### トルク点
`[40.0, 45.0, 50.0, 54.0, 57.0, 59.5, 61.0, 62.0, 62.5, 62.7, 62.8, 62.7, 62.5, 61.8, 60.5, 58.0, 55.0]`

## 特徴
- 下限側と上限側は外挿ではなく定数保持です。
- 範囲内のみ線形補間です。
- スロットル開度やギア比の扱いはこの関数にはありません。単純に `rpm` から素のトルクを返します。

## 保存物・描画
保存処理も描画処理もありません。
