# run_stiff_model_comparison.m

## 目的
`run_stiff_model_comparison.m` は、高剛性化した 14DOF モデルに対して、RK4 の刻み幅依存性を比較するスクリプトです。タイトルには Rosenbrock 比較とありますが、実際の実行対象は RK4 の 3 刻み幅のみです。

## 入口
スクリプトです。ローカル関数はありません。

## 実行フェーズ
### 1. 初期化
- `clear; clc; close all;`
- タイトルを表示

### 2. 高剛性パラメータ設定
通常系より大きい定数を直接設定します。

#### 質量・慣性
通常系と同じです。

#### サスペンション高剛性化
コメントに増倍率が書かれています。
- `k_spring = [50000, 50000, 60000, 60000]`、2 倍
- `bw_c0 = 5000`、2.5 倍
- `bw_alpha = 3000`、2 倍
- `bw_A = 200`、2 倍
- `lugre_sigma0 = 50000`、5 倍
- `lugre_sigma1 = 50`、5 倍
- `k_arb_f = 10000`、2 倍
- `k_arb_r = 6000`、2 倍
- `bump_stop_gap = 0.02`
- `bump_stop_k = 500000`、5 倍

#### タイヤ高剛性化
- `Lx = 0.05`
- `Ly = 0.08`
- `Cx = 150000`
- `Cy = 120000`
- `k_tire = 1000000`
- `c_tire = 2000`

#### そのほか
- 空力とパワートレインは通常値
- 初速 `v0 = 15`

### 3. シミュレーション条件
- `t_span = [0, 3]`
- ステア開始 `0.5 s`
- 舵角 `0.15 rad`
- `input_func` は `throttle=0.1` と段差ステアを返します。

### 4. 剛性情報表示
`k_tire`、`c_tire`、`lugre_sigma0`、`k_spring` を標準系に対する倍率付きコメントどおりに表示します。

### 5. RK4 1ms 実行
- `dt1 = 0.001`
- `try` / `catch` 付きで `vehicle_14dof_model(...)` を実行
- 成功フラグ `rk4_1ms_ok`
- 失敗時は `ME.message` を表示し `time1 = NaN`

### 6. RK4 0.1ms 実行
- `dt2 = 0.0001`
- 成功フラグ `rk4_01ms_ok`

### 7. RK4 0.01ms 実行
- `dt3 = 0.00001`
- 成功フラグ `rk4_001ms_ok`

### 8. 結果比較
1ms と 0.1ms の両方が成功した場合だけ以降を進めます。
- 最終位置
- 最終速度
- 最大ロール角
- 計算時間
- 0.1ms を基準とした位置誤差 `err_pos`
- 0.1ms を基準としたロール誤差 `err_roll`
- 最終位置誤差

### 9. 描画
2 行 3 列の図を作ります。
1. 軌跡
2. ロール角
3. 前後速度
4. 位置誤差
5. 左前輪鉛直荷重 `data1.Fz(:,1)`
6. 計算時間棒グラフ

`rk4_001ms_ok` が真なら軌跡図と計算時間図に 0.01ms 系も含めます。

### 10. 画像保存
- `../../output/stiff_model_comparison.png`

### 11. 安定性評価
最大位置誤差 `max(err_pos)` により以下を表示します。
- `< 0.01`: 「1ms でも安定かつ高精度」「Rosenbrock 不要」
- `< 0.1`: 「目立つ誤差あり」「刻み幅縮小または Rosenbrock 検討」
- それ以上: 「有意な誤差」「Rosenbrock 推奨」

## 外部依存
- `vehicle_14dof_model`
- `interp1`
- `saveas`
- 描画系関数

## 注意点
- ファイル名とコメントは Rosenbrock を含みますが、コード上は Rosenbrock 系ソルバを呼びません。
- 0.01ms 系は比較の基準ではなく、成功した場合のみ参考として追加表示されます。
