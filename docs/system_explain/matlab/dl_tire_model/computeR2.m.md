# `matlab/dl_tire_model/computeR2.m`

## 1. 概要

`computeR2` は、実測値行列と予測値行列の各列について決定係数 `R²` を計算する関数です。

## 2. ファイルの役割

- 列ごとの `SS_res` と `SS_tot` を求め、`R² = 1 - SS_res / SS_tot` を返します。
- 出力次元ごとに独立した評価値を返します。
- 実測値が定数列で `SS_tot == 0` の場合は `NaN` を返します。

## 3. インターフェース

### 3.1 関数シグネチャ

```matlab
r2 = computeR2(y_actual, y_pred)
```

### 3.2 引数

- `y_actual`: `N×D` の実測値行列
- `y_pred`: `N×D` の予測値行列

### 3.3 戻り値

- `r2`: `1×D` の R² ベクトル

## 4. 依存関係

- MATLAB 標準関数: `size`, `sum`, `mean`, `zeros`, `error`

## 5. 処理の流れ

1. 2 つの入力の行数・列数が一致するか検証します。
2. 出力列数 `n_outputs` を取得し、結果ベクトルをゼロ初期化します。
3. 各列について残差平方和 `SS_res` を計算します。
4. 各列について全変動 `SS_tot` を計算します。
5. `SS_tot == 0` なら `NaN`、それ以外は `1 - SS_res / SS_tot` を格納します。

## 6. 関数・ローカル関数詳細

### 6.1 `computeR2`

- 列ループで実装されており、各出力次元を独立に扱います。
- コメントにある通り、負の R² もそのまま返します。

## 7. 注意点

- NaN/Inf を含む入力の前処理はしません。
- `SS_tot == 0` の場合は 0 ではなく `NaN` にしているため、後続の集計で特別扱いが必要です。
