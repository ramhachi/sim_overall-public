# `matlab/dl_tire_model/tmeasy_optimized_v2.m`

## 1. 概要

`tmeasy_optimized_v2.m` は、低荷重のコーナリング実測データを `Fz = 1000 N` 基準へ正規化し、その分布に合わせて TMeasy パラメータを再評価するスクリプトです。実データ集計、線形領域・飽和領域の推定、比較表、荷重依存確認、可視化を一通り実行します。

## 2. ファイルの役割

v1 相当の `tmeasy_optimized.m` よりも、データの実荷重分布を明示的に扱うのがこのスクリプトの役割です。`150〜200 N` のデータを選別し、`FY` を 1000N 基準に換算してからパラメータ推定とモデル比較を行います。

## 3. インターフェース

### スクリプトとしての入出力

- 入力ファイル
  - `../../data/tiredata/Cornering-Hoosier18.0×6.0-10-R20.csv`
- 出力
  - 標準出力への統計・比較表・推奨値
  - `../../output/tire_params/tmeasy_optimized_v2.png`

### 主要変数

- `Fz_ref = 1000`
  - 正規化先の基準荷重。
- `Fz_min = 150`, `Fz_max = 200`
  - 抽出対象荷重帯。
- `C_alpha = 45000`, `C_kappa = 80000`, `mu_x = 1.5`, `mu_y = 1.5`
  - 比較に使う固定パラメータ。

## 4. 依存関係

- MATLAB 組み込み
  - `detectImportOptions`, `readtable`, `polyfit`, `interp1`, `mean`, `std`, `figure`, `subplot`, `plot`, `errorbar`, `saveas`, `text`
- ローカル関数
  - `tmeasy_force_opt`
- 参照データ列
  - `FZ`, `FY`, `SA`, `SR`

## 5. 処理の流れ

### 5.1 実データ読み込みと荷重統計表示

1. コーナリング CSV を既定の列名で読み込みます。
2. `Fz_actual = -corn_data.FZ` として荷重統計を表示します。

### 5.2 1000N 基準への正規化

1. `150 < Fz_actual < 200` かつ `|SR| < 0.02` の行を抽出します。
2. `Fy_normalized = corn_filtered.FY .* (Fz_ref ./ (-corn_filtered.FZ))` により横力を基準荷重へ換算します。
3. `SA_bins = -12:1:12` ごとに平均、標準偏差、サンプル数を集計します。

### 5.3 線形域・飽和域からの推定

1. `0.5 < |SA| < 3.5` の点で線形回帰し、`C_alpha_estimate` を求めます。
2. `|SA| > 8` の点から `mu_y_estimate` を計算します。
3. これらの推定値を表示しますが、後段では固定値 `C_alpha=45000` などを使います。

### 5.4 実データとモデルの比較

1. `SA_test` の各角度について実データ値を `interp1(..., NaN)` で取得します。
2. `tmeasy_force_opt(0, SA, Fz_ref, ...)` でモデル `Fy` を計算します。
3. 実データがあり、かつ `|Fy_real| > 50` の場合は相対誤差[%]を、そうでなければ絶対差相当の値を `errors` に入れます。
4. 平均誤差を表示します。

### 5.5 条件別検証

1. `SR=0` のスリップ角スイープで `Fy` を表示します。
2. `SA=0` のスリップ率スイープで `Fx` を表示します。
3. 複数荷重で `SA=5°` の `Fy` と有効摩擦係数を表示します。

### 5.6 可視化と最終推奨出力

1. 実データ平均±標準偏差と TMeasy 曲線を重ねた `Fy-SA片` を描画します。
2. `Fx-SR` 曲線を描画します。
3. 摩擦楕円と複合スリップ点を描画します。
4. 図を `../../output/tire_params/tmeasy_optimized_v2.png` に保存し、最後に推奨パラメータを文章で表示します。

## 6. 関数・ローカル関数詳細

### スクリプト本体

- 低荷重測定値を高荷重基準へ換算してから比較している点が中心です。
- 実測分布の確認、推定、比較表、図出力までを 1 本のスクリプトで行います。

### `tmeasy_force_opt(SR, SA, Fz, C_kappa, C_alpha, mu_x, mu_y)`

- `SA` を rad に変換し、`Fx_lin = C_kappa * kappa`, `Fy_lin = -C_alpha * alpha` を計算します。
- 軸方向上限 `Fx_max = mu_x * Fz`, `Fy_max = mu_y * Fz` を使って摩擦上限を定義します。
- `ratio = F_lin_mag / F_max` に対し、`k = 1.8` の `tanh` 飽和で滑らかに遷移させます。
- 飽和後の `Fx`, `Fy` を各軸の上限内へクランプし、線形力がほぼ 0 なら両方 0 を返します。

## 7. 注意点

- 推定値 `C_alpha_estimate`, `mu_y_estimate` を算出しますが、最終比較では固定値が採用されています。
- `errors` 配列には条件により相対誤差[%]と絶対差相当値が混在するため、平均値の意味は一様ではありません。
- 正規化は `FY` のみで、元データの荷重帯は `150〜200 N` に限定されています。
