# `matlab/dl_tire_model/tmeasy_realistic_fitting.m`

## 1. 概要

`tmeasy_realistic_fitting.m` は、`500〜800 N` の現実的な荷重帯に絞って TMeasy パラメータを評価するスクリプトです。複数荷重レンジごとに `C_alpha` と `mu_y` を推定し、その傾向から推奨値と保守値を作成して検証します。

## 2. ファイルの役割

低荷重 200N データを外挿誤差の大きいデータとして扱い、より実用に近い荷重帯でのパラメータ同定を行うのがこのファイルの役割です。荷重依存性の確認、推奨値の決定、推奨値と保守値の誤差比較、可視化までを一括で実行します。

## 3. インターフェース

### スクリプトとしての入出力

- 入力ファイル
  - `../../data/tiredata/Cornering-Hoosier18.0×6.0-10-R20.csv`
- 出力
  - 標準出力への荷重帯別推定結果、推奨値、誤差比較、最終結論
  - `../../output/tire_params/tmeasy_realistic_fitting.png`

### 主要変数

- `Fz_ranges`
  - `[500,600]`, `[600,700]`, `[700,800]` の 3 荷重帯。
- `results`
  - 各荷重帯の `Fz_ref`, `C_alpha`, `mu_y`, `SA_valid`, `Fy_valid` を保存する構造体配列。
- `params_rec`, `params_cons`
  - 推奨パラメータと保守的パラメータ。

## 4. 依存関係

- MATLAB 組み込み
  - `detectImportOptions`, `readtable`, `polyfit`, `interp1`, `mean`, `std`, `floor`, `bar`, `saveas`
- ローカル関数
  - `tmeasy_force_calc`
- 参照データ列
  - `FZ`, `FY`, `SA`, `SR`

## 5. 処理の流れ

### 5.1 データ読み込みと荷重分布確認

1. コーナリング CSV を読み込みます。
2. `Fz_all = -corn_data.FZ` を作り、範囲・平均・中央値を表示します。

### 5.2 荷重帯ごとのデータ抽出と推定

1. `Fz_ranges` の各レンジについて、`|SR| < 0.02` の行を抽出します。
2. 各レンジの平均荷重を `Fz_ref` とします。
3. `FY` を `Fz_ref` 基準へ正規化します。
4. `SA_bins = -12:1:12` ごとに平均横力とサンプル数を計算します。
5. サンプル数が 10 を超えるビンだけを有効点とします。
6. `|SA| <= 2` の線形域で `C_alpha_rad` を推定します。
7. `|SA| > 8` の飽和域で `mu_y` を推定します。
8. 結果を `results(range_idx)` へ保存します。

### 5.3 荷重依存性の整理

1. `results` を表形式で表示します。
2. `C_alpha_all`, `mu_y_all`, `Fz_ref_all` を収集します。
3. `C_alpha` と `mu_y` の平均・標準偏差・範囲を表示します。

### 5.4 推奨値と保守値の作成

1. 中荷重帯 `results(2)` の `C_alpha` を推奨値の基準にします。
2. `mu_y_rec` は `mu_y_all` の平均です。
3. `C_kappa_rec = C_alpha_rec * 1.5`、`mu_x_rec = mu_y_rec * 0.9` と推定します。
4. 保守値は `floor` を使って切り下げ丸めを行います。

### 5.5 モデル検証

1. `test_idx = 2` として `600〜700N` 帯を検証用に使います。
2. `SA_test` 上で推奨モデルと保守モデルの `Fy` を計算します。
3. `MAE`, `MAPE`, `RMSE` を求めます。
4. 代表的な `SA = [-10, -5, 0, 5, 10]` で実データとの比較表を出力します。

### 5.6 可視化と最終結論

1. 荷重帯別実データと推奨・保守モデルの `Fy-SA` を描きます。
2. `SA=5°` における荷重依存性を描きます。
3. 推奨・保守の摩擦楕円を描きます。
4. 誤差指標を棒グラフで比較します。
5. 図を `../../output/tire_params/tmeasy_realistic_fitting.png` に保存し、最後に 14DOF 用推奨値を表示します。

## 6. 関数・ローカル関数詳細

### スクリプト本体

- 荷重帯を分けて推定結果を保持し、荷重依存性を見たうえで推奨値を組み立てます。
- `C_kappa_rec` と `mu_x_rec` はコメント通り推定値であり、直接観測から同定したものではありません。

### `tmeasy_force_calc(SR, SA, Fz, params)`

- `params` から `C_alpha`, `C_kappa`, `mu_x`, `mu_y` を参照して `Fx`, `Fy` を返します。
- 線形力計算、合力比 `ratio`、`k = 1.8` の `tanh` 飽和、各軸クランプという流れは他の TMeasy スクリプトと同系統です。
- `F_lin_mag <= 1e-6` のときは `Fx = 0`, `Fy = 0` を返します。

## 7. 注意点

- `results(2)` を必ず中荷重帯として参照しているため、2 番目のレンジで有効推定値が得られる前提があります。
- `Fz_ref_all` は収集されますが、後続の回帰やモデル化には使われません。
- `SA_valid` の有効条件は「サンプル数 10 超」なので、ビンの少ない角度は推定から外れます。
