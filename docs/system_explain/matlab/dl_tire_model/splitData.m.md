# `matlab/dl_tire_model/splitData.m`

## 1. 概要

`splitData` は、入力特徴量 `X` と教師信号 `Y` を訓練用と検証用に分割する関数です。分割前にサンプル数と分割比を検証し、乱順化したインデックスでデータをシャッフルします。

## 2. ファイルの役割

学習前処理の一部として、同じ行数を持つ `X` と `Y` をランダムに並べ替えたうえで、訓練集合と検証集合へ分ける役割を持ちます。再現性確保のため、乱数状態は `rng('default')` に固定されます。

## 3. インターフェース

### 関数シグネチャ

```matlab
[X_train, Y_train, X_val, Y_val] = splitData(X, Y, split_ratio)
```

### 引数

- `X`
  - `N×D` の入力特徴量行列。
- `Y`
  - `N×M` の出力ターゲット行列。
- `split_ratio`
  - 訓練用に使う割合。省略時は `0.8`。

### 戻り値

- `X_train`
  - 訓練用入力。
- `Y_train`
  - 訓練用出力。
- `X_val`
  - 検証用入力。
- `Y_val`
  - 検証用出力。

### エラー条件

- `split_ratio <= 0 || split_ratio >= 1`
  - `splitData:InvalidRatio`
- `size(X,1) ~= size(Y,1)`
  - `splitData:SizeMismatch`

## 4. 依存関係

- MATLAB 組み込み
  - `nargin`, `size`, `error`, `round`, `rng`, `randperm`, `fprintf`

## 5. 処理の流れ

1. 第 3 引数がなければ `split_ratio = 0.8` を設定します。
2. `split_ratio` が 0 と 1 の間にあるか確認し、範囲外ならエラーにします。
3. `size(X,1)` を基準に総サンプル数 `n_samples` を取得します。
4. `Y` の行数が `X` と一致するか確認し、不一致ならエラーにします。
5. `round(n_samples * split_ratio)` で訓練サンプル数 `n_train` を計算します。
6. `rng('default')` の後に `randperm(n_samples)` を使ってシャッフル順を生成します。
7. 先頭 `n_train` 件を訓練用、残りを検証用インデックスとして切り分けます。
8. それぞれのインデックスで `X` と `Y` を抽出し、4 つの出力を返します。
9. 最後に件数と比率を `fprintf` で表示します。

## 6. 関数・ローカル関数詳細

### `splitData`

- 入力と出力の対応関係を保ったまま、同一インデックスで `X` と `Y` を分割します。
- 乱数シードを `rng('default')` に固定しているため、同じ入力に対して毎回同じ分割結果になります。
- ローカル関数は定義されていません。

## 7. 注意点

- 毎回 `rng('default')` を呼ぶため、実行ごとのランダム分割を期待する用途には向きません。
- `round` を使っているため、総サンプル数によっては厳密に `split_ratio` 通りの件数にならない場合があります。
- 行方向をサンプルとみなす前提で実装されており、列方向サンプルの配列にはそのまま使えません。
