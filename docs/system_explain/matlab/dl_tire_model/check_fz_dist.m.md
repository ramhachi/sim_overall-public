# `matlab/dl_tire_model/check_fz_dist.m`

## 1. 概要

`check_fz_dist.m` は、指定した Cornering CSV 1 本を `loadTireData` で読み込み、`Fz` の統計量・ヒストグラム・`SA` レンジ・先頭 3 行を表示する確認用スクリプトです。

## 2. ファイルの役割

- `Fz` の実際の値域を数値で確認します。
- ヒストグラム相当の件数を 200 N 刻みで表示します。
- `SA` の最小値・最大値、およびテーブル先頭行を目視確認できるようにします。

## 3. インターフェース

### 3.1 種別

スクリプトです。引数や戻り値はありません。

### 3.2 主な入力

- `../../data/tiredata/csv/Cr_Hoosier_18p0X6p0-10_R20_Run027.csv`

### 3.3 主な出力

- 変数 `cr`: `loadTireData` で読み込んだテーブル
- コンソール出力
  - `Fz` の min/max/mean/median
  - `prctile` の 5/25/50/75/95 パーセンタイル
  - 200 N 刻みのヒストグラム件数
  - `SA` の min/max
  - 先頭 3 行

## 4. 依存関係

- プロジェクト関数: `loadTireData`
- MATLAB 標準関数: `fprintf`, `min`, `max`, `mean`, `median`, `prctile`, `histcounts`, `disp`

## 5. 処理の流れ

1. `data_dir` と対象 CSV パスを固定値で設定します。
2. `loadTireData` で 1 本の Cornering データを読み込みます。
3. `Fz` の基本統計量とパーセンタイルを表示します。
4. `edges = -2000:200:2000` でビン境界を作り、`histcounts` で件数を数えます。
5. 件数が 0 より大きいビンだけをループで表示します。
6. `SA` のレンジと、テーブル先頭 3 行を表示して終了します。

## 6. 関数・ローカル関数詳細

このファイルにローカル関数はありません。

### 6.1 ヒストグラム部

- ビン境界は固定で `-2000` から `2000` まで 200 N 刻みです。
- `if N(k)>0` の条件付きで表示しているため、空ビンは出力されません。

## 7. 注意点

- 入力ファイルは 1 本に固定されており、他の Run は集計しません。
- `loadTireData` が返す `Fz` の符号系をそのまま使うので、ここでは正値化していません。
- 可視化は作らず、すべてコンソール出力のみです。
