# `matlab/dl_tire_model/denormalizeData.m`

## 1. 概要

正規化済みデータを元スケールへ戻す単機能の関数です。  
Z-score 正規化の逆変換 `X = X_norm .* sigma + mu` をそのまま実装しています。

## 2. ファイルの役割

- 学習や推論後の正規化済み行列を、物理量の単位系へ戻します。
- `evaluateModel` など、予測結果を実値で評価したい処理から利用される前提の補助関数です。

## 3. インターフェース

### 関数 `X = denormalizeData(X_norm, mu, sigma)`

- 入力
  - `X_norm`: 正規化済みの `N×D` 行列
  - `mu`: 各列の平均値を持つ `1×D` ベクトル
  - `sigma`: 各列の標準偏差を持つ `1×D` ベクトル
- 出力
  - `X`: 元スケールへ戻した `N×D` 行列

## 4. 依存関係

- 外部関数呼び出しはありません。
- 要素ごとの乗算と加算だけで処理します。

## 5. 処理の流れ

1. `X_norm .* sigma` で列ごとに標準偏差を掛け戻します。
2. `+ mu` で列ごとに平均値を加え、元スケールの行列 `X` を返します。

## 6. 関数・ローカル関数詳細

### `denormalizeData(X_norm, mu, sigma)`

- ファイル内の唯一の関数です。
- 入力検証は行わず、MATLAB の暗黙拡張に任せて逆正規化を実行します。
- 実装は 1 行で、出力は常に `X_norm` と同じ行数を持ちます。

## 7. 注意点

- `mu` と `sigma` の列数が `X_norm` に対応していることを前提にしています。
- `sigma` に 0 が含まれていてもこの関数自体は検証しないため、上流で正規化パラメータの妥当性を担保する必要があります。
