# `matlab/dl_tire_model/computeRMSE.m`

## 1. 概要

`computeRMSE` は、実測値と予測値の差から列ごとの RMSE を計算する関数です。

## 2. ファイルの役割

- 残差平方を計算し、列平均の平方根を返します。
- 複数出力を持つ回帰モデルの列別評価に使えます。

## 3. インターフェース

### 3.1 関数シグネチャ

```matlab
rmse = computeRMSE(y_actual, y_pred)
```

### 3.2 引数

- `y_actual`: `N×D` の実測値行列
- `y_pred`: `N×D` の予測値行列

### 3.3 戻り値

- `rmse`: `1×D` の RMSE ベクトル

## 4. 依存関係

- MATLAB 標準関数: `size`, `mean`, `sqrt`, `error`

## 5. 処理の流れ

1. 2 入力の次元一致を確認します。
2. `(y_actual - y_pred).^2` で列ごとの二乗誤差行列を作ります。
3. `mean(..., 1)` で列平均を取り、`sqrt` で平方根を取って返します。

## 6. 関数・ローカル関数詳細

### 6.1 `computeRMSE`

- 実装は完全にベクトル化されており、列ループを使いません。
- 返り値は行ベクトルです。

## 7. 注意点

- 入力サイズ不一致時は即座に `error` を投げます。
- 欠損値処理や単位変換はこの関数の責務ではありません。
