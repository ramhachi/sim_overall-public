# `matlab/dl_tire_model/normalizeData.m`

## 1. 概要

`normalizeData` は、列ごとの平均と標準偏差を用いた Z-score 正規化を行う関数です。

## 2. ファイルの役割

- 入力行列の列平均を計算する
- 列標準偏差を計算する
- 標準偏差 0 の列を安全に処理する
- 正規化後行列と統計量を返す

## 3. インターフェース

### 関数

`[X_norm, mu, sigma] = normalizeData(X)`

### 引数

- `X`
  - `N×D` 行列。

### 戻り値

- `X_norm`
  - 正規化後の `N×D` 行列。
- `mu`
  - 各列平均の `1×D` ベクトル。
- `sigma`
  - 各列標準偏差の `1×D` ベクトル。

## 4. 依存関係

- MATLAB 標準関数
  - `mean`, `std`

## 5. 処理の流れ

1. `mean(X, 1)` で列平均 `mu` を計算する。
2. `std(X, 0, 1)` で列標準偏差 `sigma` を計算する。
3. `sigma == 0` の成分を `1` に置き換える。
4. `(X - mu) ./ sigma` で `X_norm` を計算する。

## 6. 関数・ローカル関数詳細

### `normalizeData`

- `std(X, 0, 1)` の第 2 引数 `0` により、標本標準偏差（`N-1` 正規化）を使います。
- 定数列はゼロ除算回避のため `sigma=1` に置換されるので、正規化後はその列全体が 0 になります。

### ローカル関数

- 定義されていません。

## 7. 注意点

- `NaN` や `Inf` の扱いは特別処理していません。
- 学習時と推論時で同じ `mu/sigma` を再利用する前提の基本関数です。
