# `matlab/dl_tire_model/detectOutOfRange.m`

## 1. 概要

生入力 `X_raw` が学習時レンジを外れていないかを判定し、外挿に関する警告文を作る関数です。  
5 特徴量 `SR, SA, Fz, IA, TSTC` を固定順で扱います。

## 2. ファイルの役割

- 推論前の入力妥当性確認を行います。
- 各サンプルがレンジ外かどうかの論理ベクトルと、特徴量別の要約警告文を返します。

## 3. インターフェース

### 関数 `[is_out_of_range, warnings] = detectOutOfRange(X_raw, input_ranges)`

- 入力
  - `X_raw`: 生特徴量の `N×5` 行列
  - `input_ranges`: 以下のフィールドを持つ構造体
    - `min`: 各特徴量の最小値 `1×5`
    - `max`: 各特徴量の最大値 `1×5`
    - `names`: 特徴量名のセル配列（省略可）
- 出力
  - `is_out_of_range`: いずれかの列がレンジ外であるサンプルを示す `N×1` logical
  - `warnings`: 特徴量別および全体要約の警告文セル配列

## 4. 依存関係

- `isfield`, `size`, `length`, `sum`, `min`, `max`, `sprintf` を使用します。
- 外部の独自関数には依存しません。

## 5. 処理の流れ

1. `input_ranges.names` が無ければ `{'SR','SA','Fz','IA','TSTC'}` を既定値として補います。
2. `X_raw` が 5 列か、`min/max` が 5 要素かを検証し、違反時は `error` を送出します。
3. サンプル数から `is_out_of_range` を `false` で初期化し、`warnings` を空セルで開始します。
4. 5 列を順に走査し、各列について最小未満・最大超過を検出します。
5. 1 列でもレンジ外なら、その行を `is_out_of_range` に反映します。
6. 最小未満・最大超過が存在する列ごとに、件数と実際の逸脱値を含む警告文を追加します。
7. 最後に全体件数と割合を集計した要約文を追加して返します。

## 6. 関数・ローカル関数詳細

### `detectOutOfRange(X_raw, input_ranges)`

- ファイル内唯一の関数です。
- 列ループは固定で 1～5 です。
- 警告文は「どの特徴量が、どれだけ、どの境界を越えたか」を `sprintf` で明示します。
- 全体要約は少なくとも 1 件レンジ外がある場合のみ追加されます。

## 7. 注意点

- 特徴量の順序は固定で、列並びが異なる行列には使えません。
- `warnings` はサンプルごとの詳細ではなく、特徴量単位の集計メッセージです。
- `names` の長さ自体は検証していないため、呼び出し側で整合を取るのが安全です。
