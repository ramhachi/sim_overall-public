# `matlab/merge_nested_structs.m`

## 1. ファイルの目的

ネストした構造体 `override` を `base` に再帰的に重ねるための汎用マージ関数です。

## 2. 主な入出力または依存関係

- 入力: `base`, `override`
- 出力: `out`
- 依存関係: 自己再帰呼び出しのみ

## 3. 処理の流れ / アルゴリズム

1. まず `out = base` とします。
2. `override` が空ならそのまま返します。
3. `override` が構造体でなければ、`out` 全体をその値で置き換えて返します。
4. 構造体なら各フィールドを走査し、双方 struct の時だけ再帰的にマージします。
5. それ以外は `override` 側の値で上書きします。

## 4. ファイル内の関数

### `merge_nested_structs(base, override)`

- 本ファイル唯一の関数です。
- 深い階層だけ部分更新し、葉ノードは override 優先で置換します。
- MATLAB の標準 `struct` マージでは扱いにくいネスト更新を簡潔に行うための補助です。

## 5. 注意点・前提条件

- 配列 struct や cell の中身までは再帰マージせず、葉として丸ごと置換します。
- `override` が struct でない場合は `base` を保たず完全置換になる点に注意が必要です。
