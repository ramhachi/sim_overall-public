# quarter_car_ode.m

## 概要
`quarter_car_ode` は、クォーターカー縦方向モデルを固定刻みの 4 次のルンゲクッタ法で積分し、状態履歴と各力の履歴を返す関数です。冒頭コメントでは「C++検証用 Ground Truth 生成」とされており、コードでも 1 ミリ秒刻みと手書きの `RK4` を採用して、`ode45` ではなく C++ 実装に合わせた積分手順を使っています。

## エントリポイントとシグネチャ
```matlab
function [t, x, data] = quarter_car_ode(params, t_span, x0, input_func)
```

## 入力
- `params`: パラメータ構造体です。コード上で参照される主なフィールドは `m_s`、`m_u`、`k_s`、`k_t`、`c0`、`alpha`、`A`、`beta`、`gamma`、`n` です。
- `t_span`: `[t_start, t_end]` 形式の時間範囲です。未指定時は `[0, 2]` です。
- `x0`: 初期状態ベクトルです。並びは `[z_s; z_u; dz_s; dz_u; z_bw]` です。未指定時は 5 要素すべて 0 です。
- `input_func`: 路面入力関数です。`@(t) z_road` の形を想定しています。未指定時は `t=0.2` 秒で `0.02` メートルへ切り替わるステップ入力です。

## 出力
- `t`: `t_span(1):0.001:t_span(2)` で生成される時刻ベクトルです。
- `x`: 各時刻の状態履歴です。列順は `[z_s, z_u, dz_s, dz_u, z_bw]` です。
- `data`: 追加データの構造体です。
  - `F_spring`: サスペンションばね力 `[N]`
  - `F_damper`: ダンパ力 `[N]`
  - `F_tire`: タイヤ力 `[N]`
  - `z_road`: 路面変位 `[mm]`。ここだけミリメートルへ変換して保存します。

## 既定値と前提
引数が不足したときは `nargin` で分岐し、`default_params()`、`[0, 2]`、`zeros(5,1)`、20 ミリメートルのステップ入力を順に補います。積分刻み `dt` は `0.001` 秒で固定です。コメントでも「C++ と同じ」と明記されています。

## 処理の流れ
1. 引数未指定分を既定値で補います。
2. `dt = 0.001` として時刻ベクトルを生成します。
3. `x` を `length(t) x 5` で確保し、初期状態を 1 行目へ代入します。
4. 各時刻区間で `k1` から `k4` を `dynamics` で計算し、`RK4` で次状態を更新します。
5. 積分後に全時刻を再走査し、各時刻の路面変位、ばね力、ダンパ力、タイヤ力を `data` へ格納します。

## 状態方程式
`dynamics` は状態を以下の 5 変数へ展開します。
- `z_s`: ばね上変位
- `z_u`: ばね下変位
- `dz_s`: ばね上速度
- `dz_u`: ばね下速度
- `z_bw`: Bouc-Wen 履歴変数

そのうえで次を計算します。
- 相対変位 `delta_s = z_s - z_u`
- 相対速度 `v_s = dz_s - dz_u`
- ばね力 `F_spring = p.k_s * delta_s`
- ダンパ力 `F_damper = bouc_wen_force(...)`
- 履歴変数微分 `dz_bw = bouc_wen_dz(...)`
- タイヤ力 `F_tire = p.k_t * (z_road - z_u)`

タイヤ力は `max(F_tire, 0)` によって 0 未満を切り捨てます。コメントにも「タイヤ離陸対応」とあります。加速度は
- `ddz_s = (-F_spring - F_damper) / p.m_s`
- `ddz_u = (F_spring + F_damper + F_tire) / p.m_u`

で計算され、最終的に `[dz_s; dz_u; ddz_s; ddz_u; dz_bw]` を返します。

## ローカル関数

### `default_params`
既定のパラメータ構造体を返します。設定値は次のとおりです。
- `m_s = 62.5`
- `m_u = 12.0`
- `k_s = 25000`
- `k_t = 200000`
- `c0 = 1500`
- `alpha = 5000`
- `A = 1`
- `beta = 500`
- `gamma = 100`
- `n = 2`

### `dynamics`
1 時刻の状態微分を返す関数です。Bouc-Wen モデルを含むサスペンション力と、非負制約付きのタイヤ力を組み合わせて 2 自由度系の運動方程式を構成します。

### `bouc_wen_force`
```matlab
F = p.c0 * v + p.alpha * z;
```
のみを実装しています。入力引数 `x` は関数定義にありますが、関数本体では使っていません。

### `bouc_wen_dz`
```matlab
dz = p.A * v - p.beta * abs(v) * z * abs_z_n_minus_1 - p.gamma * v * abs_z_n;
```
で履歴変数の微分を返します。`abs(z)^(p.n - 1)` と `abs(z)^n` を中間計算してから使います。

## 注意点
- `t` と `x` の変位・速度はメートル系のまま扱われますが、`data.z_road` だけはミリメートルへ変換されます。
- `input_func` は `RK4` の各段で同じ `z_road` 値を使っており、`k2`、`k3`、`k4` でも中間時刻で再評価していません。
