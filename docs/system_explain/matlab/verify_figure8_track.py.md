# `matlab/verify_figure8_track.py`

## 役割

- Figure-8 トラック生成が Phase 10 仕様どおりかを、**数値積分と可視化で検証する確認スクリプト**です。
- 半径固定の 8 の字中心線を生成し、閉ループ性と主要幾何点を目視・数値の両方でチェックします。

## 運用上の入口

### `generate_figure_eight_track(radius)`
- 中心線生成の主関数です。
- スクリプト下部で `radius = 25.0` を与えて直接呼び出しています。

## 主要関数

### `generate_figure_eight_track(radius)`
- **入力**: 円半径 `radius`
- **出力**: `x`, `y` の NumPy 配列
- **処理**:
  - 曲率 `kappa_ccw = 1/radius` を一定とする
  - 半円 2 つぶんの弧長を `n_points = 500` で積分
  - 初期姿勢 `theta = π/2`、初期位置 `(R, 0)` から逐次積分
  - 最終点を始点に強制一致させて閉ループ化

## 入出力・副作用

- **入力**: スクリプト内部の `radius=25.0`
- **出力**: `matlab/figure_eight_verification.png`
- **標準出力**: 始終点、閉ループ誤差、トラック長、交点情報
- **副作用**: PNG 保存

## データフロー

1. 半径から曲率と弧長を定義
2. 数値積分で中心線座標列を生成
3. 始点・終点・円中心・自己交差点を重ねて描画
4. 画像保存と検証メトリクス表示

## システム内での位置づけ

- Figure-8 コース生成仕様の妥当性を確認する**設計検証用スクリプト**です。
- コース生成アルゴリズムを本体へ組み込む前に、幾何学的前提が崩れていないかを確認する役割を持ちます。
