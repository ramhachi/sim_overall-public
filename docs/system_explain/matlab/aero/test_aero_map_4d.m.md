# `matlab/aero/test_aero_map_4d.m`

## 役割

このスクリプトは、`aero_map_4d` クラスのグリッド、係数傾向、力計算、簡易妥当性判定を確認するテスト兼可視化スクリプトです。  
5 つの数値テストと 6 枚のプロット、最後の検証判定を一括実行します。

## 実行入口

- スクリプトです。
- `clear; clc; close all;` で初期化します。

## 外部依存

- `addpath('../aero')`
- `aero_map_4d`
- `deg2rad`
- `rad2deg`
- `saveas`

このスクリプトは冒頭で `../aero` をパス追加してから `aero_map_4d()` を生成します。

## 実行フェーズ

### 1. クラス生成とグリッド表示

`aero = aero_map_4d();` を実行し、以下を表示します。

- フロント RH 点数と範囲
- リア RH 点数と範囲
- ロール点数と範囲
- ヨー点数と範囲

### 2. テスト 1: 基準条件

条件は固定です。

- `rh_f = 40`
- `rh_r = 55`
- `roll = 0`
- `yaw = 0`
- `velocity = 20`

`get_coeffs` と `compute_forces` の結果から

- `CL`, `CD`, `CY`
- `CoP_x`, `CoP_dist`
- `Fz`, `Fx`, `Fy`
- `Fz_front`, `Fz_rear`

を表示します。

### 3. テスト 2: ライドハイト効果

`rh_test = [25, 35, 45, 55]` を用い、リア RH を 55 mm 固定にしてフロント RH だけを変えます。  
各点で `CL` と `Fz` を表示します。

### 4. テスト 3: ロール効果

`roll_test = [0, 2.5deg, 5deg]` で `CL` を比較します。  
基準係数 `coef_base.CL` に対し、

```matlab
loss = (1 + c.CL/coef_base.CL) * 100
```

を `loss` として表示します。  
この値はコード上の定義そのままで、通常の「減少率」という名前とは式の形が異なります。

### 5. テスト 4: ヨー効果

`yaw_test = [0, 5, 10, 15]` 度で

- `CL`
- `CD`
- `CY`

を表示します。

### 6. テスト 5: 速度スイープ

`v_test = [10, 15, 20, 25, 30]` で

- `Fz`
- `Fx`

を表示します。

### 7. プロット生成

`figure('Position', [50, 50, 1400, 800])` で 2 行 3 列の図を作ります。

1. フロント RH と `CL`
2. ロール角と `CL`
3. ヨー角に対する `CL`, `CD`
   - `yyaxis` を使用
4. ヨー角に対する `CY`
5. 速度に対するダウンフォースとドラッグ
   - `-Fz`, `-Fx` を描いて正の量として表示
6. `roll=0`, `yaw=0` の `CL` 等高線図

#### プロット用スイープ

- `rh_f_vec = linspace(20, 60, 20)`
- `roll_vec = deg2rad(linspace(-5, 5, 20))`
- `yaw_vec = deg2rad(linspace(-15, 15, 30))`
- `v_vec = linspace(5, 35, 30)`

最後に `../../output/aero_map_4d_test.png` へ保存します。

### 8. 検証判定

`passed = true` から始め、次の 3 条件を順にチェックします。

#### CL 範囲

基準条件の `coef.CL` が

- `-4 < CL < -1`

なら合格です。

#### 地面効果

- `c_low = get_coeffs(25, 40, 0, 0)`
- `c_high = get_coeffs(55, 75, 0, 0)`

を比較し、`c_low.CL < c_high.CL` なら「低 RH の方がより大きいダウンフォース」と判定します。

#### ダウンフォース符号

基準条件の `forces.Fz < 0` を確認します。

3 条件すべて合格なら `4D Aero Map test PASSED`、1 つでも失敗なら `FAILED` を表示します。

## 補足

- このスクリプトにローカル関数はありません。
- 出力の多くはコンソール表示と図保存で、MAT ファイルや CSV の保存は行いません。
