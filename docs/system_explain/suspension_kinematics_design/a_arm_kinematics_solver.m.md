# a_arm_kinematics_solver.m

## 概要
- `a_arm_kinematics_solver` は、ダブルウィッシュボーン式サスペンションのハードポイントから静的幾何特性を解析的に算出する中核関数です。
- 上下アーム端点・ホイール中心・タイヤ半径を受け取り、キャンバー、キャスター、KPI、スクラブ半径、ロールセンター、瞬間中心、キャンバーゲインをまとめて返します。
- `main_a_arm_optimizer.m` と `main_rear_a_arm_optimizer.m` の目的関数評価で直接利用されます。

## 関数シグネチャ
```matlab
function results = a_arm_kinematics_solver(hardpoints)
```

## 入力
- `hardpoints`: 構造体
  - `U_F`, `U_R`, `U_U`: 上側 A アームのシャシー前側・後側・アップライト側点 `[X; Y; Z]`
  - `L_F`, `L_R`, `L_U`: 下側 A アームのシャシー前側・後側・アップライト側点 `[X; Y; Z]`
  - `W_C`: ホイール中心
  - `R_tire`: タイヤ荷重半径 `[m]`
  - `is_left`: 左右判定。左輪なら `true`、右輪なら `false`
  - `Spindle_Dir`（任意）: 静的キャンバー判定用スピンドル方向ベクトル

## 出力
- `results`: 構造体
  - `camber_deg`: 静的キャンバー角 `[deg]`
  - `caster_deg`: キャスター角 `[deg]`
  - `kpi_deg`: キングピン傾角 `[deg]`
  - `scrub_radius_m`: スクラブ半径 `[m]`
  - `roll_center_z`: ロールセンター高さ `[m]`
  - `IC_y`, `IC_z`: フロントビュー瞬間中心座標
  - `camber_gain_rad_m`: 簡易キャンバーゲイン `[rad/m]`

## 実行フロー

### 1. 入力点の抽出
- `U_U`、`L_U`、`W_C`、`is_left`、`R_tire` を構造体から取り出します。
- シャシー側は `U_C = (U_F + U_R) / 2`、`L_C = (L_F + L_R) / 2` とし、前後 2 点をフロントビュー用の中点へ圧縮します。
- 以降のロールセンター計算は、この中点とアップライト点を結んだ 2D 直線モデルで進みます。

### 2. キングピン軸の構築
- `K_vec = U_U - L_U` を上向きベクトルとして作り、`K_dir = K_vec / norm(K_vec)` で正規化します。
- さらに `K_down = L_U - U_U` を作って下向き表現も保持し、キャスターと KPI の符号計算に使います。
- `norm` が極端に小さい場合の専用保護は無く、上下ボールジョイントが重なる入力は想定外です。

### 3. キャスター角の計算
- `atan2d(K_down(1), K_down(3))` で X-Z 平面内の傾きを角度化します。
- コメントにもある通り、下側ジョイントが上側より前方にある場合を正キャスターと解釈しています。
- 座標系は SAE の `Z down` なので、通常の上向き Z 座標系と直感が逆になる点に注意が必要です。

### 4. KPI の計算
- KPI は Y-Z 平面内のキングピン傾きです。
- 左輪では `atan2d(-K_down(2), K_down(3))`、右輪では `atan2d(K_down(2), K_down(3))` を使い、「上側が車体中心寄りなら正」という定義を左右で揃えています。
- `is_left` が誤っていると KPI の符号解釈が崩れます。

### 5. 接地点とスクラブ半径の計算
- `TCP = W_C` を起点にし、`TCP(3) = TCP(3) + R_tire` として地面上のタイヤ接地点を作ります。
- Z-down 系では地面方向が正なので、ホイール中心より接地点の Z は大きくなります。
- キングピン軸と接地面の交点 `pierce_pt` を求め、接地点との Y 差をスクラブ半径として返します。
- 左右で内向きを正にするため、左輪と右輪で差分の取り方を変えています。

### 6. 瞬間中心とロールセンターの計算
- 上側リンクの投影方向 `dir_up`、下側リンクの投影方向 `dir_low` を Y-Z 平面で作ります。
- `A \ b` を解いて 2 本の直線交点を瞬間中心 `IC_y`, `IC_z` として求めます。
- 瞬間中心と接地点を結ぶ線が車両中心線 `Y = 0` と交わる Z をロールセンター高さとします。
- `det(A)` がほぼ 0 のときは平行リンクとみなし、`IC_y = sign(dir_up(1)) * 1e6` の無限遠近似へ切り替えます。

### 7. 静的キャンバーの計算
- `Spindle_Dir` が入力されていればそれを使います。
- 無ければ左輪で `[0; -1; 0]`、右輪で `[0; 1; 0]` を仮スピンドル方向として採用します。
- `asind(spindle(3))` によってスピンドルの鉛直成分からキャンバー角を求めます。
- そのため、`Spindle_Dir` を与えない単独利用ではキャンバーは 0 度相当になりやすい実装です。

### 8. キャンバーゲインの近似計算
- `bump_travel = -0.025` と固定し、25 mm のバンプを仮定します。
- `L_sa = TCP(2) - results.IC_y` をスイングアーム長の近似値とし、`camber_change_rad = bump_travel / L_sa` を計算します。
- これを `bump_travel` で割って `camber_gain_rad_m` に変換します。
- 右輪では符号を反転し、左右反転形状でも解釈が揃うようにしています。

## 関数本体の責務
- ハードポイントを単一の評価指標集合へ変換すること
- 左右輪の符号規約を KPI・スクラブ半径・キャンバーゲインへ反映すること
- 最適化器が扱いやすい連続値の幾何評価を返すこと

## 主要ロジックの要点
- 入力は 3D ですが、ロールセンターまわりは Y-Z 平面へ投影した簡略モデルです。
- キャンバーゲインは厳密なリンク拘束解ではなく、瞬間中心ベースの近似です。
- 平行リンク時には瞬間中心を無限遠扱いする特例があります。

## 外部依存
- MATLAB 組み込み関数: `norm`, `atan2d`, `asind`, `det`
- 線形代数演算: `A \ b`

## 前提・注意点
- 座標系は SAE J670e の `X 前 / Y 右 / Z 下` を前提にしています。
- タイロッドやアップライト剛体の完全拘束はモデル化していません。
- `K_dir(3)` や `L_sa` が極端に小さい場合の数値安定化は限定的です。
- 上下ボールジョイントが重なるような異常形状は想定していません。
