# tire_fitting/model_selector.py

## 役割
複数のタイヤモデル候補から、縦力・横力ごとに最適モデルを選ぶ判定器です。

## 主なクラス
- `SelectionMode`
- `ModelSelector`

## 選定ロジック
- まず RMSE 最小
- RMSE 差が 5% 未満なら TIC を優先
- さらに接戦なら R² を参照する前提でログを残す

## 背景
縦力と横力の支配現象は異なるため、単一モデル固定より方向別選択のほうが合理的です。本ファイルはその意思決定ルールを明文化します。

## 入出力
- 入力: モデル別の `rmse/tic/r2`
- 出力: `(fx_model, fy_model)` の選択結果

## パイプライン上の位置
複数モデル同定結果をハイブリッド構成へ落とし込む判断層です。
