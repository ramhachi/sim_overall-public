# tire_fitting/models/hybrid.py

## 役割
縦力モデルと横力モデルを別々に保持し、1 つのタイヤモデルとして見せるラッパです。

## 主な内容
- `fx_model` と `fy_model` を保持
- `calculate_fx()`/`calculate_fy()` を各サブモデルへ委譲
- `get_model_type()` で構成を文字列化
- `set_parameters()` で方向別パラメータ更新

## 背景
縦と横で最適モデルが異なるという、このプロジェクトの重要な設計思想を具現化するクラスです。

## パイプライン上の位置
選択結果を実際の実行可能モデルへ変換する統合層です。
