# frame_optimize/tests/test_node_var.m

## 役割

`generate_parametric_nodes.m` の設計変数が、最小値側と最大値側でどのように節点配置を変えるかを確かめる簡易テストです。

## 確認していること

- 最小境界と最大境界の 2 ケースで節点を生成する
- 節点数がどう変わるかを表示する
- FH 上端や SI 上端の座標が期待どおり変わるかを見る
- 先頭 23 節点の差分から、基本骨格の変位量をざっくり確認する

## 実装上の意味

最適化は連続形状変数と離散トグルを同時に扱うため、節点生成が壊れると全体が止まります。このスクリプトはその最初の安全確認として役立ちます。
