# frame_optimize/cpp/beam_fem_server.cpp

## 役割

現在のフレーム最適化で **標準バックエンド** として使われる TCP サーバーです。MATLAB 側の `beam_fem_solver_tcp_java.m` から JSON を受け取り、3D ティモシェンコ梁 FEM を解いて結果を返します。

## 受け付けるコマンド

- `SOLVE`: 節点・要素・拘束・荷重を解く
- `PING`: 生存確認
- `SHUTDOWN`: 停止要求

## 解法の中身

- 円管 / 角管の断面特性を計算
- 要素ごとに 12x12 局所剛性を作る
- 回転行列で全体座標へ変換
- 疎行列を組み立てて `SparseLU` で解く
- 直接トルクまたは左右の Fz カップルからねじり剛性を推定する

## 実装上の特徴

- 16 ワーカースレッドの簡易スレッドプールを持つ
- Eigen は `setNbThreads(1)` で内側並列を止め、過剰並列を避ける
- BFS で拘束点から到達不能な節点を見つけ、浮遊部分を強制拘束して特異行列を避ける

## 位置づけ

MEX 版と計算の芯は近いですが、**現行ワークフローではこのサーバー版が主役** です。
