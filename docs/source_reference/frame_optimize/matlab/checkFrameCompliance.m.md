# frame_optimize/matlab/checkFrameCompliance.m

## 役割

FSAE 2026 規則に対する簡易コンプライアンス判定器です。フレーム要素のグループ名を手掛かりに、必要サイズ、材料制限、アルミ肉厚、必須構造の有無をまとめて評価します。

## 何を検査するか

- サイズクラス適合 (`F.3.4.1`)
- 材料制限 (`F.3.2.1`)
- アルミ材の最小板厚
- `main_hoop` と `front_hoop` の存在

## 出力

- `pass`: すべて合格なら true
- `penalties`: 合計罰則値
- `report`: 違反内容を `size_violations` などに分けた詳細構造体

## 現在の位置づけ

この関数は **規則チェックの独立ユーティリティ** です。現行の EasyStart 最適化経路では `frameObjectiveFunction` から直接は呼ばれていません。したがって「今の最適化がこの関数で完全に規則準拠している」とは読まず、**手動検証・将来統合用の部品** と理解すると分かりやすいです。
