# frame_optimize/matlab/verify_suspension_geometry.m

## 役割

`load_suspension_hardpoints.m` の座標変換が正しいかを 3D 図で目視確認する補助スクリプトです。最適化本体ではなく、前側サスペンション取付点の妥当性確認用です。

## 何を表示するか

- FBH の矩形
- 8 個の前側シャシー取付点
- アップライト点
- 左右 A アームを模した接続線
- 地面平面

## 使いどころ

サスペンション JSON を更新したときや、FBH オフセットの意味を確かめたいときに使います。`generate_parametric_nodes.m` が返す節点配置の前提確認として便利です。

## 実装上の注意

読み込む JSON パスは最適化本体とは少し異なり、可視化専用の固定参照になっています。実運用の最適化ループには入りません。
