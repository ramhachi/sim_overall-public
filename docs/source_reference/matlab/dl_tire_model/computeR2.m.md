# computeR2.m

## 概要
実測値と予測値から決定係数 R² を計算する評価関数です。各出力次元ごとに 1×D のスコアを返します。

## 主要関数・クラス
- `computeR2(y_actual, y_pred)`

## 理論・背景
R² は分散説明率を表す代表的な回帰指標で、1 に近いほど良好です。Fx、Fy、Mx、Mz の各チャネルについて個別評価することで、どの物理量が苦手かを切り分けられます。

## 外部ライブラリ・ツールボックス
- MATLAB 標準数値演算

## 入出力
- 入力: `y_actual`, `y_pred`
- 出力: `1×D` の R² 配列

## システム上の役割
`evaluateModel` の基礎評価関数として使われ、比較レポートや可視化へ定量指標を供給します。
