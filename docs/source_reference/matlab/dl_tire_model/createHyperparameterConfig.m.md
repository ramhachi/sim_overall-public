# createHyperparameterConfig.m

## 概要
名前付き引数からハイパーパラメータ設定構造体を組み立てる補助関数です。グリッド探索とランダム探索の両方で再利用しやすい統一設定を作ります。

## 主要関数・クラス
- `createHyperparameterConfig(varargin)`
- Name-Value 形式の入力を解釈して構造体化

## 理論・背景
探索コードでは設定項目が増えやすく、ベタ書きでは実験再現性が低下します。本関数は設定を一元化し、ログ保存・比較・再学習を容易にします。

## 外部ライブラリ・ツールボックス
- MATLAB 標準引数処理

## 入出力
- 入力: 任意個の Name-Value ペア
- 出力: 学習率、バッチサイズ、エポック数、モデル種別などを含む構造体

## システム上の役割
探索スクリプト群の設定生成入口です。人手入力ミスを減らし、実験ログとの対応を明確化します。
