# loadExperimentLog.m

## 概要
実験 ID を指定して保存済みログを読み込む関数です。探索結果の再解析や比較表生成に使われます。

## 主要関数・クラス
- `loadExperimentLog(experiment_id, log_dir)`

## 理論・背景
探索実験は多数の設定と結果を伴うため、後から個別試行を再参照できることが重要です。本関数はログファイル配置を抽象化し、呼び出し側の実装を簡潔にします。

## 外部ライブラリ・ツールボックス
- MATLAB 標準 I/O

## 入出力
- 入力: 実験 ID、ログディレクトリ
- 出力: 設定、指標、学習情報を含むログ構造体

## システム上の役割
`compareExperiments` や分析スクリプトの基礎読込関数です。探索結果の追跡性を支えます。
