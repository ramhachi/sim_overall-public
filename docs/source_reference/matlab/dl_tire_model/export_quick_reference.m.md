# export_quick_reference.m

## 概要
エクスポート関連機能の使い方を短くまとめたリファレンス用スクリプトです。実行例と典型コマンドを素早く参照できます。

## 主要関数・クラス
- スクリプト形式の使用例集
- `exportModel`、`exportForCpp`、`exportModelForCpp` などの呼び出し例

## 理論・背景
エクスポート手段が複数あるため、用途別の使い分けを即座に思い出せる資料が必要です。研究コードから実運用コードへの橋渡し手順を簡潔に整理する目的があります。

## 外部ライブラリ・ツールボックス
- 文書・サンプルコード中心

## 入出力
- 入力: なし
- 出力: 参照情報、サンプル手順

## システム上の役割
新規利用者向けの導線です。エクスポート系 API の入口として機能します。
