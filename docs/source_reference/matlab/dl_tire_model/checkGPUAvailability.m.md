# checkGPUAvailability.m

## 概要
学習実行前に GPU の利用可否を判定し、利用可能な場合はデバイス情報を収集する関数です。GPU が使えないときは CPU 実行へ自動的にフォールバックします。

## 主要関数・クラス
- `checkGPUAvailability()`
- 戻り値として `gpu_available` と `gpu_info` 構造体を返します。

## 理論・背景
深層学習の学習時間は計算資源に大きく依存します。本関数は実行環境の差異を吸収し、同じスクリプトを GPU 環境でも CPU 環境でも安全に走らせるためのハードウェア抽象化層として機能します。

## 外部ライブラリ・ツールボックス
- Parallel Computing Toolbox
- GPU 非搭載時は MATLAB 標準機能のみで継続可能

## 入出力
- 入力: なし
- 出力:
  - `gpu_available`: 論理値
  - `gpu_info`: 名称、インデックス、計算能力、総メモリ、空きメモリを持つ構造体

## システム上の役割
`trainTireModel` や検証スクリプトの前段で実行され、訓練設定の実行環境を決定します。学習失敗時の原因切り分けにも役立つ診断関数です。
