# computeInputRanges.m

## 概要
学習入力行列から各特徴量の最小値と最大値を算出し、入力レンジ構造体を返す関数です。学習領域の境界を明示化します。

## 主要関数・クラス
- `computeInputRanges(X_train)`
- `min`、`max`、特徴名をまとめた構造体を返却

## 理論・背景
ニューラルネットは学習レンジ外で予測精度が低下しやすいため、推論時には学習領域を明示的に管理する必要があります。本関数は外挿検出や C++ 側の安全策の基礎情報を作ります。

## 外部ライブラリ・ツールボックス
- MATLAB 標準配列演算

## 入出力
- 入力: `X_train`（`N×5`）
- 出力: 最小値、最大値、特徴量名を含む構造体

## システム上の役割
`detectOutOfRange` やエクスポート処理に渡す境界情報の生成を担当します。学習・推論の一貫した有効範囲管理に必要です。
