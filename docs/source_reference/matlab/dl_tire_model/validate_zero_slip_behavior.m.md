# validate_zero_slip_behavior.m

## 概要
ゼロスリップ条件 `SR=0, SA=0` 付近で、力・モーメントが十分小さいことを確認する検証スクリプトです。物理整合性を直接点検します。

## 主要関数・クラス
- スクリプト形式または検証関数
- ゼロ近傍入力での予測評価

## 理論・背景
ゼロスリップで大きな力が出るモデルは物理的に不自然で、車両シミュレーションでも不安定化要因になります。データ拡張や学習の効果を確認するうえで重要な性質試験です。

## 外部ライブラリ・ツールボックス
- MATLAB 標準機能

## 入出力
- 入力: 学習済みモデルまたはデータ
- 出力: ゼロスリップ妥当性の判定結果

## システム上の役割
物理制約に関する重要な品質ゲートです。最終検証の一部を構成します。
