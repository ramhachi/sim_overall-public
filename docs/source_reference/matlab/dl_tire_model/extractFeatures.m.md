# extractFeatures.m

## 概要
読込済みデータテーブルから学習入力特徴量を抽出し、`N×5` 行列 `[SR, SA, Fz, IA, TSTC]` を返す関数です。

## 主要関数・クラス
- `extractFeatures(data)`

## 理論・背景
ネットワークへの入力順序は学習・推論の両方で厳密一致が必要です。本関数は特徴量抽出順を固定し、後段処理の整合性を確保します。

## 外部ライブラリ・ツールボックス
- MATLAB 標準テーブル操作

## 入出力
- 入力: `table` 形式のタイヤデータ
- 出力: `N×5` 数値行列

## システム上の役割
`preprocessData` の中核ユーティリティです。データ層から学習層への変換を担当します。
