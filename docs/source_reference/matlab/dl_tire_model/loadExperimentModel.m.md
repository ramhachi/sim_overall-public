# loadExperimentModel.m

## 概要
実験 ID に対応する学習済みモデルを読み込む関数です。探索後に特定試行のモデルを再評価・再利用できます。

## 主要関数・クラス
- `loadExperimentModel(experiment_id, model_dir)`

## 理論・背景
最良モデルだけでなく、比較対象モデルも含めて後から再評価できることは研究再現性に不可欠です。本関数は保存規約に従って対象モデルを一意に復元します。

## 外部ライブラリ・ツールボックス
- MATLAB 標準ファイル読み込み

## 入出力
- 入力: 実験 ID、モデル保存先
- 出力: 学習済みネットワークと関連付随情報

## システム上の役割
探索と評価をつなぐ関数です。比較図生成やベストモデルの再エクスポートで利用されます。
