# tmeasy_parameter_fitting.m

## 概要
TMeasy モデルのパラメータ同定を実行する標準ワークフローです。実測データに合わせて古典モデルを調整します。

## 主要関数・クラス
- スクリプト形式または関数形式のフィッティング処理
- 誤差関数評価
- 最適化ルーチン呼び出し

## 理論・背景
TMeasy は少ないパラメータでタイヤの代表的挙動を表現できるため、DNN と比較するベースラインとして有用です。パラメータ同定により、実測に合わせた現実的な古典モデルが得られます。

## 外部ライブラリ・ツールボックス
- Optimization Toolbox

## 入出力
- 入力: タイヤ試験データ
- 出力: TMeasy パラメータ、誤差評価

## システム上の役割
古典モデル比較の標準実装です。DNN 導入効果の定量比較に欠かせません。
