# loadAndPredict.m

## 概要
保存済みモデルを読み込み、生の入力特徴量に対して一度に予測を返す簡便推論関数です。実運用に近い単発 API として使えます。

## 主要関数・クラス
- `loadAndPredict(model_path, X_raw)`
- 内部でモデル読込、正規化、予測、逆正規化を実施

## 理論・背景
利用者が毎回モデル読込や前後処理を個別実装すると、正規化ミスやファイル形式差異が起きやすくなります。本関数は推論手順を単純化し、再現性ある利用を促します。

## 外部ライブラリ・ツールボックス
- Deep Learning Toolbox

## 入出力
- 入力: モデルパス、`N×5` の生入力
- 出力: `N×4` の予測値 `[Fx, Fy, Mx, Mz]`

## システム上の役割
MATLAB 側の標準推論入口です。`main_prediction_workflow` や検証スクリプトから再利用されます。
