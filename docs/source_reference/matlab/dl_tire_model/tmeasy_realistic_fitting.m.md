# tmeasy_realistic_fitting.m

## 概要
物理的制約を加えながら TMeasy パラメータを同定するスクリプトです。数学的適合だけでなく、物理妥当性を重視します。

## 主要関数・クラス
- スクリプト形式
- 制約付き最適化
- 物理妥当性の確認

## 理論・背景
単純な誤差最小化だけでは、非現実的なパラメータに収束することがあります。本スクリプトは拘束条件を導入し、ピーク摩擦や剛性が物理的に解釈可能な範囲に収まるようにします。

## 外部ライブラリ・ツールボックス
- Optimization Toolbox

## 入出力
- 入力: タイヤ試験データ、制約条件
- 出力: 制約付き同定結果

## システム上の役割
古典モデルの信頼性を高めるための上位版です。比較ベースラインの品質向上に使われます。
