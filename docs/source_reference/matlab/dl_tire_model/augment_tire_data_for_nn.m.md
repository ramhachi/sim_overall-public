# augment_tire_data_for_nn.m

## 概要
DriveBrake と Cornering の CSV を対象に、ニューラルネット学習向けの拡張データを生成するスクリプトです。ゼロスリップ点の合成追加と対称性の付与により、低スリップ域と符号反転挙動の学習を安定させます。

## 主要関数・クラス
- 主処理はスクリプト形式で実行されます。
- 典型的には `SR=0`、`SA=0` の人工サンプル追加と、符号反転データの複製・整形を行います。

## 理論・背景
タイヤモデルでは、ゼロスリップ近傍で力が滑らかにゼロへ近づくこと、また横力・縦力が奇関数的な対称性を近似的に持つことが重要です。実測データだけではその近傍が疎になりやすいため、学習バイアスを減らす目的で拡張を行います。

## 外部ライブラリ・ツールボックス
- MATLAB 標準機能のみ
- 外部ツールボックス依存は想定されません

## 入出力
- 入力: DriveBrake CSV、Cornering CSV
- 出力: 拡張済みデータセット、または後続学習で利用可能な整形テーブル

## システム上の役割
学習前のデータ品質改善を担う前処理補助です。特にゼロスリップ挙動や左右対称性の再現性を高め、後段の `trainTireModel` の収束性改善に寄与します。
