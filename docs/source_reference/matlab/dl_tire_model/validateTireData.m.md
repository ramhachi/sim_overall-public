# validateTireData.m

## 概要
読込済みタイヤデータの整合性と基本統計を確認し、検証構造体として返す関数です。

## 主要関数・クラス
- `validateTireData(data)`

## 理論・背景
学習前に列欠落、異常値、分布の偏りを把握しておくと、後の不具合切り分けが容易になります。本関数はそのための標準データ監査口です。

## 外部ライブラリ・ツールボックス
- MATLAB 標準統計機能

## 入出力
- 入力: タイヤデータテーブル
- 出力: 検証結果構造体、統計情報

## システム上の役割
データ品質保証の入口です。学習・同定・可視化の前段で使われます。
