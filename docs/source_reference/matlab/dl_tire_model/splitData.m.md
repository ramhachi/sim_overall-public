# splitData.m

## 概要
前処理済みデータを学習用と検証用に分割する関数です。記述上は層化分割を意図した役割を持ちます。

## 主要関数・クラス
- `splitData(X, Y, split_ratio)`

## 理論・背景
学習と評価を分離しないと、過学習を見抜けません。分割比率を明示的に管理することで、異なる実験間で比較可能な検証条件を維持できます。

## 外部ライブラリ・ツールボックス
- MATLAB 標準配列操作

## 入出力
- 入力: 特徴量 `X`、教師 `Y`、分割比率
- 出力: `X_train`, `Y_train`, `X_val`, `Y_val`

## システム上の役割
前処理パイプラインの終端です。評価の信頼性を支える基本関数です。
