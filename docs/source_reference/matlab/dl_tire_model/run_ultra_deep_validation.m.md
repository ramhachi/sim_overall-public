# run_ultra_deep_validation.m

## 概要
8 隠れ層の非常に深いネットワークを用い、長めの学習で深さの効果を検証するスクリプトです。一般に 400 エポック前後の高負荷実験を想定します。

## 主要関数・クラス
- スクリプト形式
- `createVeryDeepTireModel`
- 学習、詳細評価、モデル保存

## 理論・背景
深いネットワークがタイヤの高次非線形性をより良く表現できるかを検証するための実験です。一方で過学習や学習不安定性も増すため、性能だけでなく訓練挙動の観察も重要になります。

## 外部ライブラリ・ツールボックス
- Deep Learning Toolbox

## 入出力
- 入力: 学習データ、超深層向け設定
- 出力: 超深層モデル、性能レポート

## システム上の役割
高精度候補の性能上限を探る研究用スクリプトです。最終採用モデルの候補評価にも使われます。
