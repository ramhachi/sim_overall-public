# loadTireData.m

## 概要
TTC タイヤ試験 CSV を読み込み、必要列を統一したテーブルとして結合するデータ読込関数です。DriveBrake と Cornering の異なるヘッダ形式を判別して処理します。

## 主要関数・クラス
- `loadTireData(data_paths)`
- `detectImportOptions`
- `readtable`
- 列名統一処理（`FX→Fx`、`FY→Fy`、`FZ→Fz` など）

## 理論・背景
試験装置由来の CSV は形式差や列名ゆれを含みます。この段階で共通スキーマ `SR, SA, Fz, IA, TSTC, Fx, Fy, Mx, Mz` にそろえることで、後段の前処理や学習コードを簡潔に保てます。読込時に必須列を検証するため、データ欠損を早期発見できる点も重要です。

## 外部ライブラリ・ツールボックス
- MATLAB 標準テーブル I/O

## 入出力
- 入力: CSV パスのセル配列
- 出力: 必須 9 列を持つ統合テーブル

## システム上の役割
パイプライン最上流のデータ入口です。ほぼすべての学習・検証・古典モデル同定がこの関数に依存します。
