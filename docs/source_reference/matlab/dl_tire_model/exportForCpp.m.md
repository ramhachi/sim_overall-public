# exportForCpp.m

## 概要
学習済み MATLAB モデルを C++ シミュレータへ統合するための包括的エクスポート関数です。モデル読込から 5 次元ルックアップテーブル生成、正規化係数保存、C++ ヘッダ生成、検証用テストデータ出力までを一括実行します。

## 主要関数・クラス
- `exportForCpp(model_path, output_dir, grid_config)`
- 内部補助:
  - 正規化係数のテキスト書き出し
  - C++ ヘッダ生成
  - テストデータ生成
  - ルックアップテーブル CSV 展開

## 理論・背景
MATLAB の学習済みネットワークをそのまま C++ で推論するより、所定レンジ上で事前計算した 5D ルックアップテーブルを使うほうが、実装単純性・実行速度・依存削減の面で有利です。本関数はその橋渡しとして、補間前提の静的データ形式へ変換します。正規化係数も同時に埋め込むことで、MATLAB 側と C++ 側の数値整合性を保ちます。

## 外部ライブラリ・ツールボックス
- Deep Learning Toolbox
- MATLAB 標準ファイル I/O

## 入出力
- 入力:
  - `model_path`: `.mat` 形式の学習済みモデル
  - `output_dir`: 出力先ディレクトリ
  - `grid_config`: SR、SA、Fz、IA、TSTC の範囲と分割数
- 出力:
  - ルックアップテーブル `.mat`
  - `normalization_params.txt`
  - `dl_tire_model.hpp`
  - `test_data.csv`
  - 各軸配列 CSV、各出力グリッド CSV

## システム上の役割
MATLAB 学習パイプラインと C++ 車両シミュレータを接続する中核関数です。学習成果を実運用側へ受け渡す最終工程であり、オフライン高精度モデルをオンライン高速推論へ変換します。
