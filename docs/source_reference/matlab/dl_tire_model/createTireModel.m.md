# createTireModel.m

## 概要
標準のフィードフォワード型タイヤモデルを生成する既定アーキテクチャ関数です。構成は `5→128→64→32→4` で、入力 5 特徴から 4 出力を直接回帰します。

## 主要関数・クラス
- `createTireModel()`
- `featureInputLayer`
- `fullyConnectedLayer`
- `reluLayer`
- `dropoutLayer`
- `regressionLayer`

## 理論・背景
静的なタイヤ状態量から力・モーメントを直接近似する多層パーセプトロンであり、前処理後の表形式データに対して扱いやすい構成です。過度に複雑でないため、ベースラインとして比較しやすい点が利点です。

- 入力: なし
- 出力: 回帰用 `layerGraph`

本ディレクトリの既定モデルです。多くの学習・検証・推論スクリプトが、この構成を出発点として利用します。
