# exportNetworkWeights.m

## 概要
ニューラルネットワークの重みパラメータをテキスト形式へ書き出す関数です。外部実装で層構造を再現する際の基礎データを生成します。

## 主要関数・クラス
- `exportNetworkWeights(trained_net, output_path)`

## 理論・背景
ネットワーク移植では、学習済みパラメータを透明な形式で保持できることが重要です。テキスト出力により、C++ 実装やデバッグ時に値を直接検査できます。

## 外部ライブラリ・ツールボックス
- Deep Learning Toolbox

## 入出力
- 入力: 学習済みネットワーク、出力パス
- 出力: 重みテキストファイル

## システム上の役割
低レベル移植用ユーティリティとして、`exportModelForCpp` の構成要素を担います。
