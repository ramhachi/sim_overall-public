# main_prediction_workflow.m

## 概要
保存済みモデルを読み込み、入力データに対して予測を行う実運用向けのサンプルワークフローです。モデル利用側の最短経路を示します。

## 主要関数・クラス
- スクリプト形式
- `loadAndPredict`
- 必要に応じて結果の可視化や保存

## 理論・背景
学習と推論のコードを分離することで、利用者は学習詳細を意識せず推論だけを実行できます。本スクリプトは運用側で必要な最低限の流れを定型化します。

## 外部ライブラリ・ツールボックス
- Deep Learning Toolbox

## 入出力
- 入力: モデルファイル、予測対象入力
- 出力: 予測結果、必要に応じて出力ファイル

## システム上の役割
MATLAB 内での本番利用例です。モデル利用者向けの入口として機能します。
