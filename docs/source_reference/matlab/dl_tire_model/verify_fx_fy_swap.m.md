# verify_fx_fy_swap.m

## 概要
データ列や推論結果において Fx と Fy が入れ替わっていないか確認する整合性チェックです。重大なデータ配線ミスを防ぎます。

## 主要関数・クラス
- スクリプト形式の整合性検証
- 符号、分布、条件依存性を用いた確認

## 理論・背景
Fx/Fy の取り違えは、見た目には学習できていても物理的には全く別のモデルになる危険な不具合です。本チェックはそのようなサイレントエラーを早期発見するために重要です。

## 外部ライブラリ・ツールボックス
- MATLAB 標準機能

## 入出力
- 入力: データまたは予測結果
- 出力: 入れ替わり有無の判定、警告

## システム上の役割
データ整合性保証の重要項目です。`extractTargets` や可視化結果の妥当性確認と密接に関係します。
