# computeRMSE.m

## 概要
実測値と予測値の二乗平均平方根誤差 RMSE を計算する関数です。出力次元ごとに誤差の大きさを物理単位のまま評価できます。

## 主要関数・クラス
- `computeRMSE(y_actual, y_pred)`

## 理論・背景
RMSE は大きな誤差を強く罰するため、ピーク域や外れ予測の影響を把握しやすい指標です。タイヤ力モデルでは Fx と Fy が支配的になりやすいため、モーメント成分と併せて確認することが重要です。

## 外部ライブラリ・ツールボックス
- MATLAB 標準数値演算

## 入出力
- 入力: `y_actual`, `y_pred`
- 出力: `1×D` の RMSE 配列

## システム上の役割
モデル比較の主要 KPI です。学習中の性能監視、最終評価、古典モデルとのベンチマーク比較に使われます。
