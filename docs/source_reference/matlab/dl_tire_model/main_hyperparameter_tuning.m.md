# main_hyperparameter_tuning.m

## 概要
データ前処理から探索空間定義、グリッド探索またはランダム探索、比較レポート生成、最良構成での再学習までを一貫して行うメインスクリプトです。

## 主要関数・クラス
- スクリプト形式の探索全体制御
- `preprocessData`
- `runHyperparameterSearch`
- `compareExperiments`
- `createModelFromConfig`
- `trainTireModel`

## 理論・背景
ネットワーク精度は学習率、バッチサイズ、深さ、ドロップアウトなどに大きく依存します。本スクリプトは探索手順を標準化し、設定空間の系統的比較と最良候補の再現可能な抽出を実現します。最後に最良設定で改めて学習し直すことで、探索結果をそのまま成果物へ接続できます。

## 外部ライブラリ・ツールボックス
- Deep Learning Toolbox
- MATLAB 標準 I/O

## 入出力
- 入力: データパス、探索種別、探索空間、出力先
- 出力: 実験ログ群、比較レポート、最良モデル

## システム上の役割
研究段階のモデル改善を推進する上位ワークフローです。通常学習よりも広い設計空間を探索し、性能向上のための意思決定を支援します。
