# removeMissingData.m

## 概要
入力行列と教師行列から NaN や Inf を含む行を除去し、除去統計も返す関数です。学習前の最低限のクリーニングを担います。

## 主要関数・クラス
- `removeMissingData(X, Y)`

## 理論・背景
欠損や無限大を含むサンプルは、学習発散や評価不整合の直接原因になります。本関数は行単位で不良データを排除し、どの程度データが失われたかも可視化します。

## 外部ライブラリ・ツールボックス
- MATLAB 標準論理演算

## 入出力
- 入力: 特徴量行列 `X`、教師行列 `Y`
- 出力: クリーン後の `X`, `Y`、除去件数などの統計

## システム上の役割
前処理パイプラインの安全弁です。学習不安定化要因を初期段階で除去します。
