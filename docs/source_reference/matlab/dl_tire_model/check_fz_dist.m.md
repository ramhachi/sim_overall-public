# check_fz_dist.m

## 概要
Cornering 系 CSV に含まれる鉛直荷重 `Fz` の分布を調べる解析スクリプトです。ヒストグラムと統計量を通じて、学習データの荷重帯が偏っていないか確認します。

## 主要関数・クラス
- スクリプトとして実行
- `Fz` の最小値、最大値、平均、分位点などを集計
- ヒストグラムを生成して分布を可視化

## 理論・背景
タイヤ力は荷重依存性が強く、`Fz` 分布の偏りはモデルの汎化性能に直接影響します。特定荷重域にサンプルが集中すると、外挿時の誤差やゼロ近傍での不安定性が生じやすくなります。

## 外部ライブラリ・ツールボックス
- MATLAB 標準可視化機能

## 入出力
- 入力: Cornering CSV
- 出力: コンソール統計、ヒストグラム図

## システム上の役割
前処理前のデータ監査ツールです。学習前に荷重レンジの不足や偏在を検出し、再サンプリングやデータ拡張の判断材料を提供します。
