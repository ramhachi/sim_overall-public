# detectOutOfRange.m

## 概要
推論入力が学習レンジ外にあるかを判定する関数です。各サンプルの論理配列と警告情報を返し、危険な外挿を可視化します。

## 主要関数・クラス
- `detectOutOfRange(X_raw, input_ranges)`

## 理論・背景
データ駆動モデルは補間には強くても外挿には弱い傾向があります。入力が学習時の `min-max` を外れる場合、予測値は物理的に不自然になりうるため、事前警告が重要です。

## 外部ライブラリ・ツールボックス
- MATLAB 標準機能

## 入出力
- 入力:
  - `X_raw`: 生入力
  - `input_ranges`: 各特徴量の許容レンジ
- 出力:
  - 範囲外判定の論理配列
  - 警告メッセージや要約情報

## システム上の役割
推論安全性を補強する関数です。MATLAB 側だけでなく C++ エクスポート時の使用域設計にも間接的に寄与します。
