# run_export_for_cpp.m

## 概要
重み・バイアス・正規化係数をテキスト形式でまとめて出力するバッチスクリプトです。内部で `exportModelForCpp` を呼びます。

## 主要関数・クラス
- スクリプト形式
- `exportModelForCpp`

## 理論・背景
ネットワークを C++ で直接再実装するケースでは、低レベルなパラメータ出力が必要です。本スクリプトはその反復作業を簡単にします。

## 外部ライブラリ・ツールボックス
- Deep Learning Toolbox

## 入出力
- 入力: モデルファイル、出力先
- 出力: テキスト形式のモデル構成要素

## システム上の役割
ルックアップテーブル以外の統合方式を支える補助ワークフローです。
