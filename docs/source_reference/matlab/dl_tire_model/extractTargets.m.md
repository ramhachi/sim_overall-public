# extractTargets.m

## 概要
タイヤデータテーブルから教師信号を抽出し、`N×4` 行列 `[Fx, Fy, Mx, Mz]` を返す関数です。

## 主要関数・クラス
- `extractTargets(data)`

## 理論・背景
出力順序も入力と同様に厳密な一貫性が必要です。特に Fx と Fy の取り違えは重大な物理破綻を招くため、明示的な抽出関数で順序を固定する意義があります。

## 外部ライブラリ・ツールボックス
- MATLAB 標準テーブル操作

## 入出力
- 入力: `table` 形式のタイヤデータ
- 出力: `N×4` 数値行列

## システム上の役割
教師データ生成の標準入口です。`evaluateModel` や検証スクリプトの基礎となります。
