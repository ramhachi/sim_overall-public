# run_separated_training.m

## 概要
Cornering 用モデルと DriveBrake 用モデルを分けて学習するスクリプトです。データ混在によるバイアスを抑えることを目的とします。

## 主要関数・クラス
- スクリプト形式
- データ分離
- 個別モデル学習
- 個別評価

## 理論・背景
純横力中心のデータと純縦力・複合スリップ中心のデータを単一モデルに混在させると、片方の性能が犠牲になることがあります。分離学習はその干渉を減らす代替戦略です。

## 外部ライブラリ・ツールボックス
- Deep Learning Toolbox

## 入出力
- 入力: Cornering / DriveBrake データ、学習設定
- 出力: 分離学習済みモデル群、比較評価

## システム上の役割
データ構成に起因する精度問題を調べるための実験スクリプトです。混合学習との比較材料を提供します。
