# visualization_quick_reference.m

## 概要
可視化関数群の目的と呼び出し方を簡潔に整理したリファレンスです。

## 主要関数・クラス
- `generateAllVisualizations`
- `generateScatterPlots`
- `generateResidualPlots`
- `generateTimeSeriesPlots`
- `generateOperatingConditionPlots`

## 理論・背景
可視化は目的に応じて適切な図を選ぶことが重要です。本資料は、どの図がどの失敗モードの発見に向くかを素早く参照できるようにします。

## 外部ライブラリ・ツールボックス
- 文書・サンプルコード中心

## 入出力
- 入力: なし
- 出力: 関数一覧、用途別の参照情報

## システム上の役割
評価結果の解釈を支援するナビゲーション文書です。
