# run_final_validation.m

## 概要
総合検証関数 `final_system_validation` を実行する起動用スクリプトです。最終チェックを定型手順として呼び出します。

## 主要関数・クラス
- スクリプト形式
- `final_system_validation`

## 理論・背景
最終検証を定期的に実行するためには、入口を簡単にしておくことが重要です。本スクリプトは標準検証ルートを明示します。

## 外部ライブラリ・ツールボックス
- Deep Learning Toolbox

## 入出力
- 入力: 通常なし
- 出力: 総合検証レポート

## システム上の役割
品質保証工程の起動点です。モデル更新時の確認作業を簡易化します。
