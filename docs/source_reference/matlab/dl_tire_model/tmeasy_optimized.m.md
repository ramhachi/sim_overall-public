# tmeasy_optimized.m

## 概要
実測データから TMeasy パラメータを最適化するスクリプトです。特に `Fz≈1000N` 近傍を重視した実データ適合を狙います。

## 主要関数・クラス
- スクリプト形式
- TMeasy パラメータ推定
- 実測との誤差評価

## 理論・背景
TMeasy は比較的簡潔で実装しやすい古典タイヤモデルです。本スクリプトは代表荷重帯での整合性を高め、DNN や Magic Formula とのベンチマークに使えるようにします。

## 外部ライブラリ・ツールボックス
- Curve Fitting Toolbox
- MATLAB 標準数値演算

## 入出力
- 入力: 実測タイヤデータ
- 出力: 最適化済み TMeasy パラメータ、適合結果

## システム上の役割
古典モデル比較の一角を担います。軽量モデルの実用性評価に使われます。
