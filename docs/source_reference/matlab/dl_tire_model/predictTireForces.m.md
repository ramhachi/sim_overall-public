# predictTireForces.m

## 概要
生入力特徴量を受け取り、内部で正規化・ネットワーク予測・逆正規化を行って `Fx, Fy, Mx, Mz` を返す推論関数です。

## 主要関数・クラス
- `predictTireForces(net, X_raw, norm_params)`

## 理論・背景
推論利用者が正規化手順を意識せずに済むよう、前後処理を関数内へ閉じ込めています。これにより、学習時と推論時のスケーリング不一致を防げます。

## 外部ライブラリ・ツールボックス
- Deep Learning Toolbox

## 入出力
- 入力: 学習済みネットワーク、生入力、正規化係数
- 出力: 物理単位に復元された予測値

## システム上の役割
MATLAB 側の共通推論 API です。可視化、検証、ルックアップテーブル生成でも再利用されます。
