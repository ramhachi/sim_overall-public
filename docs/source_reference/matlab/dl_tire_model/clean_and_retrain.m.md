# clean_and_retrain.m

## 概要
データ洗浄と再学習を一体で実行する再構築用スクリプトです。異常値や不整合を除去したうえでモデルを作り直し、データ品質が性能へ与える影響を評価します。

## 主要関数・クラス
- スクリプト形式の再学習パイプライン
- データ読込、フィルタリング、モデル生成、学習、評価を連続実行

## 理論・背景
タイヤ試験データは欠損、外れ値、条件混在の影響を受けやすく、単純学習では誤差構造をそのまま学習してしまいます。本スクリプトは前処理を強化したうえで再学習し、品質起因の誤差を切り分けることを目的とします。

## 外部ライブラリ・ツールボックス
- Deep Learning Toolbox
- 必要に応じて統計・可視化機能

## 入出力
- 入力: 元の TTC データ、前処理条件、学習設定
- 出力: クリーン化済みモデル、評価指標、可視化、再学習ログ

## システム上の役割
通常学習で性能が出ない場合の改善ルートです。データ品質問題への対処実験を担い、基準モデルとの差分評価にも使われます。
