# exportModelForCpp.m

## 概要
学習済みモデルを C++ で直接読み込めるテキスト部品へ分解して出力する関数です。重み、バイアス、正規化係数を個別ファイルとして保存します。

## 主要関数・クラス
- `exportModelForCpp(model_path, output_dir)`
- 出力対象: 重み行列、バイアス、正規化情報

## 理論・背景
ルックアップテーブル方式ではなく、ネットワークそのものを C++ で再構築したい場合には、各層パラメータの明示的な書き出しが必要です。本関数はそのための低レベルエクスポートを行います。

## 外部ライブラリ・ツールボックス
- Deep Learning Toolbox
- MATLAB 標準 I/O

## 入出力
- 入力: `.mat` モデル、出力ディレクトリ
- 出力: 各層の重み・バイアス・正規化係数テキスト

## システム上の役割
`exportForCpp` とは異なる統合手段を提供します。C++ 側で推論器を自作する場合や、ネットワーク構造の詳細検証に向きます。
