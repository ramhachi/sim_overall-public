# exportMagicFormulaForCpp.m

## 概要
Magic Formula 5.2 の同定結果を C++ で扱いやすいテキスト形式へ変換する関数です。ベンチマーク用の古典モデルを MATLAB 外へ持ち出す用途に使います。

## 主要関数・クラス
- `exportMagicFormulaForCpp(mat_path)`
- MF 5.2 パラメータ群をテキスト出力

## 理論・背景
深層学習モデルとの比較には、同一 C++ 環境で古典モデルも再現できることが重要です。MF パラメータを書き出すことで、同じシミュレータ内で速度・精度・安定性の比較が可能になります。

## 外部ライブラリ・ツールボックス
- MATLAB 標準 I/O

## 入出力
- 入力: Magic Formula 同定結果を含む `.mat`
- 出力: MF 5.2 パラメータのテキストファイル

## システム上の役割
比較モデルの C++ 展開を担う補助関数です。DNN 優位性の検証や退避用モデル実装に利用されます。
