# main_training_workflow.m

## 概要
本ディレクトリにおける主要な学習エントリポイントです。CSV 読込、前処理、モデル作成、学習、評価、可視化、モデル保存、要約レポート出力までを順番に実行します。

## 主要関数・クラス
- スクリプト形式の全体制御
- `preprocessData`
- `createModelFromConfig`
- `trainTireModel`
- `evaluateModel`
- `generateAllVisualizations`
- `exportModel`

## 理論・背景
実験コードが分散すると再現性が低下するため、本スクリプトは標準学習手順を一本化しています。入力 5 特徴、出力 4 物理量という共通前提のもと、学習から成果物整理までを一続きの工程として扱います。途中工程ごとに例外処理を持ち、失敗箇所を切り分けやすくしている点も特徴です。

## 外部ライブラリ・ツールボックス
- Deep Learning Toolbox
- MATLAB 標準可視化・I/O

## 入出力
- 入力: データファイル群、学習設定、出力ディレクトリ
- 出力:
  - 学習済み `.mat` モデル
  - `tire_model_latest.mat`
  - 可視化画像群
  - 学習サマリーテキスト
  - コンソール進行ログ

## システム上の役割
通常開発で最も重要な上位ワークフローです。新規モデル作成の基準手順を定め、他の実験系スクリプトの参照元になります。
