# compareExperiments.m

## 概要
複数のハイパーパラメータ探索結果を比較し、表形式のレポートを生成する関数です。最良モデル候補の識別に使われます。

## 主要関数・クラス
- `compareExperiments(experiment_ids, log_dir, output_file)`
- 実験ログを読み込み、比較表と最良 ID を抽出

## 理論・背景
探索では単一指標だけでなく、RMSE、R²、訓練時間、安定性など複数軸で比較する必要があります。本関数は散在するログを統一形式に集約し、再現可能な比較基盤を提供します。

## 外部ライブラリ・ツールボックス
- MATLAB 標準 I/O

## 入出力
- 入力:
  - `experiment_ids`: 比較対象の実験 ID 配列
  - `log_dir`: ログ保存先
  - `output_file`: 比較結果の出力先
- 出力: 比較テーブル、最良モデル ID

## システム上の役割
`main_hyperparameter_tuning` の後段で、試行結果を意思決定可能な形に整えます。多数実験の整理と追跡性の確保を担う管理系ユーティリティです。
