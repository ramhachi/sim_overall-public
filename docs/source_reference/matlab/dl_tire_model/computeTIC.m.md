# computeTIC.m

## 概要
Theil Inequality Coefficient（TIC）を計算する関数です。0〜1 の無次元指標で予測誤差を正規化して評価します。

## 主要関数・クラス
- `computeTIC(y_actual, y_pred)`

## 理論・背景
TIC はスケール差のある出力を比較しやすい利点があります。力とモーメントが混在する本パイプラインでは、RMSE のような絶対値尺度と併用することで、チャネル間の公平な比較がしやすくなります。

## 外部ライブラリ・ツールボックス
- MATLAB 標準数値演算

## 入出力
- 入力: `y_actual`, `y_pred`
- 出力: `1×D` の TIC 値

## システム上の役割
`evaluateModel` の補助評価指標です。スケール不変な品質判定を可能にし、ハイパーパラメータ探索時の比較にも向きます。
