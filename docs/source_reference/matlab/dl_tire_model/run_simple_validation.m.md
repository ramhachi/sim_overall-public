# run_simple_validation.m

## 概要
比較的保守的な設定で安定性重視の検証を行うスクリプトです。通常は 300 エポック程度で基本モデルの収束確認を狙います。

## 主要関数・クラス
- スクリプト形式
- 標準モデル生成
- 学習、評価、保存

## 理論・背景
複雑な改良よりも、まず基準モデルが安定して学習できることを確認することが重要です。本スクリプトは深さや特殊設定を増やし過ぎない安定検証枠です。

## 外部ライブラリ・ツールボックス
- Deep Learning Toolbox

## 入出力
- 入力: 学習データ、標準設定
- 出力: 安定性確認済みの評価結果

## システム上の役割
ベースライン検証として使われます。改良版検証との比較基準を提供します。
