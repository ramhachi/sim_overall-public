# run_cpp_export.m

## 概要
学習済みモデルに対して C++ 向けルックアップテーブル一式のエクスポートを実行するバッチスクリプトです。内部で `exportForCpp` を呼び出します。

## 主要関数・クラス
- スクリプト形式
- `exportForCpp`

## 理論・背景
定型的な C++ 連携作業をワンコマンド化することで、運用手順を簡略化します。設定済み格子を用いる定常的なエクスポートに向きます。

## 外部ライブラリ・ツールボックス
- Deep Learning Toolbox

## 入出力
- 入力: モデルファイル、出力先、必要に応じて格子設定
- 出力: C++ 連携用成果物一式

## システム上の役割
実務上のエクスポート手順を簡易化するラッパーです。頻繁な再エクスポートの負担を減らします。
