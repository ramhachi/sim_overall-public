# preprocessDataWrapper.m

## 概要
入力がファイルパスでも既存テーブルでも扱えるようにした柔軟版前処理ラッパーです。呼び出し元のデータ形式差を吸収します。

## 主要関数・クラス
- `preprocessDataWrapper(data_input, config)`
- 内部で `preprocessData` または同等処理を呼び分け

## 理論・背景
実験コードでは、すでにメモリ上にあるテーブルを再利用したい場合と、CSV から読み直したい場合が混在します。本関数はその差異を隠蔽し、前処理ロジックの重複を避けます。

## 外部ライブラリ・ツールボックス
- MATLAB 標準機能

## 入出力
- 入力: テーブルまたはファイルパス群、設定構造体
- 出力: 学習・検証データと正規化係数

## システム上の役割
前処理 API の柔軟化担当です。試験的スクリプトや分析ノートブックからの再利用性を高めます。
