# generateTimeSeriesPlots.m

## 概要
実測値と予測値をサンプル系列に沿って並べ、時間的または並び順的な一致度を可視化する関数です。必要に応じて区間指定やサブセット表示に対応します。

## 主要関数・クラス
- `generateTimeSeriesPlots(Y_actual, Y_pred, output_dir, varargin)`

## 理論・背景
系列表示は、局所的な追従遅れ、ピークの取りこぼし、符号反転時の不連続などを確認しやすい特徴があります。特に連続した試験ランを扱う場合に有効です。

## 外部ライブラリ・ツールボックス
- MATLAB 標準可視化機能

## 入出力
- 入力: 実測値、予測値、保存先、任意オプション
- 出力: 時系列比較図

## システム上の役割
点群評価では見えにくい連続挙動を検査する補助可視化です。過渡応答やラン単位の癖の確認に使われます。
