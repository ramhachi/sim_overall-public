# run_quick_validation.m

## 概要
データ量やエポック数を抑えて短時間で健全性確認を行う簡易検証スクリプトです。通常は 50 エポック以下でのサニティチェック用途です。

## 主要関数・クラス
- スクリプト形式
- 簡易学習、簡易評価、基本可視化

## 理論・背景
重い学習を始める前に、データ読込や学習設定に致命的な問題がないかを短時間で確認することは重要です。本スクリプトはそのための高速な入口です。

## 外部ライブラリ・ツールボックス
- Deep Learning Toolbox

## 入出力
- 入力: データ、簡易設定
- 出力: 短時間の評価結果

## システム上の役割
実験前の初期確認を担います。環境構築直後の動作確認にも向きます。
