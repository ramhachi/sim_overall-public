# check_symmetry.m

## 概要
タイヤデータが期待される反対称性を満たしているか確認する検証スクリプトです。代表的には `Fy(SA) ≈ -Fy(-SA)`、`Fx(SR) ≈ -Fx(-SR)` を比較します。

## 主要関数・クラス
- スクリプト形式の対称性チェック
- 近い条件同士を比較し、誤差や偏差を集計

## 理論・背景
理想化したタイヤ応答では、左右・前後のスリップ符号に対して奇関数的な応答が期待されます。実測ではノイズや試験条件差があるため完全一致はしませんが、大きく崩れている場合は学習データの整合性に問題がある可能性があります。

## 外部ライブラリ・ツールボックス
- MATLAB 標準機能

## 入出力
- 入力: タイヤ試験データ
- 出力: 対称性評価結果、誤差指標、必要に応じて確認用図

## システム上の役割
データ品質確認の一部として、物理的に不自然な偏りを早期に発見する役割を持ちます。`augment_tire_data_for_nn` の効果確認にも有用です。
