# saveExperimentModel.m

## 概要
実験 ID と結びつけて学習済みモデルを保存する関数です。探索結果と成果物を一対一で対応付けます。

## 主要関数・クラス
- `saveExperimentModel(trained_net, norm_params, experiment_id, model_dir)`

## 理論・背景
後から最良モデルを再評価するには、ログとモデルファイルの対応関係が明確でなければなりません。本関数はその対応付けを保存規約として保証します。

## 外部ライブラリ・ツールボックス
- MATLAB 標準保存機能

## 入出力
- 入力: 学習済みネットワーク、正規化係数、実験 ID、保存先
- 出力: 実験 ID 付きモデルファイル

## システム上の役割
探索管理の成果物保存担当です。`loadExperimentModel` と対になる存在です。
