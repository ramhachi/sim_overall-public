# generateResidualPlots.m

## 概要
各出力チャネルについて残差分布や偏りを可視化する関数です。通常は 4 枚の PNG を生成します。

## 主要関数・クラス
- `generateResidualPlots(Y_actual, Y_pred, output_dir)`

## 理論・背景
残差図は、平均誤差では見えない系統バイアス、分散の増大、非線形誤差構造の検出に適しています。タイヤモデルではピーク力付近で残差が増える傾向の確認に有効です。

## 外部ライブラリ・ツールボックス
- MATLAB 標準プロット機能

## 入出力
- 入力: 実測値、予測値、保存先
- 出力: Fx/Fy/Mx/Mz の残差図

## システム上の役割
品質診断の詳細分析を担います。可視化セットの中でも、誤差原因の切り分けに特に有効な関数です。
