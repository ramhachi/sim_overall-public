# generateOperatingConditionPlots.m

## 概要
荷重、スリップ角、スリップ率などの運転条件レンジごとにモデル性能を可視化する関数です。条件依存の RMSE や R² を比較できます。

## 主要関数・クラス
- `generateOperatingConditionPlots(...)`
- 条件ビニングと性能集計

## 理論・背景
平均的な誤差だけでは、どの条件で失敗しているか分かりません。条件別評価により、低荷重域、ピークスリップ域、複合スリップ域などの弱点を局所的に特定できます。

## 外部ライブラリ・ツールボックス
- MATLAB 標準可視化機能

## 入出力
- 入力: 実測・予測データ、条件特徴量、出力先
- 出力: 条件別性能グラフ

## システム上の役割
モデル改善の方向性を示す解析図を作成します。ハイパーパラメータ探索後の失敗領域の特定にも有効です。
