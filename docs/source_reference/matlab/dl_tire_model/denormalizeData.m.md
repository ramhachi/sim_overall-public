# denormalizeData.m

## 概要
Z スコア正規化されたデータを元の物理単位へ戻す逆変換関数です。推論結果の可視化や評価時に使われます。

## 主要関数・クラス
- `denormalizeData(X_norm, mu, sigma)`

## 理論・背景
ニューラルネット学習では正規化が必須ですが、最終的な解釈は物理単位で行う必要があります。本関数は `x = x_norm .* sigma + mu` に相当する逆操作を担います。

## 外部ライブラリ・ツールボックス
- MATLAB 標準配列演算

## 入出力
- 入力: 正規化データ、平均、標準偏差
- 出力: 元スケールへ復元した行列

## システム上の役割
`evaluateModel`、可視化関数群、推論ワークフローの橋渡しを担います。学習内部表現と外部利用単位をつなぐ基本ユーティリティです。
