# generateScatterPlots.m

## 概要
実測値と予測値の対応を散布図で可視化する関数です。通常は 4 出力分の PNG を作成し、図中に R² を付記します。

## 主要関数・クラス
- `generateScatterPlots(Y_actual, Y_pred, output_dir)`

## 理論・背景
散布図は理想線からのずれを直感的に確認でき、飽和域やゼロ近傍での偏りを見つけやすい表現です。論文・報告資料でも使いやすい基本図です。

## 外部ライブラリ・ツールボックス
- MATLAB 標準可視化機能

## 入出力
- 入力: 実測値、予測値、保存先
- 出力: 4 枚の散布図 PNG

## システム上の役割
学習品質の第一印象を与える代表図を生成します。`generateAllVisualizations` の中核要素です。
