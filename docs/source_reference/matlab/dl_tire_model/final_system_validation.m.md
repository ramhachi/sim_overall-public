# final_system_validation.m

## 概要
学習済み DNN タイヤモデル全体を対象に、単体・性質・性能の各観点から最終検証を実施する総合関数です。実運用前の受け入れ試験に相当します。

## 主要関数・クラス
- `final_system_validation()`
- 単体テスト、物理整合性テスト、性能テスト、回帰確認を統合

## 理論・背景
高精度でも、ゼロスリップ挙動、対称性、レンジ外応答、処理時間などが満たされなければ実用に耐えません。本関数は複数の検証軸を横断して、モデルの総合健全性を判定します。

## 外部ライブラリ・ツールボックス
- Deep Learning Toolbox
- 必要に応じて Statistics / Parallel Computing Toolbox

## 入出力
- 入力: なし、または内部で既定モデルを読込
- 出力: 総合ステータス、詳細レポート、失敗項目一覧

## システム上の役割
MATLAB 側品質保証の最終関門です。C++ 連携前や実験成果の確定前に使われます。
