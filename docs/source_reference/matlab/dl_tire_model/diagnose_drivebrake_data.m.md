# diagnose_drivebrake_data.m

## 概要
DriveBrake データをラン単位で解析し、スリップ角分布や条件偏りを診断するスクリプトです。系列ごとの癖や混在条件を洗い出します。

## 主要関数・クラス
- スクリプト形式の診断処理
- Run ごとの統計集計
- SA 分布や条件別プロットの生成

## 理論・背景
DriveBrake データには純縦力用ランと複合スリップ用ランが混在しやすく、これが学習バイアスの原因になります。ラン単位で分解して見ることで、除外対象や分離学習の必要性を判断できます。

## 外部ライブラリ・ツールボックス
- MATLAB 標準可視化機能

## 入出力
- 入力: DriveBrake CSV 群
- 出力: 診断統計、分布図、ラン別の所見

## システム上の役割
`run_separated_training` や `clean_and_retrain` の前段診断として有効です。データセット設計を見直すための調査用スクリプトに位置付けられます。
