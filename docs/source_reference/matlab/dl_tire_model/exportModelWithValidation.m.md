# exportModelWithValidation.m

## 概要
モデル保存前後で検証入力に対する整合性チェックを行う品質保証付きエクスポート関数です。単なる保存ではなく、書き出し妥当性の確認まで含めます。

## 主要関数・クラス
- `exportModelWithValidation(trained_net, norm_params, output_path, X_test)`

## 理論・背景
モデルファイルが生成できても、保存内容や正規化係数に不整合があれば後段で誤推論が発生します。本関数はテスト入力での予測確認を通じて、エクスポート工程に品質ゲートを設けます。

## 外部ライブラリ・ツールボックス
- Deep Learning Toolbox

## 入出力
- 入力: 学習済みネットワーク、正規化係数、保存先、検証用入力
- 出力: 検証済み `.mat` モデル、確認結果

## システム上の役割
安全性重視の保存ルートです。最終納品モデルや C++ 展開前の品質確認に適しています。
