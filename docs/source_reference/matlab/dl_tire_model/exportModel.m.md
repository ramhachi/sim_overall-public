# exportModel.m

## 概要
学習済みネットワークと正規化パラメータを `.mat` ファイルとして保存する基本エクスポート関数です。再利用可能な学習成果物を生成します。

## 主要関数・クラス
- `exportModel(trained_net, norm_params, output_path)`

## 理論・背景
再学習のたびに同じ成果物構造で保存しておくことで、後続の評価、可視化、C++ 書き出し、推論テストを共通の形式で実行できます。保存の標準化は研究再現性の基盤です。

## 外部ライブラリ・ツールボックス
- MATLAB 標準保存機能

## 入出力
- 入力: 学習済みネットワーク、正規化構造体、保存先パス
- 出力: `.mat` ファイル

## システム上の役割
すべての後段処理の出発点となる共通保存形式を提供します。メイン学習、探索、検証の成果物保存に用いられます。
