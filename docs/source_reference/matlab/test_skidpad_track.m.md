# `test_skidpad_track.m`

## 概要
- SAE スキッドパッドコースの幾何が仕様どおり生成されているかを検証するスクリプトです。
- 2 つの完全円と総走行長 `4πR` など、重要な幾何条件を確認します。
- 軌跡追従評価やラップタイム計算の前提となるコース定義の妥当性をチェックします。

## 主要関数・クラス
- 主処理はスキッドパッド座標の生成、主要点の表示、プロットです。
- 円中心、接続点、総長などを確認し、期待形状と一致するかを見ます。
- 定量確認と視覚確認を併用する簡易検証スクリプトです。

## 理論・背景
- スキッドパッドは半径と走行長が評価に直結するため、トラック定義の誤差が性能指標を直接歪めます。
- 特に左右円の配置や周回長の扱いにミスがあると、比較結果の公平性が失われます。
- 本ファイルは、こうした基礎入力の整合性を保証するための検証用です。

## 外部ライブラリ・ツールボックス
- MATLAB Graphics を使います。
- 図で円配置を確認できるため、数値だけでは見落としやすい幾何不整合を発見しやすくなります。

## 入出力
- 入力: スクリプト内で設定するスキッドパッド半径等。
- 出力: 幾何確認用の数値表示とプロット。
- 出力は主に開発・検証担当者向けです。

## システム上の役割
- 標準イベントトラック定義の品質保証に使われます。
- スキッドパッド関連のシミュレーションや最適化結果の信頼性を下支えします。
- トラック生成ロジック変更時の回帰確認にも有効です。
