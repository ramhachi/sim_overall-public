# `grid_search_pid.m`

## 概要
- PID ゲインを格子状に走査し、比較的短時間で良好な組み合わせを見つけるスクリプトです。
- ベイズ最適化より単純ですが、10〜15 分程度で大まかなチューニングを済ませたい場面に向きます。
- トラック条件ごとに実用的な初期ゲインを得るための高速手法です。

## 主要関数・クラス
- `grid_search_pid(track_type, track_radius, sim_time)` が主関数です。
- 各候補ゲインについてシミュレーションを実行し、評価指標から最良組を選びます。
- 出力は最良ゲイン構造体で、後続の本番実行やベイズ最適化初期値に使えます。

## 理論・背景
- PID 調整はブラックボックス最適化の対象ですが、まず粗い探索で妥当な範囲を掴むと後段が安定します。
- 格子探索は計算効率では最良ではない一方、実装が単純で再現性が高く、失敗モードを把握しやすい利点があります。
- 本ファイルは、運用上の即効性を重視した現場向けチューニング手段です。

## 外部ライブラリ・ツールボックス
- Docker を利用します。
- 理由は、各ゲイン候補の評価を C++ シミュレータで統一的に実行し、MATLAB 側で結果比較するためです。
- MATLAB 側で特別な最適化ツールボックスがなくても実行できます。

## 入出力
- 入力: トラック種別、トラック半径、シミュレーション時間。
- 出力: 最良の PID ゲイン構造体。
- 内部では多数のシミュレーション結果を比較し、ラップタイムや誤差指標を評価に使います。

## システム上の役割
- PID チューニングの高速入口です。
- `run_full_pipeline` や検証スクリプトで、まず使えるゲインを確保するための前処理として有用です。
- ベイズ最適化ほど重くないため、素早い実験サイクルを支えます。
