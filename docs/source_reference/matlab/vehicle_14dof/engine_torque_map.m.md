# `matlab/vehicle_14dof/engine_torque_map.m`

## 概要

`engine_torque_map` は、CBR600RR エンジンの回転数に対するトルクカーブを線形補間で返す関数である。  
3000–15000 rpm の 17 点データを持ち、12000 rpm 付近で最大 62.8 Nm を与える。

## 主要関数・クラス

- `engine_torque_map(rpm)`  
  単一入力・単一出力のトルクマップ関数。
- 内部データ
  - `rpm_points`
  - `torque_points`
- `interp1(...)`  
  範囲内の線形補間に使う。範囲外では端値固定。

## 理論・背景

エンジントルクはパワートレイン応答の基本入力であり、車輪トルク・加速・LSD の作動量へ直結する。  
複雑な吸排気モデルや燃焼モデルを使わず、実用上十分な piecewise linear 曲線で扱うことで、車両運動側へ負担をかけない設計になっている。

端値固定のため、低回転・高回転で不自然な外挿暴走を避けられる。  
このシンプルさが MATLAB / C++ で同一マップを持つ際の再現性向上につながる。

## 外部ライブラリ・ツールボックス

MATLAB 標準の `interp1` を使用。  
外部ツールボックスは不要。

## 入出力

- 入力
  - `rpm` [rpm]
- 出力
  - `torque` [Nm]

## システム上の役割

14DOF モデルのパワートレイン入力源として、エンジン出力トルクを供給する。  
C++ と一致したトルク曲線を共有することで、加速や LSD 応答の比較基準を作る。
