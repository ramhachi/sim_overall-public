# `matlab/vehicle_14dof/aero_map_4d.m`

## 概要

`vehicle_14dof/aero_map_4d.m` は、14DOF モデル用に用意された関数版 4D 空力マップである。  
クラス版と同じ考え方で、車速・前後ライドハイト・ロール・ヨーから `Fx, Fy, Fz` とモーメント、前後ダウンフォース配分を返す。

## 主要関数・クラス

- `aero_map_4d(velocity, rh_front_mm, rh_rear_mm, roll_rad, yaw_rad, params)`  
  空力計算の公開関数。
- `compute_coefficients(rh_f, rh_r, roll, yaw, grid, params)`  
  地面効果、ロール損失、ヨー感度、圧力中心前後移動を計算する。

## 理論・背景

理論はクラス版と同じく、ライドハイトで地面効果、ロールでフロア効率低下、ヨーでダウンフォース低下とサイドフォース発生を表現する。  
ただし 14DOF 用ではクラス保持ではなく関数呼び出しにすることで、完全車両の ODE 内から軽く呼べる構成になっている。

出力は総力だけでなく前後ダウンフォース配分も含むため、タイヤ垂直荷重計算との結合が容易である。  
MATLAB / C++ 間で同一ロジックを保つための空力ラッパーとして重要である。

## 外部ライブラリ・ツールボックス

外部ツールボックスは不要。  
標準関数と単純な係数式のみで構成される。

## 入出力

- 入力
  - `velocity`
  - `rh_front_mm`, `rh_rear_mm`
  - `roll_rad`, `yaw_rad`
  - `params`
- 出力
  - `Fx`, `Fy`, `Fz`
  - `Mx`, `My`, `Mz`
  - `Fz_front`, `Fz_rear`

## システム上の役割

14DOF 完全車両 ODE 内で使われる空力サブシステムであり、姿勢・車高依存の空力荷重を供給する。  
クラス版 `matlab/aero/` の考え方をフルビークル実装へ埋め込むための関数ラッパーである。
