# `matlab/vehicle_14dof/run_14dof_cpp_comparison.m`

## 概要

`run_14dof_cpp_comparison.m` は、TMeasy ベースの 14DOF MATLAB 結果を C++ 実装と比較する主要検証スクリプトである。  
完全車両パラメータを設定し、ステップステアを与えて MATLAB 側を実行し、結果の可視化と CSV 出力を行う。

## 主要関数・クラス

- `setup_params_cpp_compatible()`  
  C++ 互換のパラメータ一式を構成する。
- `vehicle_14dof_model(...)`  
  フルビークルシミュレーション本体。
- 結果可視化部  
  8 パネルで軌跡、速度、ヨーレート、ロール角、輪荷重、加速度、タイヤ横力、タイヤ前後力を表示する。
- CSV 出力部  
  `matlab_14dof_result.csv` を生成し、C++ 側比較へ流す。

## 理論・背景

14DOF ではサブシステム結合が多く、差異の原因切り分けが難しい。  
そのため本スクリプトでは、まず NN ではなく TMeasy 版で比較し、タイヤモデル差を排除したうえで MATLAB / C++ の整合を見る構成になっている。

出力項目は軌跡や姿勢だけでなく輪荷重・タイヤ力まで含み、フルビークルの各サブシステムが適切に結合しているかを総合的に確認できる。  
フル車両比較の第一選択肢となるハーネスである。

## 外部ライブラリ・ツールボックス

外部ツールボックスは基本不要。  
標準の CSV 書込、補間、描画関数を使う。

## 入出力

- 入力
  - 解析時間 5 s
  - `dt = 1 ms`
  - `t=1 s` で `0.1 rad` ステップステア
  - `throttle = 0.3`
- 出力
  - プロット表示
  - `matlab_14dof_result.csv`
  - C++ 結果があれば RMS / Max 比較

## システム上の役割

14DOF MATLAB ↔ C++ 検証の中心ファイルである。  
完全車両ダイナミクスの基準比較ハーネスとして、統合実装の品質保証に直接使われる。
