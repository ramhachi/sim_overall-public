# `matlab/vehicle_14dof/vehicle_14dof_model.m`

## 概要

`vehicle_14dof_model` は、本リポジトリの MATLAB 側における完全車両ダイナミクス参照実装である。  
6DOF ばね上剛体、4 輪ばね下垂直、4 輪回転に加え、TMeasy タイヤ、Bouc-Wen ダンパ、LuGre 摩擦、ARB、バンプストップ、空力、エンジン、LSD を統合し、40 状態を 1 ms RK4 で積分する。

## 主要関数・クラス

- `vehicle_14dof_model(params, t_span, dt, input_func)`  
  主関数。40 状態を初期化し、`data.ax`, `data.ay`, `data.Fz`, `data.Fx`, `data.Fy`, `data.F_spring`, `data.F_bw`, `data.F_lugre` を記録する。
- `compute_equilibrium(params)`  
  静的輪荷重と平衡位置を求める。
- `derivatives(...)`  
  完全 ODE 本体。各輪サスペンション変位、タイヤ力、ダンパ力、摩擦力、バンプストップ、車体剛体運動、車輪回転などを統合して計算する。
- 補助サブシステム群  
  実ファイル内外で空力、エンジントルク、LSD、回転変換などを併用する。

## 理論・背景

このモデルは SAE J670e 座標系、Tait-Bryan Z-Y-X オイラー角、1 ms 固定刻み RK4 を前提とする完全車両モデルである。  
各輪で  
- TMeasy による縦横タイヤ力  
- Bouc-Wen によるヒステリシス減衰  
- LuGre による微小速度域摩擦  
- バンプストップ非線形ばね  
を計算し、さらに ARB と空力荷重を重ねて車体へ反映する。

このように多数のサブシステムを 1 本の ODE にまとめることで、実車らしい輪荷重移動、旋回姿勢、サスペンション非線形、駆動応答を一貫して追える。  
MATLAB での完全車両参照実装という位置付けから、C++ 実装や各種簡略モデルの最終比較基準になる。

## 外部ライブラリ・ツールボックス

基本的に外部ツールボックスは不要。  
数値積分・座標変換・サスペンション／タイヤ計算は自前実装で構成される。

## 入出力

- 入力
  - `params`: 車体、サスペンション、タイヤ、空力、パワートレイン一式
  - `t_span`, `dt`
  - `input_func`: `steering`, `throttle` などを返す関数
- 出力
  - `t`
  - `state`: 40 状態履歴
  - `data`: 加速度、輪荷重、タイヤ力、ばね力、Bouc-Wen 力、LuGre 力

## システム上の役割

MATLAB 側フルビークルの最重要参照実装であり、14DOF 車両運動の中心ファイルである。  
C++ 検証、積分器比較、サブシステム差し替え、NN 版比較など、多くの上位スクリプトがこのファイルを基準に構成される。
