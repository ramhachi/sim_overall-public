# `matlab/vehicle_14dof/run_stiff_model_comparison.m`

## 概要

`run_stiff_model_comparison.m` は、サスペンション・タイヤ・摩擦の剛性を意図的に高めた条件下で RK4 の安定性を調べる比較スクリプトである。  
通常より硬いモデルに対して `dt=1 ms`、`0.1 ms`、`0.01 ms` の RK4 を実行し、位置誤差・ロール誤差・計算時間を比較する。

## 主要関数・クラス

- 高剛性パラメータ設定部  
  ばね、タイヤ、LuGre、バンプストップ、ARB を増強する。
- `vehicle_14dof_model(...)`  
  各ステップサイズで比較する対象モデル。
- 誤差比較部  
  `1 ms` と `0.1 ms` の位置誤差、ロール誤差を計算する。
- 可視化部  
  軌跡、ロール、速度、位置誤差、輪荷重、計算時間を表示する。

## 理論・背景

通常条件では 1 ms RK4 で十分でも、剛性が増すと数値安定性が悪化する可能性がある。  
このスクリプトは、タイヤ剛性や LuGre 剛性を大きく上げたときに、時間刻み縮小がどこまで必要かを確認するためのストレステストである。

実質的には「Rosenbrock が必要になる境界」を探るファイルであり、高剛性化しても RK4 が破綻しないか、あるいは極端に小さい刻みが必要かを調べる。  
将来のモデル高精細化時に数値解法を見直す判断材料になる。

## 外部ライブラリ・ツールボックス

外部ツールボックスは不要。  
比較自体は標準 MATLAB 関数のみで行う。

## 入出力

- 入力
  - 高剛性化したサスペンション・タイヤ・摩擦パラメータ
  - RK4 刻み: `1 ms`, `0.1 ms`, `0.01 ms`
- 出力
  - `../../output/stiff_model_comparison.png`
  - 各刻みの計算時間、位置誤差、ロール誤差

## システム上の役割

数値安定性評価のストレステストとして、14DOF モデルの頑健性限界を調べる。  
高剛性化や将来の詳細モデル追加に対し、現行 RK4 戦略がどこまで耐えられるかを可視化する役目を持つ。
