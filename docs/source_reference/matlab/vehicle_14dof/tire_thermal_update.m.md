# `matlab/vehicle_14dof/tire_thermal_update.m`

## 概要

`tire_thermal_update` は、タイヤ表面温度を 1 ステップ進める集中定数熱モデルである。  
摩擦仕事による発熱と対流冷却を計算し、オイラー積分で新しい表面温度を返す。

## 主要関数・クラス

- `tire_thermal_update(T_surf, Fx, Fy, vsx, vsy, v_wind, T_amb, dt)`  
  公開関数。発熱 `Q_gen`、冷却 `Q_conv`、温度変化率 `dT/dt` を計算する。
- 内部定数
  - `m_tread = 2.0 kg`
  - `c_p = 1000 J/(kg·K)`
  - `h_conv = 50 W/(m²·K)`
  - `A_tread = 0.05 m²`

## 理論・背景

モデルは集中定数系の熱収支  
`m*c_p*dT/dt = Q_gen - Q_conv`  
に基づく。  
発熱は `|Fx*vsx| + |Fy*vsy|` として摩擦仕事率から近似し、冷却は `h*A*(T_surf - T_amb)*(1 + 0.1*v_wind)` で風速依存を入れる。

詳細な内部層温度や伝導までは扱わないが、フルビークルに追加しても計算負荷が小さい。  
そのため、NN タイヤモデルの温度依存入力を供給する簡便な熱サブモデルとして適している。

## 外部ライブラリ・ツールボックス

外部ツールボックスは不要。  
標準演算のみで実装される。

## 入出力

- 入力
  - 現在温度 `T_surf`
  - `Fx`, `Fy`
  - `vsx`, `vsy`
  - `v_wind`
  - `T_amb`
  - `dt`
- 出力
  - `T_surf_new`
  - 温度は 0–120°C にクランプされる

## システム上の役割

`vehicle_14dof_nn` におけるタイヤ温度状態更新を担う。  
ML タイヤモデルへ温度入力を供給し、熱影響を含むシミュレーション拡張を成立させるモジュールである。
