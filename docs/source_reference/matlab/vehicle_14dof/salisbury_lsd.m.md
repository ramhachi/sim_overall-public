# `matlab/vehicle_14dof/salisbury_lsd.m`

## 概要

`salisbury_lsd` は、Salisbury 式リミテッドスリップデファレンシャルを簡略モデルで表した関数である。  
左右車輪角速度、入力トルク、ランプ角、プリロード、効率から左右出力トルクと差動出力軸回転数を返す。

## 主要関数・クラス

- `salisbury_lsd(omega_L, omega_R, T_in, params)`  
  公開関数。加減速でランプ角を切り替え、LSD 制限トルクを計算する。
- パラメータ
  - `ramp_accel`
  - `ramp_decel`
  - `preload`
  - `efficiency`

## 理論・背景

Salisbury LSD は、ランプ角とクラッチ／ギヤ機構により左右回転差へ抵抗を与える差動装置である。  
本モデルでは  
`T_lsd = preload + |T_in| * tan(ramp_angle)`  
とし、入力トルクが大きいほど拘束トルクが増える簡易表現を採用している。

左右車輪の速度差がある場合には、遅い側へ多めのトルクを配分する。  
精密なクラッチ摩擦解析ではないが、コーナ立上りやトラクション左右差の効果を車両モデルへ入れるには十分な簡潔さを持つ。

## 外部ライブラリ・ツールボックス

外部ツールボックスは不要。  
三角関数と標準算術のみで構成される。

## 入出力

- 入力
  - `omega_L`, `omega_R` [rad/s]
  - `T_in` [Nm]
  - `params`: ランプ角、プリロード、効率
- 出力
  - `T_L`, `T_R` [Nm]
  - `omega_out` [rad/s]

## システム上の役割

14DOF パワートレインの差動機構として、左右駆動輪のトルク配分を決める。  
加速旋回時のトラクション配分やヨー応答へ影響する、重要な駆動系サブシステムである。
