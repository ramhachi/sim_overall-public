# `matlab/vehicle_14dof/verify_params_match.m`

## 概要

`verify_params_match.m` は、MATLAB と C++ の 14DOF 用パラメータや補助サブシステム関数が一致しているかを点検する監査スクリプトである。  
車体・サスペンション・タイヤ・空力・駆動パラメータを表示し、さらにエンジントルクマップ、LSD、4D 空力マップの試験も実行する。

## 主要関数・クラス

- パラメータ表示部  
  質量、慣性、サスペンション、タイヤ、空力、駆動、初速を一覧表示する。
- `engine_torque_map(rpm)`  
  3000–15000 rpm のトルク曲線を試験する。
- `salisbury_lsd(...)`  
  左右輪速度差を与えて配分トルクを確認する。
- `aero_map_4d(...)`  
  基準条件とライドハイト掃引で空力応答を確認する。

## 理論・背景

フルビークル比較が崩れる原因は、しばしば ODE 本体ではなく「定数や補助関数の食い違い」にある。  
このファイルは、そのような差を早期に見つけるためのパラメータ監査ツールであり、サブシステム単位の sanity check を兼ねている。

エンジントルク、LSD、空力を個別に確認することで、駆動系・空力系・静的車両定数のどこにズレがあるかを切り分けやすい。  
フル比較前の前処理として非常に有用である。

## 外部ライブラリ・ツールボックス

外部ツールボックスは不要。  
補助関数呼び出しとコンソール出力だけで完結する。

## 入出力

- 入力
  - スクリプト内定義パラメータ一式
- 出力
  - コンソール上のパラメータ一覧
  - エンジントルクマップ試験結果
  - LSD 出力トルク
  - 4D 空力マップの基準点・ライドハイト効果レポート

## システム上の役割

14DOF 系のパラメータ監査・整合確認を担う診断ツールである。  
MATLAB ↔ C++ 比較やモデル更新前に、補助サブシステムと定数が揃っているかを簡潔に点検できる。
