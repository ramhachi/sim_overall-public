# `matlab/vehicle_14dof/run_14dof_verification.m`

## 概要

`run_14dof_verification.m` は、Bouc-Wen・LuGre・ARB・バンプストップを含む 14DOF 完全車両モデルの検証スクリプトである。  
MATLAB 単体でフルシミュレーションを行い、必要に応じて C++ 結果も読み込んで比較する。

## 主要関数・クラス

- `vehicle_14dof_model(...)`  
  完全車両モデル本体。
- パラメータ設定部  
  LuGre `sigma0=10000`、Bouc-Wen、ARB、バンプストップ、TMeasy を含む一式を構成する。
- 可視化部  
  軌跡、速度、ロール、ピッチ、タイヤ荷重、Bouc-Wen 力、LuGre 力、ヨーレートを描く。
- C++ 比較部  
  14DOF 出力 CSV が見つかれば主要量の比較を行う。

## 理論・背景

この検証は「全サブシステムを含んだ状態で車両として自然に走るか」を確認するためのものだ。  
部分モデルでは見えない、サスペンション非線形・輪荷重移動・ヨー応答・駆動の相互作用を一度に観察できる。

静的荷重と初期輪荷重を併記している点も重要で、初期化の破綻を早期に見つけやすい。  
フルシステム検証として最も包括的な MATLAB 側ハーネスの一つである。

## 外部ライブラリ・ツールボックス

外部ツールボックスは不要。  
標準の描画・表読込機能を用いる。

## 入出力

- 入力
  - 完全車両パラメータ一式
  - 5 秒解析、`dt=1 ms`
  - ステップステア入力
- 出力
  - 軌跡、速度、角度、輪荷重などの図
  - C++ 結果があれば比較図
  - コンソール上の最終位置、方位、速度、最大ロール・ピッチ

## システム上の役割

MATLAB 側フルシステム検証の総本山であり、サブシステム統合後の健全性確認を担う。  
サスペンション・タイヤ・空力・駆動の完全統合状態を確認する最終的な品質ゲートの一つである。
