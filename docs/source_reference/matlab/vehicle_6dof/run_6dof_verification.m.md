# `matlab/vehicle_6dof/run_6dof_verification.m`

## 概要

`run_6dof_verification.m` は、6DOF MATLAB モデルと C++ 実装を比較する検証スクリプトである。  
12 状態変数について補間後の誤差を計算し、許容差とともに PASS / FAIL を表示する。

## 主要関数・クラス

- `vehicle_6dof_model(...)`  
  MATLAB 側の基準シミュレーション。
- `interp1(...)`  
  MATLAB 結果を C++ の時刻列へ再サンプルする。
- 誤差評価部  
  `x, y, z, phi, theta, psi, vx, vy, vz, p, q, r` を対象に最大誤差と RMSE を算出する。
- 可視化部  
  3×4 のプロット行列で軌跡、姿勢、速度、誤差を一覧表示する。

## 理論・背景

6DOF では平面運動に加えてヒーブ・ロール・ピッチが入るため、誤差要因が増える。  
そのため位置だけでなく、姿勢角や角速度の許容差を別々に管理し、どの自由度で差が発生しているかを把握できる構成になっている。

許容差は `x/y ±1 m`、`z ±0.1 m`、`roll/pitch ±2 deg`、`yaw ±5 deg` などで、姿勢自由度追加による累積差を見込んでいる。  
この検証で大きな差がなければ、独立ばね下自由度を含む 8DOF への拡張に進みやすい。

## 外部ライブラリ・ツールボックス

外部ツールボックスは不要。  
標準の表読込、補間、描画のみを使用する。

## 入出力

- 入力
  - ステップステア条件: `t=1 s` で `0.1 rad`
  - C++ 結果: `output/6dof_step_steer_result.csv`
- 出力
  - 誤差テーブル
  - 12 パネル比較図 `output/verify_6dof.png`

## システム上の役割

立体剛体運動を含む MATLAB / C++ 整合検証の基準ファイルである。  
8DOF 以上の詳細サスペンションモデルに進む前に、姿勢・速度・軌跡の一致度を保証する中間品質ゲートとして機能する。
