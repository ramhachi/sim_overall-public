# `matlab/pou_hardpoint_design/geometry/axis_angle_rotation.m`

## 概要
軸ベクトルと回転角から3次元回転行列を生成する基礎関数です。Rodriguesの回転公式を用いて、キングピン回りの姿勢変換を行います。

## 主要関数・クラス
- `axis_angle_rotation`: 軸・角度表現を回転行列へ変換する関数

## 理論・背景
3次元剛体運動では、単位軸と回転角から直接回転行列を求める軸角表現が有効です。POU設計ではアップライトの操舵回転を安定かつ明快に記述するため、この基本変換が繰り返し使われます。

## 外部ライブラリ・ツールボックス
- MATLAB 行列演算
- 基本線形代数

## 入出力
- 入力: 単位軸 `axis [3x1]`、回転角 `angle`
- 出力: 回転行列 `R [3x3]`

## システム上の役割
幾何ソルバ全体の最小単位となるユーティリティです。上位の剛体変換計算を支える共通数学関数として利用されます。
