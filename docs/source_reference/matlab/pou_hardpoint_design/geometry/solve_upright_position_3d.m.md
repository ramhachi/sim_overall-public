# `matlab/pou_hardpoint_design/geometry/solve_upright_position_3d.m`

## 概要
操舵角に対するアップライトの3次元位置と姿勢を解く剛体運動ソルバです。キングピン軸まわりの回転を適用し、剛体変換 `R` と `t`、各ボールジョイント位置を返します。

## 主要関数・クラス
- `solve_upright_position_3d`: アップライト状態計算の主関数
- 軸角回転処理: キングピン回りの姿勢変換

## 理論・背景
ダブルウィッシュボーンの操舵幾何では、アップライトを剛体として扱い、基準姿勢からキングピン軸回りに回転させる近似が中心になります。この変換を正確に解くことで、タイロッド・プッシュロッド・スピンドル傾きの後続計算が成立します。

## 外部ライブラリ・ツールボックス
- MATLAB 行列演算
- `axis_angle_rotation`

## 入出力
- 入力: `delta`、`geom`
- 出力: 回転行列、並進、各ジョイント位置を含む `upright_state`

## システム上の役割
POU幾何計算の根幹であり、操舵角に対する全ハードポイント応答の起点です。順運動学と可視化の共通基礎を提供します。
