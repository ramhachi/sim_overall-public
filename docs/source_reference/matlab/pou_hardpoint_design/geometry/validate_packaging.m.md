# `matlab/pou_hardpoint_design/geometry/validate_packaging.m`

## 概要
最適化後の設計案が実装可能なパッケージ条件を満たすかを確認する検証関数です。リムクリアランス、キャリパ干渉、ベルクランク内側配置、高さ条件の4項目を評価します。

## 主要関数・クラス
- `validate_packaging`: パッケージ検証の主関数
- 違反収集処理: 各条件の判定と一覧化

## 理論・背景
数値的に良い解でも、ホイール内やシャシー内で干渉すれば設計として成立しません。POU機構はホイール周辺部品との距離制約が厳しいため、後段の実装可否判定が不可欠です。

## 外部ライブラリ・ツールボックス
- MATLAB 幾何計算
- 条件判定用の基本関数

## 入出力
- 入力: `design_vars`、`geom`、`delta_range`
- 出力: `valid`、`violations`

## システム上の役割
最適化解を製作候補として採用できるかを決める最終チェックです。設計品質を数値誤差だけでなく実装可能性まで含めて判定します。
