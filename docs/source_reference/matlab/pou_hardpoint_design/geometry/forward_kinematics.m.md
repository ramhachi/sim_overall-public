# `matlab/pou_hardpoint_design/geometry/forward_kinematics.m`

## 概要
設計変数からジャックアップ曲線・キャンバー曲線・プッシュロッド長変化を計算する順運動学関数です。Mピボットとベルクランク配置を前提に、操舵角ごとの幾何応答を評価します。

## 主要関数・クラス
- `forward_kinematics`: 順運動学の主関数
- `solve_upright_position_3d`: アップライト姿勢計算の内部依存先

## 理論・背景
逆設計の目的関数を評価するには、候補ハードポイントから実際の応答曲線を前向きに計算する必要があります。操舵に伴うアップライトの剛体運動とプッシュロッド長変化から、ジャックアップ量とキャンバー変化を抽出します。

## 外部ライブラリ・ツールボックス
- MATLAB 行列演算
- 幾何ソルバ群

## 入出力
- 入力: `design_vars [6x1]`、`geom`、`delta_range`
- 出力: `jack_curve`、`camber_curve`、`pushrod_lengths`

## システム上の役割
目的関数と制約関数が共通参照するPOUのコアモデルです。候補解を評価可能な物理量へ変換する要所として働きます。
