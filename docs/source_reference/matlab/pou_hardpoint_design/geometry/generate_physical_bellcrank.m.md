# `matlab/pou_hardpoint_design/geometry/generate_physical_bellcrank.m`

## 概要
数理最適化で得られた抽象的なプッシュロッド配置を、実際に製作可能な三角ベルクランク形状へ写像する関数です。フレーム側ピボット、ダンパーピン、シャシーマウントを計算します。

## 主要関数・クラス
- `generate_physical_bellcrank`: ベルクランク実体化の主関数
- ダンパーピン算出処理: モーメントアームと角度から導出

## 理論・背景
最適化で扱う点やベクトルだけでは、実機で製作可能なロッカー形状を直接示せません。そこでモーメントアームと姿勢条件を用いて、抽象設計を機械要素レベルの形状へ変換します。

## 外部ライブラリ・ツールボックス
- MATLAB ベクトル演算
- 幾何構成用基本関数

## 入出力
- 入力: `x_pushrod_chassis`、`pushrod_vec_nominal`、`geom`
- 出力: ピン位置や取付点を含む `phys` 構造体

## システム上の役割
数理解と製造可能形状の間をつなぐ橋渡しです。解析モデルをそのまま実装設計へ落とすための具体化処理として機能します。
