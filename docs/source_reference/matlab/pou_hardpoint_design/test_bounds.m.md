# `matlab/pou_hardpoint_design/test_bounds.m`

## 概要
設計変数の上下限制約が妥当かを確認する検証スクリプトです。各輪について探索範囲が過度に狭すぎないか、または非現実的に広すぎないかを点検します。

## 主要関数・クラス
- `test_bounds`: 境界条件の確認処理
- 幾何生成処理: ホイールごとの境界構成確認

## 理論・背景
非線形最適化では境界設定が解の品質と収束性を大きく左右します。設計自由度に対して適切な範囲を与えないと、局所解への拘束や物理的に意味のない解の探索が起こるため、事前検証が重要です。

## 外部ライブラリ・ツールボックス
- MATLAB 基本数値計算機能
- 必要に応じて POU 幾何生成関数群

## 入出力
- 入力: 車両パラメータ、輪ごとの幾何定義、境界設定
- 出力: 各輪の境界チェック結果、警告、デバッグ用表示

## システム上の役割
本番最適化の前に探索空間の妥当性を確認するデバッグ支援です。収束不良や不自然な解の原因切り分けを早める補助ツールとして使われます。
