# `matlab/pou_hardpoint_design/run_all_wheels.m`

## 概要
複数輪に対してPOU最適化を一括実行するバッチスクリプトです。通常は操舵輪を対象にしつつ、必要に応じて後輪も含め、左右対称条件を守りながら結果をCSV・JSON・レポートへまとめます。

## 主要関数・クラス
- `run_all_wheels`: 全輪処理の主関数
- `main_pou_hardpoint_optimizer`: 各輪の最適化実行先
- 各種エクスポート関数: 出力ファイル生成

## 理論・背景
単輪最適化だけでは車両全体の整合を評価しにくいため、左右鏡像と前後の運用条件を加味したバッチ処理が必要です。とくにFL/FR対称性は製造性とセッティング整合に直結するため、自動チェックとまとめ出力が重要になります。

## 外部ライブラリ・ツールボックス
- MATLAB Optimization Toolbox
- MATLAB の CSV / JSON 出力
- MATLAB レポート生成用のファイルI/O

## 入出力
- 入力: 車両パラメータJSON、対象輪の指定、対称性オプション、出力ディレクトリ
- 出力: 輪ごとの最適化結果、左右比較、CSV、JSON、テキストレポート

## システム上の役割
研究用の単体検証を量産向けワークフローへ引き上げる自動化入口です。実運用ではこのスクリプトが設計結果の整合確認と成果物生成をまとめて担当します。
