# `matlab/pou_hardpoint_design/example_usage_jp.m`

## 概要
`example_usage.m` の日本語版デモであり、対話的な案内や入力確認を含めてPOU設計手順を説明するスクリプトです。全輪最適化の要約表も扱い、複数輪の結果比較をしやすくしています。

## 主要関数・クラス
- `example_usage_jp`: 日本語メッセージ付きの実行例
- `run_all_wheels`: 全輪処理の呼び出し先
- 各種表示処理: 結果要約表やプロンプト表示

## 理論・背景
日本語の説明を加えることで、逆運動学・制約付き最適化・左右対称性の概念を段階的に理解できる構成です。とくに全輪最適化では、左右ミラー条件と輪ごとの差異を同時に把握することが重要になります。

## 外部ライブラリ・ツールボックス
- MATLAB Optimization Toolbox
- MATLAB テーブル表示機能
- MATLAB の対話入力機能

## 入出力
- 入力: ユーザ選択、JSONパラメータ、最適化オプション、対象輪設定
- 出力: 日本語の進行表示、全輪結果サマリ、可視化結果、最適化済み座標

## システム上の役割
教育用・説明用・デモ用の入口として機能します。英語版スクリプトよりも運用者支援に重きを置き、設計レビューやチーム内共有を容易にします。
