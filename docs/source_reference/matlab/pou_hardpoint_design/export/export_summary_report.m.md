# `matlab/pou_hardpoint_design/export/export_summary_report.m`

## 概要
POU最適化結果を人間が読みやすいテキストレポートへまとめる関数です。主要指標と制約評価を整理し、合否表示を含む設計レビュー資料を生成します。

## 主要関数・クラス
- `export_summary_report`: レポート生成の主関数
- 合否表示処理: 制約や誤差の判定結果の整形

## 理論・背景
最適化結果は数値だけでは解釈しづらいため、誤差・取付比・パッケージ制約違反を一覧化した報告書が必要です。設計審査では可視化と並んで文章化されたサマリが意思決定に役立ちます。

## 外部ライブラリ・ツールボックス
- MATLAB のテキストファイル出力
- 文字列整形機能

## 入出力
- 入力: 最適化結果、検証結果、出力先ファイル情報
- 出力: テキスト形式の要約レポート

## システム上の役割
解析者以外の設計者やレビュー担当者にも結果を共有するための文書化層です。POU設計の説明責任と判断材料の提供を担います。
