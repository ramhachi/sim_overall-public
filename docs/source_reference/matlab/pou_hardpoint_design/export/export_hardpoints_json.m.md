# `matlab/pou_hardpoint_design/export/export_hardpoints_json.m`

## 概要
POUハードポイント結果をC++シミュレーション向けJSONとして出力する関数です。輪ごとのデータを構築し、既存JSONに追記または新規生成して整形済みで保存します。

## 主要関数・クラス
- `export_hardpoints_json`: JSON出力の主関数
- 輪データ構築処理: 各ホイールのPOU座標整理
- 整形保存処理: 可読性を保った書き出し

## 理論・背景
MATLABで得た結果を動的シミュレーションへ戻すには、シミュレータ側が読むスキーマへ正しく合わせる必要があります。POU座標は車両挙動計算に直接影響するため、構造化されたJSON出力が不可欠です。

## 外部ライブラリ・ツールボックス
- MATLAB の `jsonencode` / `jsondecode`
- ファイルI/O機能

## 入出力
- 入力: 最適化結果、幾何情報、既存JSONの有無、出力先
- 出力: C++シミュレータ向けPOU JSON

## システム上の役割
MATLAB設計とC++実走行シミュレーションを接続する主要な連携関数です。設計反映の自動化を進めるうえで欠かせないデータ橋渡しを担います。
