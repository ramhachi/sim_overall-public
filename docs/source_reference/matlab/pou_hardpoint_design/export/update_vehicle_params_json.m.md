# `matlab/pou_hardpoint_design/export/update_vehicle_params_json.m`

## 概要
既存の車両パラメータJSONへPOU最適化結果を反映する更新関数です。各輪に対応する `pou_hardpoints` セクションを追加し、既存データと整合を取りながら保存します。

## 主要関数・クラス
- `update_vehicle_params_json`: 車両JSON更新の主関数
- 輪別更新処理: ホイールごとのPOUデータ反映

## 理論・背景
設計の最終成果は単独ファイルよりも車両パラメータ全体へ統合されて初めて活用しやすくなります。既存設定を壊さずPOU情報だけを追加する更新手順は、シミュレーション再現性の維持に重要です。

## 外部ライブラリ・ツールボックス
- MATLAB の JSON 読み書き機能
- 構造体編集機能

## 入出力
- 入力: 既存車両パラメータJSON、最適化結果、対象輪情報
- 出力: `pou_hardpoints` を含む更新済み車両パラメータJSON

## システム上の役割
POU設計を車両データベースへ閉ループで戻す役目を持ちます。MATLAB最適化結果をそのままC++側の正式パラメータへ昇格させる更新点です。
