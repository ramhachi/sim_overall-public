# `matlab/pou_hardpoint_design/test_pou_optimizer.m`

## 概要
POU最適化系の回帰テストをまとめた12件のユニットテストです。ダブルウィッシュボーン幾何、キングピン導出、Aアーム回転、ゼロ舵角、アップライト剛体性、順運動学、目的関数、制約、左右対称性、大舵角時の健全性まで広く検証します。

## 主要関数・クラス
- `test_pou_optimizer`: テストスイート本体
- `forward_kinematics` / `solve_upright_position_3d`: 幾何計算の主要被験体
- `objective_polynomial_fit` / `constraint_rod_misalignment`: 最適化評価系の被験体

## 理論・背景
POU設計は幾何、最適化、制約の三層が密結合しているため、個別の数式誤りが全体結果を大きく崩します。回帰テストにより、ゼロ舵角での恒等性や左右鏡像など、保存されるべき幾何学的性質を継続監視します。

## 外部ライブラリ・ツールボックス
- MATLAB Optimization Toolbox
- MATLAB ユニットテスト機能またはアサーション機能

## 入出力
- 入力: テスト用幾何条件、設計変数、ステア角、JSONパラメータ
- 出力: 合否結果、失敗時の詳細、回帰異常の通知

## システム上の役割
機能追加や制約調整の際に既存ロジックが壊れていないかを確認する品質ゲートです。幾何計算の信頼性を保つための基盤テストとして機能します。
