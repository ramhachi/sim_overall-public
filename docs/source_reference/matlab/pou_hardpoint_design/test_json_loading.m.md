# `matlab/pou_hardpoint_design/test_json_loading.m`

## 概要
入力JSONの構造と必要フィールドを確認する事前検証スクリプトです。`params.suspension`、POU多項式係数、質量など、最適化に必要な情報が正しく読み込めるかを点検します。

## 主要関数・クラス
- `test_json_loading`: JSONパース確認
- `jsondecode` 呼び出し部: 構造体変換と必須項目検査

## 理論・背景
POU設計は車両パラメータに強く依存するため、入力データ欠落は最適化失敗に直結します。事前にJSON構造を検査することで、計算本体に入る前にデータ品質の問題を見つけられます。

## 外部ライブラリ・ツールボックス
- MATLAB の `jsondecode`
- MATLAB 構造体処理機能

## 入出力
- 入力: 車両パラメータJSONファイル
- 出力: 読み込み可否、必須フィールドの存在確認、前処理時点の警告情報

## システム上の役割
実行前チェックとして、データ不整合の切り分けを行う守りの役目です。設計アルゴリズムの不具合と入力データ不備を分離して扱えるようにします。
