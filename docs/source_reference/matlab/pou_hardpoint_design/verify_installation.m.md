# `matlab/pou_hardpoint_design/verify_installation.m`

## 概要
POU最適化環境が正しく導入されているかを確認するセットアップ検証スクリプトです。作業ディレクトリ、関数ファイル、Optimization Toolbox ライセンス、ダミー関数呼び出し、入力JSONの存在を5段階で確認します。

## 主要関数・クラス
- `verify_installation`: 導入確認の主関数
- 各種存在確認処理: ファイル・ライセンス・入力データの検査

## 理論・背景
最適化本体の前段で実行環境を検査することで、依存不足やパス設定ミスを早期に検出できます。とくに `fmincon` 依存があるため、ツールボックス可用性の確認は重要です。

## 外部ライブラリ・ツールボックス
- MATLAB Optimization Toolbox
- MATLAB のファイル存在確認・ライセンス確認機能

## 入出力
- 入力: 関数配置、JSONファイル、MATLAB環境情報
- 出力: 導入可否、項目別の合否、セットアップ修正のための警告

## システム上の役割
新規環境への展開や他メンバーへの受け渡し時に、最初に走らせる健全性チェックです。計算本体へ入る前のトラブルシュートを標準化します。
