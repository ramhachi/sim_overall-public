# `matlab/pou_hardpoint_design/example_usage.m`

## 概要
POUハードポイント設計の標準デモスクリプトです。`optimized_autocross.json` を読み込み、最適化設定を組み立て、逆運動学最適化を実行し、結果評価と比較プロット生成までを一通り再現します。

## 主要関数・クラス
- `example_usage`: POU設計ワークフロー全体を順に呼び出す実行例
- `main_pou_hardpoint_optimizer`: 最適化本体
- `plot_comparison`: 目標多項式との比較可視化

## 理論・背景
単なる使用例ではなく、車両レベルの要求曲線を幾何設計へ変換する一連の流れを確認する教材でもあります。非線形最適化には `fmincon` を用い、設計変数の収束性と結果妥当性を実務に近い形で確認します。

## 外部ライブラリ・ツールボックス
- MATLAB Optimization Toolbox
- MATLAB の JSON 読み込み機能
- MATLAB グラフ描画機能

## 入出力
- 入力: `optimized_autocross.json`、最適化オプション、対象ホイール設定
- 出力: 最適化結果構造体、評価指標、比較図、コンソール上の進捗情報

## システム上の役割
初回導入時の確認、再現手順の共有、解析フローの説明に使う代表的な入口です。個別関数をどう連携させるかを示し、運用者が本番用の一括実行へ進むための橋渡しを担います。
