# `matlab/pou_hardpoint_design/visualization/`

## 概要
POU設計結果を解析者・設計者が理解しやすい形で可視化するモジュールです。比較プロットと3Dサスペンション表示により、目標追従性と実装形状を確認できます。

## 主要関数・クラス
- [`plot_comparison.m.md`](plot_comparison.m.md)
- [`visualize_3d_suspension.m.md`](visualize_3d_suspension.m.md)

## 理論・背景
最適化結果の妥当性は数値だけでなく形状と傾向を見て判断する必要があります。ジャックアップ曲線の一致、誤差分布、3D配置、リンク姿勢を視覚的に確認することで、数式上は成立しても直感に反する解を見分けられます。

## 外部ライブラリ・ツールボックス
- MATLAB の2D/3D描画機能
- テーブル表示・注釈表示機能

## 入出力
- 入力: 最適化結果、目標曲線、幾何構造体、可視化オプション
- 出力: 比較図、3Dモデル表示、要約表

## システム上の役割
設計レビューとデバッグのための観測窓です。POU設計結果を人が判断可能な形へ変換し、他工程とのコミュニケーションを支えます。
