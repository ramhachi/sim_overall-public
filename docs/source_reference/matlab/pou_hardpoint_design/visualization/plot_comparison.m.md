# `matlab/pou_hardpoint_design/visualization/plot_comparison.m`

## 概要
POU最適化結果と目標特性を比較する6分割図を生成する可視化関数です。ジャックアップ、キャンバー、誤差分布、要約表を同時に表示し、結果の全体像を把握しやすくします。

## 主要関数・クラス
- `plot_comparison`: 比較可視化の主関数
- サブプロット生成処理: 曲線比較と要約表示

## 理論・背景
最適化の成否は平均誤差だけでは判断しにくく、角度域ごとの偏差や最悪誤差も確認する必要があります。複数視点を1枚にまとめることで、設計レビュー時の比較効率を高めます。

## 外部ライブラリ・ツールボックス
- MATLAB グラフ描画機能
- ヒストグラム・表表示機能

## 入出力
- 入力: 目標曲線、最適化結果曲線、誤差情報、注記用統計量
- 出力: 6サブプロットの比較図

## システム上の役割
POU最適化の結果説明を担う主要な可視化関数です。設計者が採用可否を判断するための要約画面を提供します。
