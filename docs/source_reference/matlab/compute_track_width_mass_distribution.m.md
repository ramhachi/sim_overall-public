# `compute_track_width_mass_distribution.m`

## 概要
- 前後トレッド幅の拡大量に応じて、質量増加を見積もる補助関数です。
- unsprung mass を基準に、アーム延長や周辺部材増加の影響を簡易的に反映します。
- トレッド幅の拡大が常に有利とは限らないよう、設計探索に物理的ペナルティを与えます。

## 主要関数・クラス
- `compute_track_width_mass_distribution(base_unsprung, track_f, track_r, varargin)` が主関数です。
- 前後トレッドと基準質量から、総質量ペナルティまたは関連分布量を算出します。
- 任意引数により係数や換算則を差し替えられる想定です。

## 理論・背景
- トレッド拡大は横安定性や荷重移動特性に利点をもたらす一方、部材長増加による重量増を伴うことがあります。
- 概念最適化でこの副作用を無視すると、非現実的に広いトレッドが選ばれやすくなります。
- 本関数は、詳細構造設計を行わずに質量面の代償を取り込むための近似モデルです。

## 外部ライブラリ・ツールボックス
- 外部ツールボックスは不要です。
- 近似計算のみを行うため、標準 MATLAB で十分です。

## 入出力
- 入力: 基準 unsprung mass、前後トレッド幅、任意の係数類。
- 出力: トレッド拡大に伴う総質量ペナルティ、または質量分布情報。
- 概念設計時には他のパラメータ計算と組み合わせて利用されます。

## システム上の役割
- 幾何変更と質量影響を結び付ける補助物理モデルです。
- トレッド幅を設計自由度に含める最適化で、現実的な方向に探索を誘導します。
- 軽量な近似ながら、コンセプトレベルの妥当性維持に重要です。
