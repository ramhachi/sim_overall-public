# `build_extended_vehicle_tunable_specs.m`

## 概要
- 拡張車両チューナブル項目の仕様一覧を定義する関数です。
- 15 項目前後のパラメータについて、名称、範囲、対象フィールド、説明メタデータを構造体配列として返します。
- ブレーキ、操舵、エンジン、タイヤ、バンプストップ、シャシにまたがる共通定義を集約します。

## 主要関数・クラス
- `build_extended_vehicle_tunable_specs()` — 全仕様の配列を構築します。
- `make_spec()` — 各チューナブル項目を共通形式で組み立てる補助関数です。
- 各 spec は後続の適用関数や最適化コードから参照される前提で設計されています。

## 理論・背景
- 多数の調整項目をベクトルで扱う場合、順序や意味をコード中に散在させると取り違えが起きやすくなります。
- そのため「仕様を定義する層」と「仕様を適用する層」を分離する設計が重要です。
- 本ファイルは仕様の単一情報源として機能し、設計変数の解釈を一貫化します。

## 外部ライブラリ・ツールボックス
- 外部ツールボックスは使いません。
- 構造体配列と補助関数のみで十分表現でき、共有定義として軽量に保てます。

## 入出力
- 入力: 基本的にはなし。
- 出力: チューナブル仕様を表す構造体配列。
- 各要素には名称、範囲、カテゴリ、既定値、対象フィールドなどの情報が含まれます。

## システム上の役割
- `apply_vehicle_extra_tunables` などの共通仕様レジストリです。
- 最適化器、GUI、レポート生成が同じ定義を参照できるため、説明と実装のずれを減らします。
- 車両パッケージの追加調整軸を拡張する際の拠点となります。
