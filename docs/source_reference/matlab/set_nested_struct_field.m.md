# `set_nested_struct_field.m`

## 概要
- ドット区切りなどのパス文字列を使って、ネストした構造体フィールドへ値を設定するユーティリティ関数です。
- 動的に対象フィールドが決まる場面で、`s.a.b.c = value` 相当の処理を一般化します。
- 設計仕様レジストリやチューナブル変数適用と相性の良い補助関数です。

## 主要関数・クラス
- `set_nested_struct_field(s, field_path, value)` が主関数です。
- `field_path` を解析し、`substruct` などを使って対象階層へ値を設定します。
- 静的コードでは冗長になる深いフィールド更新を、データ駆動で実現します。

## 理論・背景
- チューナブル仕様を構造体配列で管理する場合、更新先フィールドを文字列で保持すると汎化しやすくなります。
- その一方で、MATLAB ではネストした動的代入がそのままでは書きにくいため、専用関数があると実装が整理されます。
- 本ファイルは、仕様駆動のパラメータ更新を支える基本ユーティリティです。

## 外部ライブラリ・ツールボックス
- `substruct` など MATLAB 標準機能を使います。
- 追加ツールボックスは不要で、構造体操作を一般化することが主目的です。

## 入出力
- 入力: 構造体 `s`、フィールドパス文字列、設定値。
- 出力: 指定フィールドが更新された構造体。
- 存在しない階層への対応方針は、呼び出し側の運用ルールに依存します。

## システム上の役割
- 動的なパラメータ適用を成立させる低レベル基盤です。
- `apply_vehicle_extra_tunables` のような汎用適用処理で再利用される可能性が高い関数です。
- 設計変数と構造体フィールドを疎結合に保つために重要です。
