# `verify_skidpad_time.m`

## 概要
- 最適化済みの概念設計パラメータを用いて、スキッドパッド結果を再実行・確認する検証スクリプトです。
- ラップタイム、平均速度、横偏差などを出力し、最適化結果が再現できるかを点検します。
- 最適化結果の妥当性を本番条件で確認するための後段検証です。

## 主要関数・クラス
- 主処理は最適化済みパラメータの読み出しまたは構築、`VehicleSimRunner` による実行、結果表示です。
- スキッドパッド用の条件設定を明示し、重要指標を集約して報告します。
- 目的は改善案の再現確認であり、探索そのものではありません。

## 理論・背景
- 最適化中の最良値は、評価設定や偶発的条件によって偏ることがあります。
- そのため、最終候補は単独スクリプトで再評価し、主要指標を改めて確認する工程が必要です。
- 本ファイルは、その「結果の検証」を切り出した実務用スクリプトです。

## 外部ライブラリ・ツールボックス
- Docker を利用します。
- 理由は、検証時も本番と同じ C++ シミュレーション環境で再現性ある評価を行うためです。

## 入出力
- 入力: 最適化済み概念パラメータ、スキッドパッド条件。
- 出力: ラップタイム、平均速度、横偏差などの評価値。
- 画面表示やログ出力が主な成果になります。

## システム上の役割
- 最適化結果の受け入れ判定を支える確認ステップです。
- 概念最適化と報告・共有の間に入り、再現性チェックを行います。
- 設計成果を安心して次段階へ渡すための品質ゲートとして機能します。
