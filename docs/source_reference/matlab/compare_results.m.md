# `compare_results.m`

## 概要
- 2 つのシミュレーション結果 CSV を読み込み、軌跡・誤差・速度などを比較可視化する関数群です。
- 標準設定と最適化設定の差を視覚的に把握するための分析ツールです。
- トラック中心線を生成し、車両軌跡との関係も同じ図上で確認できます。

## 主要関数・クラス
- `compare_results(default_csv, optimized_csv, track_type, track_radius)` — 2 ケースの比較図を生成します。
- `generate_track_centerline()` — 指定トラックの基準中心線を描画・比較用に生成します。
- 主処理は複数パネル図を構成し、時系列と空間軌跡を併せて示します。

## 理論・背景
- 最適化結果は単一のラップタイム値だけでなく、どこで改善したかを把握することが重要です。
- 軌跡誤差、速度プロファイル、横加速度の違いを見ることで、制御寄りの改善か機械系の改善かを切り分けやすくなります。
- 本ファイルは、その比較を定量値から視覚分析へ広げるための支援ツールです。

## 外部ライブラリ・ツールボックス
- MATLAB Graphics を使用します。
- 複数サブプロット、色分け、軸制御を使う理由は、挙動差を一目で比較できるようにするためです。
- 特別な外部ライブラリは不要です。

## 入出力
- 入力: 2 つの結果 CSV、トラック種別、トラック半径。
- 出力: 軌跡・誤差・速度などを含む複数パネルの比較図。
- 図の生成が主目的で、解析に使う中心線データは内部生成されます。

## システム上の役割
- 最適化や PID 調整後の結果確認を効率化する可視化層です。
- `run_comparison` の背後にある実処理として、日常的な比較分析に使われます。
- 数値評価だけでは見えにくい挙動差を共有し、チームの設計判断を支えます。
