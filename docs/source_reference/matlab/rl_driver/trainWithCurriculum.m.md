# `matlab/rl_driver/trainWithCurriculum.m`

## 概要
カリキュラム学習を一般化して扱う共通フレームワークです。課題段階、移行条件、各段階の学習設定をまとめて管理します。

## 主要関数・クラス
- `trainWithCurriculum`: 段階学習の主関数
- 段階遷移管理処理

## 理論・背景
カリキュラム学習では、いつ次の難易度へ進むかが成否を分けます。本関数は進捗管理を共通化し、版ごとの再利用と比較を容易にします。

## 外部ライブラリ・ツールボックス
- MATLAB Reinforcement Learning Toolbox
- 段階管理用補助関数

## 入出力
- 入力: カリキュラム定義、段階別学習設定、初期エージェント
- 出力: 段階学習済みエージェント、進行履歴

## システム上の役割
複数のカリキュラム版スクリプトの共通土台です。段階的育成ロジックを再利用可能にします。
