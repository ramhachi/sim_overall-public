# `matlab/rl_driver/trainAutocrossV6.m`

## 概要
オートクロスコース向けの第6版学習スクリプトです。円旋回より複雑な操舵要求に対応し、実戦的なトラックでの方策学習を行います。

## 主要関数・クラス
- `trainAutocrossV6`: オートクロスV6学習の主関数
- `trainRLDriver`: 共通学習処理

## 理論・背景
オートクロスでは連続コーナ、速度変化、コース逸脱リスクが増えるため、報酬の安全性項や進捗評価の重みが重要になります。V6はその条件に合わせた調整版です。

## 外部ライブラリ・ツールボックス
- MATLAB Reinforcement Learning Toolbox
- C++ RLサーバ

## 入出力
- 入力: オートクロストラック、V6用ハイパーパラメータ
- 出力: オートクロス走行用学習済みエージェント

## システム上の役割
実用課題に近いトラックでの性能確認を担う学習版です。円旋回で得た基礎を実戦課題へ拡張します。
