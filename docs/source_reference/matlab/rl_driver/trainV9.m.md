# `matlab/rl_driver/trainV9.m`

## 概要
第9版の学習スクリプトで、V8からさらに調整を加えた版です。報酬や学習率、探索挙動などの改良を反映した実験入口と考えられます。

## 主要関数・クラス
- `trainV9`: V9学習の主関数
- `trainRLDriver`: 共通学習処理

## 理論・背景
継続的な版更新は、どの条件が性能改善に効いたかを確認する実験管理手法です。V9は最新版へ至る途中の調整結果を保存する役割があります。

## 外部ライブラリ・ツールボックス
- MATLAB Reinforcement Learning Toolbox
- Deep Learning Toolbox

## 入出力
- 入力: V9用の学習条件、トラック、車両設定
- 出力: V9で得られた方策と学習履歴

## システム上の役割
最新版への橋渡しとなる中間版です。性能比較と再現実験のために保持されます。
