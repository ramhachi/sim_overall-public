# `matlab/rl_driver/getDeterministicActorModel.m`

## 概要
確率的SACアクタから決定論的な平均行動モデルを取り出す補助関数です。評価やC++輸出で平均方策のみを使いたいときに利用します。

## 主要関数・クラス
- `getDeterministicActorModel`: 決定論モデル抽出の主関数

## 理論・背景
学習時は確率方策で探索を行いますが、評価や組み込み推論では平均行動のみを使う方が扱いやすい場合があります。学習用と運用用の役割を分けるための関数です。

## 外部ライブラリ・ツールボックス
- MATLAB Reinforcement Learning Toolbox
- Deep Learning Toolbox

## 入出力
- 入力: 学習済みSACエージェントまたはアクタ
- 出力: 平均行動を返す決定論モデル

## システム上の役割
学習フェーズと推論フェーズの接続を簡潔にする補助関数です。評価・輸出・比較の共通前処理として使われます。
