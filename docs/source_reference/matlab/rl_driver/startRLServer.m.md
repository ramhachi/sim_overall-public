# `matlab/rl_driver/startRLServer.m`

## 概要
C++のRLサーバをDocker経由で起動する補助関数です。MATLAB側から学習や評価を始める前に、通信相手となるシミュレータプロセスを立ち上げます。

## 主要関数・クラス
- `startRLServer`: サーバ起動の主関数
- 起動確認処理: 接続可否の検査

## 理論・背景
MATLAB側だけでは物理シミュレーションを完結できないため、外部サーバ起動の手順を標準化する必要があります。Docker利用により依存環境差分を減らせます。

## 外部ライブラリ・ツールボックス
- Docker
- MATLAB の外部プロセス起動補助

## 入出力
- 入力: イメージ名、ポート設定、起動オプション
- 出力: 起動状態、接続先情報

## システム上の役割
学習基盤を立ち上げる実行補助です。MATLABとC++の分散構成を実用的に運用するための入口になります。
