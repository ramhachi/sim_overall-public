# `matlab/rl_driver/trainCurriculumV7.m`

## 概要
段階的に難易度を上げるカリキュラム学習の第7版スクリプトです。簡単な条件から始めて、徐々に複雑なコースや設定へ進みます。

## 主要関数・クラス
- `trainCurriculumV7`: カリキュラムV7学習の主関数
- `trainWithCurriculum`: 段階学習の共通処理

## 理論・背景
難しい課題を最初から与えるよりも、簡単な課題から徐々に育てる方が収束しやすい場合があります。カリキュラム学習は探索を安定させ、学習の足場を築く方法です。

## 外部ライブラリ・ツールボックス
- MATLAB Reinforcement Learning Toolbox
- カリキュラム管理用の補助関数

## 入出力
- 入力: 段階ごとのトラック・パラメータ・進行条件
- 出力: V7条件で鍛えられたエージェントと段階別結果

## システム上の役割
複雑課題への到達率を高めるための育成用入口です。段階学習の実験履歴を保持します。
