# `matlab/rl_driver/exportActorForCpp.m`

## 概要
学習済みアクタネットワークをC++推論用のテキストファイル群として保存する関数です。重み、バイアス、正規化情報を取り出して、MATLAB外で再現可能な形に変換します。

## 主要関数・クラス
- `exportActorForCpp`: 方策エクスポートの主関数
- パラメータ抽出処理: 各層の重み・バイアスの保存

## 理論・背景
学習環境と推論環境が異なる場合、ニューラルネットワークを数値パラメータとして輸出する必要があります。SACの確率方策から平均行動側を再現できるようにすることが、C++組み込みで重要です。

## 外部ライブラリ・ツールボックス
- MATLAB Deep Learning Toolbox
- MATLAB ファイルI/O

## 入出力
- 入力: 学習済みアクタ、保存先、正規化パラメータ
- 出力: C++推論用テキストファイル群

## システム上の役割
MATLABで得た知能をシミュレータや将来の実機ソフトへ持ち出すための展開点です。学習フェーズと運用フェーズを接続します。
