# `matlab/rl_driver/get_rl_server_host_port.m`

## 概要
RLサーバ接続先のホスト名とポート番号を取得する関数です。MATLAB側の通信設定を一箇所に集約します。

## 主要関数・クラス
- `get_rl_server_host_port`: 接続設定取得の主関数

## 理論・背景
通信先を各スクリプトに散らすと環境差分管理が難しくなります。接続設定を関数化することで、ローカル・Docker・共有環境の差し替えが容易になります。

## 外部ライブラリ・ツールボックス
- MATLAB 基本設定処理

## 入出力
- 入力: 任意の接続オプションや環境設定
- 出力: `host`、`port`

## システム上の役割
TCP接続まわりの設定集中点です。環境依存値を共通化して保守性を高めます。
