# `matlab/rl_driver/getVehicleParamBounds.m`

## 概要
車両パラメータランダム化の上下限を返す関数です。どの物理量をどの範囲で揺らすかを一元管理します。

## 主要関数・クラス
- `getVehicleParamBounds`: 境界取得の主関数

## 理論・背景
ドメインランダム化は範囲が狭すぎると効果が薄く、広すぎると学習が不安定になります。境界を一箇所にまとめることで、実験条件の管理と見直しがしやすくなります。

## 外部ライブラリ・ツールボックス
- MATLAB 構造体処理

## 入出力
- 入力: 基準設定や任意のオプション
- 出力: 車両各パラメータの上下限構造体

## システム上の役割
ランダム化系関数の基準辞書です。環境多様化の一貫性を保ちます。
