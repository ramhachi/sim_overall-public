# `matlab/rl_driver/trainV10_finetune.m`

## 概要
V10で学習済みのエージェントを特定トラックへ微調整するファインチューニング用スクリプトです。汎用方策を保持しつつ、特定課題への適応を高めます。

## 主要関数・クラス
- `trainV10_finetune`: V10微調整の主関数
- 既存エージェント再開処理

## 理論・背景
大域的に学んだ方策を特定環境へ適応させると、初期学習より少ない試行で高性能に到達しやすくなります。ファインチューニングは汎化性能と専門性能の折衷手法です。

## 外部ライブラリ・ツールボックス
- MATLAB Reinforcement Learning Toolbox
- 既存エージェント読み込み機能

## 入出力
- 入力: V10学習済みエージェント、対象トラック、追加学習条件
- 出力: 微調整済みエージェント

## システム上の役割
共通モデルを個別コースへ最適化する後工程です。実運用想定の性能引き上げに使われます。
