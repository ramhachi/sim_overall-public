# `matlab/rl_driver/generateRandomVehicleParams.m`

## 概要
ドメインランダム化用の車両パラメータをランダム生成する関数です。質量、重心、タイヤ・空力・駆動系などの変動を模擬するための構造体を返します。

## 主要関数・クラス
- `generateRandomVehicleParams`: 乱択パラメータ生成の主関数

## 理論・背景
固定条件だけで学習するとシミュレータ特有の条件へ過適合しやすくなります。車両パラメータをランダム化することで、変動に強い方策を育てられます。

## 外部ライブラリ・ツールボックス
- MATLAB 乱数生成
- パラメータ境界関数群

## 入出力
- 入力: ランダム化境界、基準車両パラメータ
- 出力: ランダム化済み車両パラメータ構造体

## システム上の役割
ロバスト学習を支えるドメインランダム化の生成器です。環境多様性を増やす基盤を提供します。
