# `matlab/rl_driver/trainCircleV4.m`

## 概要
円旋回学習の第4版スクリプトです。V3から報酬整形やハイパーパラメータをさらに見直し、円旋回課題での安定性向上を狙います。

## 主要関数・クラス
- `trainCircleV4`: 円旋回V4学習の主関数
- `trainRLDriver`: 共通学習エンジン

## 理論・背景
同一課題で段階的に条件を調整することで、どの変更が挙動改善に効いたかを追跡できます。V4は報酬の滑らかさや探索制御の調整版として理解できます。

## 外部ライブラリ・ツールボックス
- MATLAB Reinforcement Learning Toolbox
- RL環境関連関数

## 入出力
- 入力: 円旋回課題向け調整済み設定
- 出力: V4学習結果、比較用ログ

## システム上の役割
実験条件の系譜を残しつつ、より良い円旋回モデルを得るための改良版です。バージョン間評価の対象になります。
