# `matlab/rl_driver/assertAgentObservationDimension.m`

## 概要
エージェントの観測次元と環境の観測次元が一致しているかを確認する検証関数です。学習開始前に次元不整合を検出します。

## 主要関数・クラス
- `assertAgentObservationDimension`: 次元整合チェックの主関数

## 理論・背景
観測次元の不一致は学習開始時の典型的な失敗原因です。早い段階で明示的に検証することで、原因切り分けを容易にします。

## 外部ライブラリ・ツールボックス
- MATLAB アサーション機能
- RL Toolboxの仕様情報

## 入出力
- 入力: エージェント、環境、期待観測次元
- 出力: 正常時は通過、異常時はエラー

## システム上の役割
学習前の安全確認として機能します。モデル構成変更時の見落としを防ぎます。
