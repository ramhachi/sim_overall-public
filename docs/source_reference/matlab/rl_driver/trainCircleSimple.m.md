# `matlab/rl_driver/trainCircleSimple.m`

## 概要
円旋回コースでの簡易学習を行う最小構成スクリプトです。基本ハイパーパラメータでSAC学習を試し、環境接続や報酬挙動を素早く確認します。

## 主要関数・クラス
- `trainCircleSimple`: 簡易円旋回学習の主関数
- `trainRLDriver`: 実際の学習呼び出し先

## 理論・背景
複雑なトラックよりも円旋回は状態空間が単純で、報酬設計や接続不具合の切り分けに向いています。基礎設定での収束性確認に使われる開発用入口です。

## 外部ライブラリ・ツールボックス
- MATLAB Reinforcement Learning Toolbox
- C++ RLサーバ接続機構

## 入出力
- 入力: 円旋回トラック設定、基本学習パラメータ
- 出力: 学習済みエージェント、初期検証用の学習ログ

## システム上の役割
本格学習前の最小再現例として機能します。RLパイプライン全体が動くかを早く確認するための入口です。
