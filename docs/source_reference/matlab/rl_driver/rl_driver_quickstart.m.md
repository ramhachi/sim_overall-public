# `matlab/rl_driver/rl_driver_quickstart.m`

## 概要
RLドライバ系の導入から学習、評価、準備完了確認までを案内するクイックスタート文書スクリプトです。Dockerサーバ起動、接続試験、単一トラック学習、カリキュラム学習、評価の流れをまとめます。

## 主要関数・クラス
- `rl_driver_quickstart`: 手順案内の主入口
- `startRLServer`、`trainRLDriver`、`evaluateRLDriver` への案内

## 理論・背景
RL系は依存関係が多く、初回立ち上げの失敗が起きやすいため、手順の整理が重要です。環境構築から学習・評価までを一貫した順序で示すことで、作業ミスを減らします。

## 外部ライブラリ・ツールボックス
- MATLAB 実行環境
- Docker利用前提のC++ RLサーバ
- RL Toolbox関連一式

## 入出力
- 入力: 利用者の実行環境、接続設定、学習対象トラック
- 出力: 実行手順、確認項目、次に呼ぶべきスクリプト

## システム上の役割
オンボーディング文書として、RLシステムへの最短導線を提供します。導入者が複数スクリプトの関係を把握するための出発点です。
