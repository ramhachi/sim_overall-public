# `matlab/rl_driver/evaluateRLDriver.m`

## 概要
学習済みエージェントを決定論的に評価する解析関数です。軌跡、g-gダイアグラム、時系列、必要に応じたPIDベースライン比較を行い、学習成果を可視化します。

## 主要関数・クラス
- `evaluateRLDriver`: 評価実行の主関数
- 評価ループ: エピソード走行とログ取得
- 描画処理: 軌跡・時系列・比較図

## 理論・背景
学習報酬が上がっていても、挙動が不自然であれば実運用には使えません。決定論的評価で再現性のある走行を確認し、軌跡や横加速度分布から制御品質を検証します。

## 外部ライブラリ・ツールボックス
- MATLAB Reinforcement Learning Toolbox
- MATLAB 描画機能

## 入出力
- 入力: 学習済みエージェント、評価用環境、比較用設定
- 出力: 評価メトリクス、軌跡図、g-g図、時系列グラフ

## システム上の役割
学習後の品質保証を担う評価入口です。研究結果を説明可能な形へ整理し、ベースラインとの比較にも使われます。
