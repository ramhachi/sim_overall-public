# `matlab/rl_driver/FSAESimClient.m`

## 概要
C++のRLサーバと通信する低水準TCP/IPクライアントです。Java Socketを使い、`INIT`、`STEP`、`RESET`、`PARAM`、`QUIT` といったバイナリコマンドを送受信します。

## 主要関数・クラス
- `FSAESimClient`: ソケット通信クラス
- 接続管理メソッド: 接続、切断、再接続
- コマンド送受信メソッド: 初期化、1ステップ進行、リセット

## 理論・背景
学習ループでは小刻みなシミュレータ呼び出しが大量に発生するため、遅延の少ないTCP実装が重要です。`TCP_NODELAY` を使う設計は、制御周期ごとの応答性を確保する狙いがあります。

## 外部ライブラリ・ツールボックス
- Java `java.net.Socket`
- MATLAB からのJava連携

## 入出力
- 入力: `host`、`port`、`timeout`、バイナリコマンド、行動ベクトル
- 出力: 観測配列、シミュレータ状態、応答情報

## システム上の役割
学習環境から見れば物理シミュレータへの唯一の通信窓口です。高レベルな環境定義をネットワーク層で支える基盤として機能します。
