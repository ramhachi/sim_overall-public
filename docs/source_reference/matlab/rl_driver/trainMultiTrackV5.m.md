# `matlab/rl_driver/trainMultiTrackV5.m`

## 概要
複数コースを横断して学習させる第5版スクリプトです。単一コースへの過適合を避け、汎化性能を高めることを主目的とします。

## 主要関数・クラス
- `trainMultiTrackV5`: 複数トラック学習の主関数
- `trainRLDriver`: 共通学習基盤

## 理論・背景
1コースだけで学習すると、特定レイアウトに依存した方策になりやすくなります。複数トラック学習は状態分布を広げ、より一般的な操舵・加減速戦略を習得させる手法です。

## 外部ライブラリ・ツールボックス
- MATLAB Reinforcement Learning Toolbox
- 複数トラック切替ロジック

## 入出力
- 入力: 複数トラック一覧、共通学習設定、車両条件
- 出力: 汎化重視で学習したエージェント

## システム上の役割
単一課題の高得点よりも実用的な汎用走行能力を目指す版です。将来の未知コース適応の基礎になります。
