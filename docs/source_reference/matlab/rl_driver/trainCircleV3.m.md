# `matlab/rl_driver/trainCircleV3.m`

## 概要
円旋回学習の第3版スクリプトです。初期版よりも報酬や学習条件を整理し、安定収束を狙った改良版として位置付けられます。

## 主要関数・クラス
- `trainCircleV3`: 円旋回V3学習の主関数
- `trainRLDriver`: 共通学習基盤

## 理論・背景
版管理された学習スクリプトは、報酬設計や探索ノイズ、停止条件の変更履歴を残すために重要です。V3は基礎的な改善を取り込み、ベースライン比較に使いやすい版です。

## 外部ライブラリ・ツールボックス
- MATLAB Reinforcement Learning Toolbox
- RL環境・SAC生成関数群

## 入出力
- 入力: 円旋回用ハイパーパラメータ、車両設定
- 出力: V3条件で学習されたエージェントとログ

## システム上の役割
円旋回学習の履歴を管理する一版として、後続版との差分評価に使われます。実験再現の足場を提供します。
