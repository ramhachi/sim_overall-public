# `matlab/rl_driver/resolve_rl_vehicle_params.m`

## 概要
RL環境で使う車両パラメータを決定する関数です。明示入力、既定値、ランダム化設定などを統合して最終的な車両仕様を返します。

## 主要関数・クラス
- `resolve_rl_vehicle_params`: 車両設定解決の主関数

## 理論・背景
学習時には固定値、ランダム値、外部JSON由来など複数の車両設定源が混在します。最終仕様を一箇所で決めることで、環境構築の一貫性を保てます。

## 外部ライブラリ・ツールボックス
- MATLAB 構造体処理
- ランダム化関連関数

## 入出力
- 入力: 明示設定、既定値、ランダム化オプション
- 出力: RL環境に渡す最終車両パラメータ

## システム上の役割
環境構築前の設定統合点です。学習条件の差異を吸収して環境初期化を安定させます。
