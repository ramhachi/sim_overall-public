# `matlab/rl_driver/predictDeterministicAction.m`

## 概要
学習済みエージェントから決定論的に行動を予測する関数です。通常は平均方策を用いて操舵・加減速コマンドを返します。

## 主要関数・クラス
- `predictDeterministicAction`: 決定論行動予測の主関数

## 理論・背景
評価や比較ではランダム探索を含まない方が挙動を再現しやすくなります。確率的SAC方策から平均行動を取り出して使うことで、性能評価を安定化できます。

## 外部ライブラリ・ツールボックス
- MATLAB Reinforcement Learning Toolbox
- 決定論モデル抽出補助関数

## 入出力
- 入力: 学習済みエージェント、観測ベクトル
- 出力: 決定論的行動 `[steer, accel]`

## システム上の役割
評価・比較・輸出前確認で使う推論窓口です。ランダム性を排除した標準推論手段を提供します。
