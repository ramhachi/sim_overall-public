# `matlab/rl_driver/get_rl_vehicle_observation_vector.m`

## 概要
車両状態からRL用観測ベクトルを組み立てる関数です。シミュレータ内部状態を学習器が扱える固定長ベクトルへ変換します。

## 主要関数・クラス
- `get_rl_vehicle_observation_vector`: 観測構築の主関数

## 理論・背景
RLでは観測設計が性能に直結します。速度、姿勢、トラック相対情報などを一貫した並びで与えることで、エージェントが必要な状態表現を学びやすくします。

## 外部ライブラリ・ツールボックス
- MATLAB ベクトル操作
- 環境状態処理関数

## 入出力
- 入力: 車両状態、トラック状態、正規化情報
- 出力: RL用観測ベクトル

## システム上の役割
シミュレータの詳細状態を学習器へ橋渡しする特徴量生成器です。環境定義の要となる変換を担います。
