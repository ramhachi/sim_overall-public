# `matlab/rl_driver/applyRLEnvOverrides.m`

## 概要
RL環境に対して上書き設定を適用する補助関数です。ドメインランダム化や実験条件差し替えなど、環境パラメータの動的変更を担います。

## 主要関数・クラス
- `applyRLEnvOverrides`: 環境上書きの主関数

## 理論・背景
同じ環境クラスでも、実験ごとに報酬係数や車両条件を調整したい場合があります。上書き関数を分けることで、環境本体を汚さず設定差分を管理できます。

## 外部ライブラリ・ツールボックス
- MATLAB 構造体編集機能
- RL環境関連関数

## 入出力
- 入力: 環境オブジェクト、上書き設定
- 出力: 変更済み環境オブジェクト

## システム上の役割
実験条件差分を吸収する設定アダプタです。学習スクリプトごとの再利用性を高めます。
