# `TrackDesigner.m`

## 概要
- マウス操作で独自コースを作成する対話型 MATLAB GUI です。
- ユーザーがウェイポイントをクリックしていくと、中心線候補が逐次更新され、最終的に CSV として保存できます。
- コース定義を手早く作るためのユーザー向けツールです。

## 主要関数・クラス
- `createUI()` — ウィンドウ、ボタン、描画領域など GUI 全体を初期化します。
- `onMouseDown()` — クリック位置を取得し、ウェイポイント追加や選択処理を行います。
- `onMouseMove()` — ドラッグやプレビュー表示に応じて描画内容を更新します。
- `updatePlot()` — 現在の点列や補間結果を再描画し、ユーザーに最新状態を見せます。

## 理論・背景
- 車両シミュレーションでは、中心線と曲率変化がドライバモデルや軌跡追従誤差に直接影響します。
- 既成コースだけでなく独自トラックを素早く作れると、セットアップ比較や制御検証の幅が広がります。
- 本ファイルは高精度な CAD ツールではなく、シミュレーション入力用のコース定義を軽量に作ることを目的にしています。

## 外部ライブラリ・ツールボックス
- MATLAB 標準 GUI 機能を使います。
- `uicontrol` や `uipanel` を使う理由は、クリック入力、保存操作、状態表示を 1 画面で完結させるためです。
- 専用ツールボックスは不要で、基本的な MATLAB 環境で動かせます。

## 入出力
- 入力: マウスクリック、ドラッグ、GUI 上の操作。
- 出力: コース中心線を表す CSV ファイル。
- 中間状態として、ウェイポイント列や描画中の曲線情報をメモリ上で保持します。

## システム上の役割
- シミュレーション用トラックデータを人手で作成する入口です。
- 自動生成では表しにくいコース形状を、最適化・可視化・比較フローへ供給できます。
- MATLAB 側のユーザー操作と C++ 側シミュレーション入力の橋渡しを担います。
