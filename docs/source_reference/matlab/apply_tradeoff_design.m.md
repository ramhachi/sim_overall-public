# `apply_tradeoff_design.m`

## 概要
- 概念設計レベルの設計変数を、離散選択を含めて実車パラメータへ変換する関数です。
- `ConceptTradeOffs` の設定を参照しながら、空力パッケージや各種トレードオフ量を車両仕様に反映します。
- 初期段階の粗い設計空間を、評価可能な物理パラメータへ落とし込む役割を持ちます。

## 主要関数・クラス
- `apply_tradeoff_design(base_params, x, config, design_context)` が主関数です。
- `config` には `ConceptTradeOffs` 由来の離散候補と連続範囲が入り、`x` はその選択結果を表します。
- `design_context` は変数の意味や追加ルールを与え、単純代入ではない設計反映を可能にします。

## 理論・背景
- 概念設計では、詳細設計ほど多自由度ではないものの、空力・質量・パワートレインなど主要因を同時に比較したい場面が多くあります。
- この段階では候補パッケージ選択と連続微調整が混在するため、専用の変換関数が必要です。
- 本関数は概念最適化と物理モデル入力の境界を整理し、探索結果の解釈性を高めます。

## 外部ライブラリ・ツールボックス
- 外部ツールボックスは使いません。
- 構造体操作と単純計算で処理できるため、依存を増やさず設計空間の記述に集中できます。

## 入出力
- 入力: ベース車両構造体、設計ベクトル `x`、設定構造体 `config`、設計文脈 `design_context`。
- 出力: 概念設計変数が反映された車両パラメータ構造体。
- 離散選択値の解決結果や、計算された副次量が内部で使われます。

## システム上の役割
- Phase 1 の概念最適化で使う主要マッパーです。
- `ConceptTradeOffs` で定義した探索空間を、`VehicleSimRunner` が実行可能な形へ変換します。
- ここを変更することで、概念設計で評価したい因子を安全に増減できます。
