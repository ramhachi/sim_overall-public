# `verify_steering_param.m`

## 概要
- 操舵剛性などのステアリング関連パラメータが、設計ベクトルから構造体、さらに JSON へ正しく伝播するかを確認する検証スクリプトです。
- 数値自体の妥当性ではなく、受け渡し経路の完全性をチェックします。
- パラメータ反映漏れやキー名不一致を早期に発見するために使われます。

## 主要関数・クラス
- 主処理は設計ベクトルの設定、車両構造体への反映、JSON エンコード内容の確認です。
- 対象フィールドが期待どおり更新されているか、保存表現まで含めて検証します。
- 単一パラメータを題材に、変換経路全体を点検する性格の強いスクリプトです。

## 理論・背景
- 大規模最適化では、変数が多くなるほど「値は更新したつもりでも実行系に届いていない」問題が起こりやすくなります。
- 操舵系は挙動感度が高いため、こうした伝播不良が結果解釈を誤らせます。
- 本ファイルは、設計ベクトル→構造体→JSON→シミュレータという流れの健全性を確認するためのものです。

## 外部ライブラリ・ツールボックス
- JSON 処理を利用します。
- 理由は、MATLAB と C++ 間の受け渡し境界で情報が欠落していないかを見るためです。

## 入出力
- 入力: テスト用設計ベクトル、ベース車両構造体。
- 出力: 構造体フィールド確認結果、JSON 内容確認結果。
- 主にデバッグ表示として利用されます。

## システム上の役割
- パラメータ伝播の回帰確認を担う開発補助です。
- 設計変数追加や JSON 形式変更時の安全確認に有効です。
- シミュレーション結果の信頼性を裏から支える重要な検証項目です。
