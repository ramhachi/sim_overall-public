# `compute_aero_cd_a.m`

## 概要
- 揚力係数面積 `CL_A` から抗力係数面積 `CD_A` を推定する簡易空力モデルです。
- 二次関係の誘導抗力ポーラを用い、ダウンフォース増加に伴う抗力増加を近似します。
- 概念設計や高速探索向けの軽量モデルとして使われます。

## 主要関数・クラス
- `compute_aero_cd_a(cl_a, varargin)` が唯一の主要関数です。
- 必要に応じて係数や基準値を可変引数で受け取り、異なる空力仮定に対応します。
- 計算は単純ですが、概念設計で重要な空力トレードオフを表現します。

## 理論・背景
- 一般にダウンフォースを増やすとコーナリング性能は向上しやすい一方で、誘導抗力や抵抗増加によって加速・最高速に不利になります。
- そのため最適化では、揚力だけでなく抗力の増え方も同時に扱う必要があります。
- 本関数は詳細 CFD の代わりに、概念段階で十分軽い近似モデルを提供します。

## 外部ライブラリ・ツールボックス
- 外部ツールボックスは不要です。
- 純粋な代数式によるモデルなので、標準 MATLAB の演算だけで完結します。

## 入出力
- 入力: `CL_A`、および必要なら係数を表す任意引数。
- 出力: 推定 `CD_A`。
- 入出力はスカラー中心で、設計ベクトルから呼ばれる補助モデルとして使われます。

## システム上の役割
- 概念設計で空力の利得と代償をつなぐ補助物理モデルです。
- `ConceptTradeOffs` や概念最適化系の評価関数が、現実的な空力ペナルティを与えるために利用します。
- 詳細空力モデルを使う前段の高速スクリーニングに適しています。
