# `test_figure8_generation.m`

## 概要
- 8 の字コース生成ロジックが想定どおりの幾何を作っているかを確認するテストスクリプトです。
- 主要点を出力し、図示して形状や交差部の整合を目視確認できます。
- トラック生成アルゴリズムの妥当性を軽量に点検する用途です。

## 主要関数・クラス
- 主処理はコース生成、検証値表示、プロットです。
- 必要な点列や寸法を計算し、期待形状と合っているか確認します。
- 自動テストというより、開発時の確認用スクリプトとして使われます。

## 理論・背景
- トラック幾何が誤っていると、車両性能評価や制御誤差解釈が根本から崩れます。
- 特に figure-8 は交差部を含むため、単純円より生成ロジックの取り違えが起きやすい形状です。
- 本ファイルは、こうした幾何定義ミスを早期に見つけるための確認手段です。

## 外部ライブラリ・ツールボックス
- MATLAB Graphics を利用します。
- 形状検証は数値だけでなく視覚確認が有効なため、プロットが重要です。

## 入出力
- 入力: スクリプト内の figure-8 生成条件。
- 出力: 検証用数値表示とトラック図。
- 結果は主に開発者の目視確認に使われます。

## システム上の役割
- コース生成系の品質確認を行うテスト補助です。
- 可視化・シミュレーションに渡す前の形状妥当性チェックを担います。
- モデル本体ではないものの、入力データ品質の確保に有効です。
