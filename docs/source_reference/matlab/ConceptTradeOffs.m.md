# `ConceptTradeOffs.m`

## 概要
- 車両コンセプト設計の初期段階で使う設定ファイルです。
- 空力パッケージのような離散選択肢と、トレッド幅・エンジン特性のような連続的トレードオフを 1 つの構造体として返します。
- Phase 0 の探索空間定義として機能し、後段の概念最適化が「何を変えてよいか」を決めます。

## 主要関数・クラス
- 主処理は `ConceptTradeOffs` で、設定済みの構造体を返します。
- 返却構造体には、空力パッケージ候補、トレッド幅拡大時のペナルティ、エンジンマップ候補などが含まれます。
- 数値最適化そのものは行わず、最適化器に与える設計空間の辞書として働きます。

## 理論・背景
- 概念設計では、すべてを連続変数にすると探索空間が不必要に大きくなります。
- そのため「空力パッケージは候補 A/B/C から選ぶ」「トレッド幅は範囲内で連続に動かす」といった混合表現が有効です。
- 本ファイルはその混合設計空間を明示し、後続の GA や評価関数が同じ前提で設計案を比較できるようにします。

## 外部ライブラリ・ツールボックス
- 外部ツールボックスは前提としていません。
- 標準 MATLAB の構造体・配列だけで表現できるため、設定配布やバージョン管理が容易です。

## 入出力
- 入力: なし。
- 出力: 概念設計用の設定構造体。
- 出力には離散候補の一覧、連続変数の範囲、ペナルティやマップ参照情報が含まれます。

## システム上の役割
- 概念設計最適化の「設計可能領域」を規定する最上流ファイルです。
- `apply_tradeoff_design` や概念最適化スクリプトが、本ファイルの定義を基に物理パラメータへ落とし込みます。
- 仕様変更時にここを更新することで、設計探索の前提を一元管理できます。
