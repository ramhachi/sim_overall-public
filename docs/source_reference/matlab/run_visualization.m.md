# `run_visualization.m`

## 概要
- 保存済みシミュレーション CSV を可視化するための簡易起動スクリプトです。
- `visualize_laptime_sim()` を呼び出し、軌跡、速度、誤差、g-g 図などを表示します。
- 可視化関数の引数設定を簡略化し、結果確認を素早く行うために使われます。

## 主要関数・クラス
- 主処理は `visualize_laptime_sim()` の呼び出しです。
- 対象 CSV やトラック条件を設定し、必要な図をまとめて表示します。
- ロジックは薄く、利用者向けのエントリスクリプトという位置付けです。

## 理論・背景
- シミュレーション後の確認作業は頻繁に発生するため、起動コストが低いことが重要です。
- 毎回詳細関数を直接呼ぶより、用途別スクリプトを用意した方がチーム運用しやすくなります。
- 本ファイルは、保存済み結果の即時確認を支える実務的なショートカットです。

## 外部ライブラリ・ツールボックス
- MATLAB Graphics を間接的に使用します。
- 実際の図生成は `visualize_laptime_sim()` 側で担われます。

## 入出力
- 入力: スクリプト内で指定するシミュレーション CSV、トラック条件。
- 出力: 可視化図の表示。
- 手動の探索的解析や報告前確認に向きます。

## システム上の役割
- 可視化系ワークフローの簡易入口です。
- 上位パイプラインを回さなくても、既存結果をすぐ分析できるようにします。
- 日常的な開発・検証作業の速度向上に寄与します。
