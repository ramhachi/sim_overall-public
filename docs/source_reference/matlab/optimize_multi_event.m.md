# `optimize_multi_event.m`

## 概要
- 2 つ以上のイベント性能を両立させるための折衷最適化スクリプトです。
- 共有設計変数と追加チューナブル変数を合わせ、Skidpad と Acceleration など異なる競技要求を同時に考慮します。
- 単一イベント最適では得られない、総合性能寄りの解を探すための仕組みです。

## 主要関数・クラス
- `blend_cost()` — 複数イベントの評価値を重み付き和などでまとめる主目的関数です。
- 主処理は 38 変数程度の設計ベクトルを GA で探索し、各候補をシミュレーション評価します。
- 共有変数と拡張チューナブル変数を同じ最適化問題として扱います。

## 理論・背景
- 実車設計では、1 種目だけ最速でも総合得点では不利になることがあります。
- そのため、複数イベント間のトレードオフを明示的に扱う多目的寄りの単一目的化が重要です。
- 本ファイルは、重み付けによる折衷設計の探索基盤として機能します。

## 外部ライブラリ・ツールボックス
- GA を利用します。
- Docker は各イベント評価を C++ シミュレータで行うために必要です。
- MATLAB 側では主に最適化問題の構築と結果集約を担当します。

## 入出力
- 入力: 共有 + チューナブルを含む設計ベクトル、重み、基準タイム、評価条件。
- 出力: 最適化された設計ベクトル、または対応する車両仕様と評価結果。
- 内部出力としてイベント別の部分コストも持つことがあります。

## システム上の役割
- 総合競技性能を重視した設計判断を支える最適化器です。
- 概念最適化とフル最適化の成果を、複数イベント観点で再調整する用途にも使えます。
- 単一指標最適化では見えない設計バランスを評価系へ持ち込みます。
