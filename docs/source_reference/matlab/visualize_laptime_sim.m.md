# `visualize_laptime_sim.m`

## 概要
- ラップタイム系シミュレーション結果を総合的に可視化する主力関数です。
- 軌跡、速度、偏差、g-g 図などを複数の図として出力し、走行の全体像を把握できます。
- MATLAB 側の標準結果ビューアとして位置付けられます。

## 主要関数・クラス
- `visualize_laptime_sim(csv_filename, track_type, track_radius)` — 主可視化関数です。
- `generate_track_centerline()` — トラック種別に応じた基準中心線を生成し、軌跡比較に使います。
- 出力は 3 系統の図に分かれ、空間・時系列・運動性能を整理して示します。

## 理論・背景
- ラップタイムだけでは、どの局面で改善・悪化したかを判断しにくいです。
- 可視化によって、ライン取り、誤差蓄積、速度プロファイル、加減速度限界利用の状態を総合的に理解できます。
- 本関数は、最適化・制御調整・検証のいずれにも共通する分析基盤です。

## 外部ライブラリ・ツールボックス
- MATLAB Graphics を使用します。
- 複数の図やサブプロットを扱う理由は、1 つの観点だけでは走行品質を評価しきれないためです。
- 外部可視化ライブラリに依存せず、MATLAB 標準機能で完結します。

## 入出力
- 入力: シミュレーション CSV、トラック種別、トラック半径。
- 出力: 3 系統の可視化図。
- 内部では中心線や補助指標を生成し、表示専用に整形します。

## システム上の役割
- MATLAB 可視化フローの中心です。
- `run_visualization` や `run_full_pipeline` から呼ばれ、日常的な結果確認の標準手段になります。
- 数値評価を人間が解釈可能な形へ変換する重要な後処理層です。
