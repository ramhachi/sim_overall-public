# `create_vehicle_baseline_template.m`

## 概要
- 最適化や検証の出発点となる、完全展開済みの車両パラメータ構造体を生成します。
- 80 以上の現実的な既定値を含み、C++ 側の暗黙デフォルトに依存しない状態を作ります。
- ベースラインを明示することで、設計差分の意味を追いやすくします。

## 主要関数・クラス
- `create_vehicle_baseline_template()` が主関数です。
- 車体、サスペンション、空力、タイヤ、パワートレイン、制御関連などの主要階層を埋めて返します。
- 後続処理はこの構造体をコピーし、必要箇所だけ上書きする前提で使われます。

## 理論・背景
- C++ 側の内部デフォルトに依存すると、MATLAB 側で何を指定したかが不明瞭になり、再現性が低下します。
- そこで、実行に必要な主要パラメータを最初から明示したテンプレートを持つ方が安全です。
- 本関数は、設計探索の基準点と「仕様の見える化」を兼ねた土台として機能します。

## 外部ライブラリ・ツールボックス
- 外部ツールボックスは不要です。
- 固定値と構造体生成だけで成立するため、最小依存で扱えます。

## 入出力
- 入力: なし。
- 出力: 完全な車両パラメータ構造体。
- 出力は `apply_*` 系関数、最適化器、アーティファクト生成で再利用されます。

## システム上の役割
- MATLAB 側車両仕様の標準ベースラインです。
- 最適化、検証、可視化のすべてで共通出発点を提供し、隠れた既定値混入を防ぎます。
- 新規メンバーが「最低限どのパラメータが必要か」を理解する入口にもなります。
