# `optimize_pid_gains.m`

## 概要
- PID コントローラのゲインをベイズ最適化で調整する関数です。
- トラック条件や初期速度を与え、反復的に有望なゲインを試して効率よく改善を進めます。
- 手動調整や格子探索よりも少ない試行で高品質な設定を得ることを狙います。

## 主要関数・クラス
- `optimize_pid_gains(track_type, track_radius, sim_time, initial_speed, n_iter, params_file)` が主関数です。
- 各候補ゲインに対してシミュレーションを実行し、目的値を `bayesopt` に返します。
- パラメータファイル指定により、対象車両仕様を切り替えられます。

## 理論・背景
- PID ゲイン調整は評価 1 回のコストが高いブラックボックス最適化問題です。
- ベイズ最適化は試行回数を抑えつつ、有望領域を重点探索するのに向いています。
- 本ファイルは、シミュレーション回数を節約しながら実用的なドライバ設定へ到達するための自動化層です。

## 外部ライブラリ・ツールボックス
- `bayesopt` を使うため Statistics and Machine Learning Toolbox など関連機能に依存します。
- Docker はシミュレーション本体を C++ で実行するために使われます。
- MATLAB 側は最適化器、C++ 側は評価器という役割分担です。

## 入出力
- 入力: トラック種別、トラック半径、シミュレーション時間、初期速度、反復回数、パラメータファイル。
- 出力: 最適 PID ゲイン、最適化履歴、場合によっては最良シミュレーション結果。
- 評価指標としてラップタイムや横偏差などが内部利用されます。

## システム上の役割
- ドライバ制御の自動調整基盤です。
- 車両設計最適化とは別軸で、制御起因の性能差を詰めるために使われます。
- パイプライン全体の再現性とチューニング効率を高める重要な補助最適化です。
