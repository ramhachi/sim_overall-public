# `load_vehicle_artifact.m`

## 概要
- 車両アーティファクト JSON を読み込み、MATLAB で扱いやすい構造体へ正規化する関数です。
- 保存時の階層やメタ情報を維持しつつ、後続コードが参照しやすい形に整えます。
- 保存と再利用の往復を支えるデシリアライズ層です。

## 主要関数・クラス
- `load_vehicle_artifact(json_path)` が主関数です。
- JSON 読み込み後に必要なフィールド正規化や欠損補完を行い、統一された構造体を返します。
- 旧データとの互換を意識した実装になっている可能性が高く、読み込み後の利用を簡素化します。

## 理論・背景
- 複数段階の最適化結果や検証結果を JSON として保存する場合、読み込み時の形式差吸収が重要です。
- 生の JSON を毎回個別に解釈すると、利用コードが冗長になり、保存形式変更にも弱くなります。
- 本関数は、保存形式の揺れを受け止める読み込み窓口として機能します。

## 外部ライブラリ・ツールボックス
- JSON 処理を利用します。
- 理由は、言語間共有しやすい保存形式として JSON を採用しているためです。
- 特別な追加ツールボックスではなく、データ入出力機能が中心です。

## 入出力
- 入力: JSON ファイルパス。
- 出力: 正規化済みアーティファクト構造体。
- 出力は `extract_vehicle_params_from_artifact` や再実行スクリプトでそのまま使える想定です。

## システム上の役割
- アーティファクト再利用の標準入口です。
- 保存済み最適化結果を再評価、比較、可視化するときの共通基盤になります。
- データ永続化と解析ワークフローをつなぐ重要なユーティリティです。
