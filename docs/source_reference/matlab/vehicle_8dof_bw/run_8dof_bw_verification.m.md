# `matlab/vehicle_8dof_bw/run_8dof_bw_verification.m`

## 概要

`run_8dof_bw_verification.m` は、8DOF + Bouc-Wen モデルの MATLAB / C++ 比較スクリプトである。  
C++ 比較ファイルが見つかればロール角、ダンパ力、履歴変数を比較し、見つからなければ MATLAB 単体の可視化モードへフォールバックする。

## 主要関数・クラス

- `vehicle_8dof_bw_model(...)`  
  MATLAB 側シミュレーション。
- C++ 結果探索部  
  `bouc_wen_comparison.csv` を複数候補パスから探す。
- 誤差評価部  
  主に `phi_bw` と `damper_z_fl` を対象に比較する。
- 可視化部  
  ロール角、誤差、Bouc-Wen 力、履歴変数の図を生成する。

## 理論・背景

この段階の主眼は、Bouc-Wen ヒステリシスを含むサスペンションモデルが C++ と同じ履歴挙動を示すかどうかにある。  
通常の時刻歴比較だけでなく、履歴変数 `z` やダンパ力そのものを比較することで、非線形内部状態まで整合性を確認している。

ロール角最大誤差の閾値を 1.0 度に置いており、姿勢応答として十分近いかを実用的に判定する。  
比較ファイルがない場合も MATLAB 単体で力と履歴状態を描くため、アルゴリズム検証の入口として使いやすい。

## 外部ライブラリ・ツールボックス

外部ツールボックスは不要。  
標準の表読込・描画のみを利用する。

## 入出力

- 入力
  - ステア条件: `t=1.0 s` で `delta=0.15 rad`
  - C++ 結果: `bouc_wen_comparison.csv`
- 出力
  - 比較時: `../../output/verify_8dof_bw.png`
  - 単体時: ロール角、速度、Bouc-Wen 力、履歴変数の表示
  - コンソール上の Max Error / RMSE / PASS 判定

## システム上の役割

Bouc-Wen 統合モデルの品質確認とデバッグ入口を担う。  
14DOF へ拡張した際に問題がダンパ由来か他サブシステム由来かを切り分ける中間検証層である。
