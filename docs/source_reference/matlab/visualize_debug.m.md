# `visualize_debug.m`

## 概要
- ASE autocross トラック上での車両軌跡を、速度着色付きで素早く確認するデバッグ可視化スクリプトです。
- シミュレーション CSV とトラック CSV を重ね、走行ラインや速度分布の異常を把握します。
- 問題切り分けを最優先にした軽量な可視化用途です。

## 主要関数・クラス
- 主処理はシミュレーション結果読込、トラック読込、軌跡重ね描画です。
- 速度に応じた色付けを行うことで、どこで失速・加速しているかを直感的に確認できます。
- 出力として PNG などの画像保存を行う場合もあります。

## 理論・背景
- 軌跡デバッグでは、時系列グラフよりも空間上の速度分布が有用な場合があります。
- 特にトラック追従不良や局所的な減速異常は、色付き軌跡で見ると発見しやすくなります。
- 本ファイルは、詳細解析前の一次診断を素早く行うことに重点を置いています。

## 外部ライブラリ・ツールボックス
- MATLAB Graphics を使用します。
- 色分け軌跡と背景トラックの重ね描きが主用途のため、描画機能が中心です。

## 入出力
- 入力: シミュレーション CSV、ASE トラック CSV。
- 出力: 速度着色された軌跡図、必要に応じて PNG。
- 出力は報告用よりもデバッグ用の即時確認に向きます。

## システム上の役割
- 軌跡異常の素早い切り分けに使う開発者向けツールです。
- 本格的な可視化関数より軽く、問題箇所を素早く見つける役割を担います。
- トラックデータとシミュレーション結果の整合確認にも役立ちます。
