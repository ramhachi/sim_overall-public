# `run_comparison.m`

## 概要
- デフォルト設定と最適化設定の結果比較を素早く起動するための簡易スクリプトです。
- `compare_results()` を呼び出し、必要なファイル指定や図表示をまとめて実行します。
- 日常的な確認作業を短い手順で済ませるための利便性スクリプトです。

## 主要関数・クラス
- 主処理は `compare_results()` の呼び出しです。
- 比較対象 CSV やトラック条件を設定し、図を表示します。
- 複雑なロジックは持たず、作業の手間を減らすことに特化しています。

## 理論・背景
- 同じ比較作業を何度も行う場合、毎回引数を組み立てるより専用スクリプト化した方が運用しやすくなります。
- 特にチューニングの反復では、比較手順の簡素化が実験速度に直結します。
- 本ファイルは、その反復作業を支える実務的なショートカットです。

## 外部ライブラリ・ツールボックス
- MATLAB Graphics を間接的に利用します。
- 実際の描画は `compare_results()` 側で行われるため、本ファイルは起動役に近い立場です。

## 入出力
- 入力: スクリプト内で指定する比較対象 CSV やトラック条件。
- 出力: 比較図の表示。
- コマンドライン実行やエディタ上からの手動実行に向きます。

## システム上の役割
- 可視化分析のクイックエントリです。
- 詳細関数を知らないメンバーでも、比較作業をすぐ実行できるようにします。
- チーム内の検証フローを軽量化する補助ツールです。
