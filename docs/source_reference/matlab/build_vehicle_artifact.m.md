# `build_vehicle_artifact.m`

## 概要
- 車両パラメータと最適化・評価結果を、統一的なアーティファクト構造体へ組み立てる関数です。
- 単なる車両仕様保存だけでなく、段階ごとの履歴やイベント結果も 1 つの階層にまとめます。
- 後続の保存、読込、比較、再現実験に向けた標準データ形式を作る役割です。

## 主要関数・クラス
- `build_vehicle_artifact(params, varargin)` が主関数です。
- `base_artifact`、`stage_entry`、イベント結果などの任意引数を受け、既存情報を保ちながら統合します。
- 結果として、仕様・メタデータ・評価履歴を含む階層構造を返します。

## 理論・背景
- 最適化プロジェクトでは、どの条件で得た車両仕様かを後から追跡できることが重要です。
- 車両パラメータだけを保存すると、評価条件、イベント結果、段階名が分断され、再現性が落ちます。
- 本関数は成果物を一元化し、設計過程と結果を同じ器に保存できるようにします。

## 外部ライブラリ・ツールボックス
- 外部ツールボックスは不要です。
- MATLAB の構造体操作だけで階層アーティファクトを組み立てられるよう設計されています。

## 入出力
- 入力: 車両パラメータ `params`、任意で既存アーティファクト、段階エントリ、イベント結果など。
- 出力: 階層化されたアーティファクト構造体。
- 出力は `save_vehicle_artifact` で JSON 化される前提の中間表現でもあります。

## システム上の役割
- 設計結果の標準交換形式を組み立てる集約点です。
- 最適化段階ごとの知見を失わずに保存し、MATLAB と外部ツール間の連携を助けます。
- レポート、比較、再実行に必要なコンテキストをまとめるため、ドキュメント性の高いデータ基盤となります。
