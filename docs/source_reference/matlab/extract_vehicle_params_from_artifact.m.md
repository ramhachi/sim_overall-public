# `extract_vehicle_params_from_artifact.m`

## 概要
- 統一アーティファクト形式から車両パラメータだけを取り出すためのユーティリティ関数です。
- 新形式のアーティファクトと旧来の「そのまま params を持つ構造体」の両方に対応し、後方互換性を確保します。
- データ形式の違いを呼び出し側で意識させないための変換レイヤです。

## 主要関数・クラス
- `extract_vehicle_params_from_artifact(data)` が主関数です。
- `data` の構造を判定し、適切な階層から `params` を抽出します。
- 旧形式入力では、そのまま通すか最小限の正規化を行います。

## 理論・背景
- プロジェクトが進むにつれて保存形式が変化すると、過去データの再利用が難しくなります。
- 解析コードや再評価コードの各所で形式判定を書くと、保守負荷が急増します。
- 本関数はその吸収点として、保存形式の進化と利用コードの安定を両立させます。

## 外部ライブラリ・ツールボックス
- 外部ツールボックスは不要です。
- 構造体の存在確認とフィールド抽出だけで完結する軽量ユーティリティです。

## 入出力
- 入力: アーティファクト構造体、または旧形式の車両パラメータ構造体。
- 出力: 正規化された車両パラメータ構造体。
- 形式不一致時には、呼び出し側が扱いやすいよう一貫した戻り値を返すことが期待されます。

## システム上の役割
- アーティファクト互換性を維持するための橋渡し関数です。
- 読み込み、可視化、再実行系のコードを単純化し、保存形式変更の影響を局所化します。
- 長期的なデータ資産活用に重要な補助機能です。
