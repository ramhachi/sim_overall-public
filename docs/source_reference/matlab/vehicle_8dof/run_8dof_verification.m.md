# `matlab/vehicle_8dof/run_8dof_verification.m`

## 概要

`run_8dof_verification.m` は、8DOF MATLAB モデルと C++ モデルの一致性を確認する検証スクリプトである。  
ばね上 12 変数に加え、4 輪ばね下位置と速度を含む 20 変数を比較し、輪荷重・上下モードまで含めた検証を行う。

## 主要関数・クラス

- `vehicle_8dof_model(...)`  
  MATLAB 側シミュレーション。
- `interp1(...)`  
  MATLAB 結果を C++ 時刻へ補間する。
- 誤差評価部  
  ばね上状態と `z_u0..3`, `vz_u0..3` に対して最大誤差・RMSE を算出する。
- 可視化部  
  3×4 プロットで軌跡、姿勢、速度、ばね下変位、誤差を表示する。

## 理論・背景

8DOF 検証では、車体姿勢だけでなくばね下垂直応答の一致が重要になる。  
そのため、ばね下 `z_u` に対しては ±0.01 m と比較的厳しい閾値を設け、高周波上下モードの差異を検出しやすくしている。

独立ばね下を持つモデルでは、サスペンション剛性、タイヤ剛性、減衰、輪荷重移動の組合せが結果に現れる。  
このスクリプトはそれらの結合差を可視化するため、8DOF 段階での回帰検証に有効である。

## 外部ライブラリ・ツールボックス

外部ツールボックスは不要。  
標準の補間、CSV 読込、プロット機能を使う。

## 入出力

- 入力
  - ステップステア条件
  - C++ 結果: `output/8dof_step_steer_result.csv`
- 出力
  - 誤差解析テーブル
  - 比較図 `output/verify_8dof.png`

## システム上の役割

上下振動と輪荷重の検証を含む、独立ばね下モデルの品質確認ファイルである。  
この段階で整合が取れていることが、Bouc-Wen や LuGre を加えた高詳細モデルの信頼性土台になる。
