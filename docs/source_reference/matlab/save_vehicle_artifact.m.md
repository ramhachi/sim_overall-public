# `save_vehicle_artifact.m`

## 概要
- 車両アーティファクト構造体を JSON として保存する関数です。
- MATLAB 内部の階層データを、外部共有しやすい永続化形式へ変換します。
- 最適化結果や検証結果を再利用可能な資産として残すための保存層です。

## 主要関数・クラス
- `save_vehicle_artifact(output_path, artifact)` が主関数です。
- 入力構造体を JSON へシリアライズし、指定パスへ書き出します。
- 保存前に必要な整形やメタデータ付与を行う場合もあります。

## 理論・背景
- 最適化結果を MATLAB ワークスペースだけに置くと、再利用や共有が難しくなります。
- JSON で保存すれば、MATLAB 外のツールや将来の解析スクリプトでも扱いやすくなります。
- 本関数は、設計資産を持続的に管理するための基本機能です。

## 外部ライブラリ・ツールボックス
- JSON 処理を利用します。
- 理由は、階層構造を保ったまま言語横断で読み書きしやすい形式だからです。
- 特別な外部ツールボックスは不要です。

## 入出力
- 入力: 出力パス、アーティファクト構造体。
- 出力: JSON ファイル。
- 戻り値を持たない場合でも、永続化された成果物が主な出力となります。

## システム上の役割
- アーティファクト永続化の標準出口です。
- `build_vehicle_artifact` と対になり、結果保存フローを成立させます。
- 最適化・検証結果の共有、再現、比較を支える基礎機能です。
