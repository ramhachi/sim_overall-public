# `matlab/vehicle_3dof/run_3dof_verification.m`

## 概要

`run_3dof_verification.m` は、3DOF MATLAB モデルと C++ 実装の結果を比較する検証スクリプトである。  
ステップステア条件で MATLAB 側を実行し、C++ の CSV を読み込んで `x, y, psi, vx, vy, r` の誤差を算出する。

## 主要関数・クラス

- `vehicle_3dof_model(...)`  
  MATLAB 側シミュレーション本体。
- `interp1(...)`  
  C++ 時間軸へ MATLAB 結果を補間する。
- 誤差評価部  
  最大誤差、RMSE、平均誤差を計算し、許容差と比較する。
- 可視化部  
  6 パネルで軌跡、姿勢、速度、誤差を表示する。

## 理論・背景

3DOF 検証は、平面車両運動とタイヤ力モデルが C++ と同じ傾向を示すかを確認する最初の段階である。  
ステップステアは横運動系の基本入力であり、ヨー角・横速度・ヨーレートの一致度を見ることで、車体剛体系とタイヤ系の両方の誤差を把握しやすい。

許容差は位置 ±1 m、姿勢 ±5 deg、速度 ±0.5 m/s など実装差と長時間積分誤差を考慮した設定である。  
この段階で大きな差があると上位自由度モデルでも差が増幅されるため、重要な検証層になっている。

## 外部ライブラリ・ツールボックス

外部ツールボックスは不要。  
標準の `readtable`、`interp1`、描画関数を用いる。

## 入出力

- 入力
  - MATLAB 条件: `t=1 s` で `0.1 rad` ステア、`throttle=0.3`
  - C++ 結果: `3dof_step_steer_result.csv`
- 出力
  - 誤差統計
  - 比較図 `output/verify_3dof.png`
  - MATLAB 結果 CSV `output/3dof_matlab_result.csv`

## システム上の役割

平面車両ダイナミクスの検証層として、MATLAB / C++ 間の基本挙動整合を保証する。  
より高次の 6DOF・8DOF モデルへ拡張する前に、横運動とタイヤ応答の基準一致を確認するためのファイルである。
