# `matlab/vehicle_3dof/vehicle_3dof_model.m`

## 概要

`vehicle_3dof_model` は、平面位置 `x, y`、ヨー角 `ψ`、車体速度 `vx, vy`、ヨーレート `r`、4 輪回転、タイヤ内部状態を持つ 3DOF ベースの車両モデルである。  
RK4 で 18 状態を積分し、TMeasy 風の半経験タイヤモデルにより各輪の前後力・横力を計算する。

## 主要関数・クラス

- `vehicle_3dof_model(params, t_span, dt, input_func)`  
  主関数。静的荷重を求め、状態 `[x, y, psi, vx, vy, r, omega(4), tire_xi(4), tire_eta(4)]` を積分する。
- `derivatives(x, input, params, static_Fz)`  
  各輪接地点速度、ステア角変換、タイヤ力、空力抵抗、ヨーモーメント、車輪回転をまとめて計算する。
- `tmeasy_force(xi, eta, Fz, vsx, vsy, vcx, tire)`  
  タイヤ内部変形状態から前後力・横力と内部状態微分を返す。

## 理論・背景

このモデルは bicycle model より詳細で、左右輪を分けつつ上下運動を持たない平面車両モデルとして位置付けられる。  
タイヤは TMeasy 系の簡易実装で、縦・横の変形状態 `xi, eta` を持ち、正規化変形量と飽和則で摩擦力を決める。

また、車輪回転を明示的に持つため、駆動トルクとタイヤ縦力の相互作用を表現できる。  
低速時の特異性回避には C++ 側と同様の仮想速度 `v_N = 0.5 m/s` を前提とする設計思想があり、基礎ダイナミクス検証に適している。

## 外部ライブラリ・ツールボックス

外部ツールボックスは不要。  
RK4、タイヤモデル、運動方程式はすべて手書き実装である。

## 入出力

- 入力
  - `params`: 質量・慣性・タイヤ・空力・パワートレイン
  - `t_span`, `dt`
  - `input_func(t)`: `steering`, `throttle` を返す関数
- 出力
  - `t`
  - `state`: `18×N` 相当の状態履歴
  - `data`: `Fx`, `Fy`, `ax`, `ay`

## システム上の役割

6DOF 以上へ進む前の最小横運動モデルとして、タイヤ力学と車体平面応答の確認を担う。  
TMeasy 実装、駆動輪トルク配分、ステップステア応答の基礎比較における出発点である。
