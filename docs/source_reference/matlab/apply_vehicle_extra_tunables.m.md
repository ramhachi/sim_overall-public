# `apply_vehicle_extra_tunables.m`

## 概要
- ベース車両仕様に対して、追加の調整用パラメータ群をまとめて適用する関数です。
- ブレーキバランス、Ackermann、エンジントルク倍率、タイヤ緩和長、バンプストップ、シャシ設定などをモジュール的に反映します。
- 基本設計変数とは別に「セットアップ調整だけを増やしたい」ケースに対応します。

## 主要関数・クラス
- `apply_vehicle_extra_tunables(params, x, specs)` が主関数です。
- `specs` で各調整項目の意味、範囲、対象フィールドを定義し、`x` の値を対応先へ適用します。
- 個々の調整量は車両構造体の異なる階層に分散していても、共通規則で処理できます。

## 理論・背景
- 最適化対象をすべて固定長のベクトルで扱う場合、物理カテゴリごとに実装を分けすぎると保守が難しくなります。
- そこで、追加チューナブル項目を仕様レジストリで定義し、適用処理を汎化する設計が有効です。
- 本ファイルはその適用側であり、設計空間の拡張に対してコード変更を局所化します。

## 外部ライブラリ・ツールボックス
- 外部ツールボックスは不要です。
- 標準 MATLAB の構造体更新だけで実装でき、依存関係を増やさず柔軟性を確保します。

## 入出力
- 入力: 車両パラメータ `params`、調整ベクトル `x`、仕様定義 `specs`。
- 出力: 拡張チューナブル項目が適用された車両パラメータ。
- `specs` に応じて、一部の値はスケール変換やオフセット加算を伴う可能性があります。

## システム上の役割
- 共有チューニング変数を物理構造体へ反映する汎用層です。
- 概念最適化、フル最適化、マニュアル調整のいずれでも同じ適用ロジックを再利用できます。
- 可変項目を増やす際の実装負荷を抑え、設計空間の拡張性を支えます。
