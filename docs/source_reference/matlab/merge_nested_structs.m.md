# `merge_nested_structs.m`

## 概要
- ネストした MATLAB 構造体同士を再帰的にマージするユーティリティ関数です。
- ベース設定を保持しつつ、上書きしたい部分だけを深い階層まで適用できます。
- 車両テンプレートと設計差分、既定値とイベント別設定などの合成に便利です。

## 主要関数・クラス
- `merge_nested_structs(base, override)` が主関数です。
- 同名フィールドが構造体なら再帰的に潜り、値フィールドなら `override` を優先して反映します。
- フラットな `struct` 更新では扱いにくい深い階層差分を簡潔に表現できます。

## 理論・背景
- 車両仕様は多段の階層を持つため、単純代入では一部の下位フィールドを意図せず消してしまうことがあります。
- 差分適用を安全に行うには、構造を保ちながら必要箇所だけ上書きする再帰マージが有効です。
- 本関数は設定合成を安定化し、テンプレート駆動の設計フローを支援します。

## 外部ライブラリ・ツールボックス
- 外部ツールボックスは不要です。
- MATLAB 標準の構造体操作だけで実装できる一般ユーティリティです。

## 入出力
- 入力: ベース構造体 `base`、上書き構造体 `override`。
- 出力: マージ後の構造体。
- 片方にしかないフィールドも保持または追加されることを想定します。

## システム上の役割
- 各種設定合成の土台となる補助関数です。
- 車両テンプレート、アーティファクト更新、段階別パラメータ差分の適用を単純化します。
- 直接目立たないものの、多くの上位機能の安全性を支える基盤です。
