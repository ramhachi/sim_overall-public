# `import_engine_csv.m`

## 概要
- エンジンダイノ等から得たトルク CSV を MATLAB で扱いやすい形式へ変換するスクリプトです。
- 元データが `Kgm` 単位で与えられることを想定し、RPM 配列と `Nm` 単位トルク配列へ整形します。
- 独自エンジンマップを最適化やシミュレーションへ取り込むための前処理です。

## 主要関数・クラス
- 主体はスクリプト処理で、CSV 読み込み、単位変換、配列抽出を順に行います。
- `readmatrix` を用いて元 CSV を読み込みます。
- 出力配列は、そのまま MATLAB ワークスペースや保存処理へ渡せる形に整えられます。

## 理論・背景
- エンジンマップは車両加速性能や最適化結果に大きく影響します。
- 一方で実測データは解析向けに整形されていないことが多く、単位系や列構成の差を吸収する必要があります。
- 本ファイルは、実測データをシミュレータ資産へ変換する導入スクリプトとして位置づけられます。

## 外部ライブラリ・ツールボックス
- `readmatrix` を使う標準 MATLAB 機能のみを利用します。
- 特別な外部ツールボックスは不要で、CSV 読み込みと数値変換が主目的です。

## 入出力
- 入力: エンジントルク CSV ファイル。
- 出力: RPM 配列、トルク配列（Nm）。
- 必要に応じて、後続のエンジンマップ保存形式へ再利用されます。

## システム上の役割
- 実測由来のパワートレイン特性をシミュレーション資産へ接続する入口です。
- `ConceptTradeOffs` や車両テンプレートに載せるエンジンマップの整備を助けます。
- 現実データを設計探索へ反映するための重要な前処理です。
