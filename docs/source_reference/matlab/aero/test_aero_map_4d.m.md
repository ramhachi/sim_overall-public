# `matlab/aero/test_aero_map_4d.m`

## 概要

`test_aero_map_4d.m` は、4D 空力マップクラスの妥当性を多角的に確認する総合テストスクリプトである。  
基準条件、ライドハイト掃引、ロール・ヨー感度、速度掃引を実行し、数値出力と 6 枚の比較プロットでモデル挙動を可視化する。

## 主要関数・クラス

- `aero = aero_map_4d()`  
  テスト対象クラスの生成。
- `aero.get_coeffs(...)`  
  基準条件や掃引条件で係数取得に使う。
- `aero.compute_forces(...)`  
  速度依存の空力や前後ダウンフォース配分を確認する。
- プロット部  
  2×3 のサブプロットで以下を描く。  
  - Front RH と `CL`
  - Roll と `CL`
  - Yaw と `CL/CD`
  - Yaw と `CY`
  - Velocity と Downforce / Drag
  - Front/Rear RH に対する `CL` 等高線

## 理論・背景

検証観点は、空力モデルに期待される物理傾向が保たれているかにある。  
具体的には、低いライドハイトでダウンフォース増、ロール増大でダウンフォース減、ヨー増大でサイドフォース発生とドラッグ増加、速度二乗則に基づく空力荷重増加を確認する。

加えて、基準条件の `CL` 範囲やダウンフォース符号をチェックするため、モデルが不合理な値を返していないかを簡易判定する。  
MATLAB 側の結果を見える化しておくことで、C++ 側 4D 空力実装との整合性確認にも使える。

## 外部ライブラリ・ツールボックス

外部ツールボックスは不要。  
MATLAB 標準の描画機能とファイル保存機能のみを使用する。

## 入出力

- 主な入力条件
  - 基準: RH_front=40 mm, RH_rear=55 mm, roll=0, yaw=0, velocity=20 m/s
  - ライドハイト掃引: 25–55 mm
  - ロール掃引: ±5°
  - ヨー掃引: ±15°
  - 速度掃引: 5–35 m/s
- 出力
  - コンソール上の係数・力・検証結果表示
  - `../../output/aero_map_4d_test.png`

## システム上の役割

4D 空力マップのテストハーネスとして機能し、単体確認と C++ 対応実装の比較準備を担う。  
車両モデルへ組み込む前に、空力応答の向きとスケールを確認するための最初の検証窓口である。
