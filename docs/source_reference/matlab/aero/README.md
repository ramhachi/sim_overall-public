# `matlab/aero/`

4次元空力マップを扱う MATLAB モジュール群。  
ライドハイト、ロール、ヨーに対する空力係数変化を簡易モデルとして保持し、車両運動モデルや C++ 実装との整合確認に使う。

## 収録ファイル

- `aero_map_4d.m.md` — 4D 空力マップクラス本体
- `test_aero_map_4d.m.md` — 空力マップの確認・可視化・検証スクリプト

## このディレクトリの役割

6DOF / 8DOF / 14DOF 系モデルへ組み込む前段として、  
空力係数の定義、補間、荷重配分、検証プロット生成を MATLAB 側で完結させる。
