# `visualize_14dof_cpp_result.m`

## 概要
- C++ 14DOF シミュレータが出力した CSV を多面的に可視化する関数です。
- 軌跡、前後速度、ヨー、横加速度、輪荷重、ロール・ピッチなどを 6 パネルで表示します。
- 高自由度モデルの挙動を解析しやすくする後処理ツールです。

## 主要関数・クラス
- 主関数は `visualize_14dof_cpp_result` で、CSV を読み込んで複数指標を抽出・描画します。
- 各サブプロットは異なる物理量を担当し、相互関係を同時観察できるよう構成されます。
- 単なる軌跡図ではなく、姿勢・荷重・運動応答をまとめて見る点が特徴です。

## 理論・背景
- 14DOF モデルでは、ボディ運動、輪荷重移動、姿勢変化などの結合が重要です。
- 単一指標だけでは原因分析が難しいため、複数の応答を並列表示して傾向を見る必要があります。
- 本ファイルは、高忠実度モデルの結果解釈を支援するための標準可視化です。

## 外部ライブラリ・ツールボックス
- MATLAB Graphics を使用します。
- 多数の時系列と軌跡を同時に見せるため、サブプロットと軸管理が重要です。

## 入出力
- 入力: C++ シミュレータが出力した CSV。
- 出力: 6 パネルの可視化図。
- 各列名や物理量対応は、C++ 出力仕様に依存します。

## システム上の役割
- 高忠実度 C++ 結果の標準後処理窓口です。
- 検証、モデル比較、異常解析で重要な観察手段になります。
- MATLAB が解析フロントエンドとして機能する代表例の 1 つです。
