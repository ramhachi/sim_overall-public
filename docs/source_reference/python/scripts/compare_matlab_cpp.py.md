# `python/scripts/compare_matlab_cpp.py`

> **要約**: MATLAB と C++ の出力 CSV を読み比べ、誤差指標と比較プロットを作る検証スクリプト。
> **役割**: モデル移植や実装一致性の確認に使う、ブリッジ検証用ツール。

## このファイルが担うこと

両者の結果を読み込み、共通列に対して最大絶対誤差、RMSE、平均誤差を計算し、  
比較図とヒステリシス図を出力する。

## 理論的背景

異なる言語実装の比較では、**同じ方程式を書いたつもりでも**、

- 符号規約
- 単位系
- 積分順序
- 数値丸め

で差が出る。  
このスクリプトは、その差を定量的に確認するための検証器である。

## 主要シンボル

| 種別 | 名前 | 説明 |
|:---|:---|:---|
| `function` | `load_results` | C++ / MATLAB の CSV を読む。 |
| `function` | `compute_errors` | 列ごとの差分指標を計算する。 |
| `function` | `print_error_summary` | 誤差サマリーを表示する。 |
| `function` | `plot_comparison` | 比較図と誤差図を作成する。 |
| `function` | `main` | CLI 入口。 |

## 依存関係と使用ライブラリ

- `numpy`
- `pandas`
- `matplotlib`
- `Path`

### ライブラリ選定の意味

| ライブラリ | このファイルでの目的 |
|:---|:---|
| `pandas` | CSV を列名つきで読み込み、比較対象列を扱いやすくする。 |
| `numpy` | 誤差計算と統計量計算を簡潔に書く。 |
| `matplotlib` | 差分を図で可視化し、移植誤差を直感的に確認する。 |

## 入出力と使われ方

- **入力**: C++ 結果 CSV、MATLAB 結果 CSV
- **出力**: 誤差サマリー、`verification_comparison.png`
