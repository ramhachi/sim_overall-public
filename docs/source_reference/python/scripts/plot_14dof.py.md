# python/scripts/plot_14dof.py

## 役割
14DOF 車両シミュレーション結果を可視化するスクリプトです。ステップステアと定常円旋回の 2 系列を想定しています。

## 主な関数
- `load_data()`: 結果 CSV 読み込み
- `plot_step_steer()`: 軌跡、ヨー角、速度、ヨーレート、横加速度、操舵入力を描画
- `plot_steady_circle()`: 円旋回用の軌跡・速度・横加速度を描画
- `print_summary()`: 終端状態とピーク値を表示
- `main()`: ファイル名から試験種別を推定して分岐

## 背景・理論
14DOF モデルでは車体 6DOF と各輪系自由度を含むため、単一指標では挙動を把握しにくいです。本ファイルは運動性能評価で重要な軌跡、横加速度、ヨーレートをまとめて確認します。

## 使用ライブラリ
- `pandas`, `numpy`, `matplotlib`

## 入出力
- 入力: `step_steer` または `circle` 系 CSV
- 出力: 端末サマリー、PNG 図

## パイプライン上の位置
C++ 14DOF 実行結果を人がレビュー可能な形に整える可視化段です。
