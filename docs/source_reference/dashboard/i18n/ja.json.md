# `dashboard/i18n/ja.json`

> **要約**: ダッシュボード UI の日本語翻訳辞書。全ページのラベル・説明文・ボタンテキストを格納する。

## ファイルの目的

ダッシュボードの日本語表示に使用する翻訳テキストを JSON 形式で管理する。`app.py` の `load_i18n("ja")` で読み込まれ、Jinja2 テンプレートに埋め込まれる。

## 構造

| キー | 内容 |
|:---|:---|
| `app_title` | ページタイトル（「FSAE 車両シミュレーション ダッシュボード」） |
| `nav.*` | サイドバーナビゲーション項目 |
| `home.*` | ホームページのタイトル・説明・機能カード |
| `engine.*` | エンジン特性ページのラベル |
| `vehicle.*` | 車両パラメータページ（セクション名、ボタン） |
| `simulation.*` | シミュレーション実行ページ（シナリオ名） |
| `regulation.*` | レギュレーション確認ページ（カテゴリ名、ステータス） |
| `tire.*` | タイヤモデルページのラベル |
| `export.*` | エクスポートページ（形式名、ボタン） |
| `settings.*` | 設定ページ（言語・テーマ） |
| `common.*` | 共通 UI テキスト（読み込み中、エラー等） |

## 入出力

- **入力**: `app.py` の `load_i18n()` で読み込み
- **出力**: Jinja2 テンプレートおよびクライアント JS の `T` 変数経由で UI に反映

## システム上の役割

i18n（国際化）システムの日本語リソースファイル。`en.json` と対になり、言語切り替え機能を支える。
