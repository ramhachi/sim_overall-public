# `dashboard/templates/index.html`

> **要約**: FSAE ダッシュボードのメイン HTML テンプレート。Jinja2 テンプレート構文で i18n 対応の SPA ライクな UI を定義する。

## ファイルの目的

FastAPI バックエンド (`app.py`) が Jinja2 経由でレンダリングするフロントエンド HTML。ナビゲーション、エンジン特性、車両パラメータ編集、シミュレーション実行、レギュレーションチェック、タイヤモデル、エクスポートの 7 ページを単一 HTML ファイル内にセクションとして格納する。

## 理論的背景

SPA（Single Page Application）パターンを採用し、ページ遷移はクライアント側 JavaScript で CSS クラス（`.active`）を切り替えることで実現している。サーバーサイドレンダリングと組み合わせることで、初期表示時に i18n テキストが埋め込まれた状態で配信される。

## ページ構成

| ページ ID | 内容 |
|:---|:---|
| `page-home` | ダッシュボード概要と各機能へのカード型リンク |
| `page-engine` | エンジントルク・パワーカーブの Plotly グラフ |
| `page-vehicle` | 14-DOF 車両パラメータの動的フォーム |
| `page-simulation` | シナリオ選択とシミュレーション実行 |
| `page-regulation` | FSAE 2026 レギュレーション適合性チェックテーブル |
| `page-tire` | TMeasy タイヤ力カーブ（Fx vs SR, Fy vs SA） |
| `page-export` | パラメータエクスポート（JSON/YAML/C++ ヘッダー） |

## テンプレート変数

| 変数 | 型 | 説明 |
|:---|:---|:---|
| `t` | dict | i18n 翻訳辞書（`load_i18n()` の返値） |
| `lang` | str | 現在の言語コード（`"en"` or `"ja"`） |

## 外部依存

- **Plotly.js** (CDN `plotly-2.27.0.min.js`): グラフ描画ライブラリ
- **`/static/css/style.css`**: カスタムスタイルシート
- **`/static/js/main.js`**: クライアント側ロジック

## 入出力

- **入力**: サーバーからの i18n 辞書 `t` と言語コード `lang`
- **出力**: 完全な HTML ページ（ブラウザでレンダリング）

## システム上の役割

ダッシュボードの唯一のフロントエンドページ。`app.py` の `GET /` エンドポイントからレンダリングされる。
