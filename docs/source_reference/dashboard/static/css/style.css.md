# `dashboard/static/css/style.css`

> **要約**: FSAE ダッシュボードのダークテーマ CSS。サイドバーナビゲーション、カードレイアウト、フォーム、テーブルのスタイルを定義する。

## ファイルの目的

ダッシュボード UI 全体のビジュアルデザインを管理する CSS ファイル。CSS カスタムプロパティ（変数）でカラーパレットを一元管理し、ダークテーマを適用する。

## デザインシステム

### カラーパレット（CSS 変数）

| 変数 | 値 | 用途 |
|:---|:---|:---|
| `--bg` | `#0f1117` | ページ背景 |
| `--bg-card` | `#1a1d27` | カード背景 |
| `--bg-sidebar` | `#141620` | サイドバー背景 |
| `--accent` | `#4f8cff` | アクセントカラー（リンク、ボタン） |
| `--green` | `#2dd4a8` | 成功ステータス |
| `--red` | `#ff5c5c` | エラー・レッドライン |

### レイアウト構造

- **サイドバー**: 幅 220px、固定位置、全高
- **メインコンテンツ**: サイドバーの右側にマージン `220px`
- **カードグリッド**: ホームページの機能カード
- **パラメータグリッド**: 車両パラメータ編集フォーム
- **レギュレーションテーブル**: チェック結果の表形式表示

## 入出力

- **入力**: ブラウザの CSS パーサーによる読み込み
- **出力**: UI スタイリング（視覚的出力のみ）

## システム上の役割

`templates/index.html` から `<link>` で読み込まれ、ダッシュボード全体の外観を制御する。
