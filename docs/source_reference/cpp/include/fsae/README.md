# cpp/include/fsae/ リファレンス

- この階層は FSAE シミュレータの公開 API をまとめる最上位名前空間対応ディレクトリです。
- 下位ディレクトリ:
  - `vehicle/`: 車両状態と車両モデル
  - `physics/`: タイヤ、サスペンション、パワートレイン、空力
  - `driver/`, `control/`: ドライバーと MPC
  - `track/`, `laptime/`: コース表現と速度計画
  - `sensor/`, `estimator/`: センサ/状態推定
  - `math/`, `solver/`, `utils/`: 汎用計算基盤
