# scripts/ ソースリファレンス

`scripts/` は、主系統コードの外側で使う**運用補助スクリプト**の説明です。

## 現在の主な対象

- `easystart_container_build.sh` — EasyStart 用 Docker ビルド補助
- `refit_improved.sh` — tire_fitting の再実行テンプレート
- `verify_simulation_commands.sh` — laptime_sim 実行確認
- `run_matlab_batch.sh` — MATLAB batch 実行の共通 wrapper
- `run_rl_ace_phase4_extension.sh` — ace phase4 追加学習 wrapper
- `run_rl_benchmark.sh` — RL ラップタイムベンチ wrapper
- `analysis/` — 結果解析・可視化・PINN 妥当性確認
