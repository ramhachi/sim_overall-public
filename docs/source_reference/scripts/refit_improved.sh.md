# scripts/refit_improved.sh

## 役割

`tire_fitting/main.py` を、少し緩めた温度・速度フィルタと調整済み境界で再実行する補助シェルです。  
「標準条件ではうまく合わないので、比較用にもう一度回したい」という場面を想定しています。

## このスクリプトがしていること

- 使用条件の違いを `echo` で明示する
- Hoosier 18x6 R20 の TTC データを再フィットする
- 出力先を `output/tire_params_v2` に分ける
- 実行後に検証コマンド例を表示する

## 注意点

- 実験的な再フィット用であり、標準入口ではありません
- PINN 主系統の代替ではなく、物理モデル比較用の補助です
